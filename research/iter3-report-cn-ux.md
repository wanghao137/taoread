## 二、凯叔讲故事

### 商店事实
- 开发者：北京凯声文化传媒有限责任公司；版本 V8.2.8；评分 4.7；下载量 835.8 万。标签：儿童绘本故事。

- 来源：https://sj.qq.com/appdetail/com.ks.kaishustory

### 文章事实（一）：产品结构（2022 年产品分析，人人都是产品经理）
来源：https://new.qq.com/rain/a/20220615A08VT800

1. **信息架构**：底部导航为「故事、学堂（知识）、商城、我的」四个模块；**播放按钮置于底部导航中间位置**——设计理由是"播放按钮使用频次高，放在底部导航中间，用户打开 APP 点击播放就能接着听，保证内容连续性"。
2. **首页（故事-推荐页）**：新用户可见"你的专属福利"字样（红色）+ 较大的"领取专属听单"红色按钮；会员优惠活动以动态版形式呈现，"抄底"和"194 每年"轮番滚动；推荐机制含"猜你喜欢""排行榜""获奖绘本""为你推荐""宝贝成长计划"。
3. **搜索**：设搜索框、历史搜索、热门搜索，**并在突出位置提示"语音搜索"**（原文称"特意开发出来了有声搜索"，为照顾不识字儿童）。
4. **播放页功能集合**：播放控制、收藏、下载、**定时停止**、查看文稿、选择专辑列表、留言（支持发送语音留言）、意见反馈、分享/邀请。
5. **续播**：支持断点播放，二次播放默认从头开始但提示"上次听到这"，由用户自主选择是否续播。
6. **会员体系**：会员解锁 15000+ 内容；8 大权益（离线随时听、会员福利日、视频会员价、好友免费听、家庭账号共享、每月固定更新等）；**单个账号可在 6 个设备上同时登录**；【我的-故事会员/听书会员】查看会员到期倒计时。
7. **会员墙形态**：付费故事详情页展示原价、"会员价"或"会员免费"，用红色按钮框吸睛，以价格差引导开通会员。
8. **激励设计**：凯叔任务、"凯叔乐园，听故事得星星"、我的小世界/星星商城、"寻宝乐园"、**签到及签到提醒**。
9. **家长端**：学堂模块=家长的育儿课堂与亲子互动课程（"免费亲子日课""凯叔亲子课堂"，新增"教务处、学习成就"）；我的页面设企业资质查看、在线客服、帮助中心、用户反馈。
10. **既有缺陷（分析者观点，2022）**：**"没有设置儿童屏幕时间管理和使用时长提醒"**。

### 文章事实（二）：体验报告（简书，基于 V4.0.0）
来源：https://www.jianshu.com/p/cbbc6a41aeab

- 首页以"星球动画方式"展示，"摸一摸光头会上升到另一个空间"并推荐故事（游戏化入口）。
- 场景化分区："最新""叫早""哄睡""0-2 岁""全部"——对应儿童听故事最高频的早晚场景。
- 搜索设热门推荐与历史记录，突出位置提示语音搜索。
- 下滑信息流：依次"今日推荐""本周专题""猜你喜欢"；分析者批评超长下拉体验不好、缺乏一键置顶，且免费专区被置于最底部。
- **全局悬浮入口**："整个产品的每个页面都有正在播放的图标入口"。
- 播放页直接展示评论入口；个人中心功能竖排列，"我喜欢的"位置太靠下；底部导航曾设"游戏闯关听故事"。
- 定时暂停（针对夜间听故事入睡，睡着自动暂停）。

### 交互细节（三）：定时关闭操作路径（教程类，2023）
来源：https://jingyan.baidu.com/article/ff411625f82ad353e582375a.html

- 层级深度：定时关闭入口在**播放页一级**（闹钟图标），自定义时间在二级弹窗。另有"自定义时间"教程：https://jingyan.baidu.com/article/73c3ce28208cdfa40343d9dd.html

- 内容分类按性别（男宝/女宝）、年龄（0-1、1-2、3+、6+、10+ 五档）、类型、能力维度（表达力/社交力/认知力/思维力/审美力）划分（同上腾讯新闻文章）。

### 商店事实

- 来源：https://sj.qq.com/appdetail/com.sinyee.babybus.recommendapp

### 文章事实（一）：产品分析报告（网易，2019）
来源：https://www.163.com/dy/article/EBCFOUKK0511805E.html

1. **信息架构**：四大板块「好看、好听、好学、我」；**层级深度基本不超过 4 层**；"部分内容展示区块的分类区别并不是特别明确"，如热门推荐下的分类与下方展示区分类重叠，新用户易觉杂乱。
2. **选内容路径**：打开应用 → 选择年龄分类（如 0-3 岁）系统自动推送对应资源 → 点击"动画片"等条目进入第二层级分类 → 点击具体条目进入播放/详情页。
3. **视频播放器**：具备锁屏、后台播放、离线下载；播放结束后默认单曲循环或列表循环。
4. **音频模块**：歌词目前为"文稿展示"；分析建议改为滚动歌词形式、文字要大、**支持是否显示拼音**。

**红线说明**：桃阅读硬红线为 **积分 / 打卡 / 断签惩罚 / 孩子端推送 / 广告**。以下清单中凡证据来自竞品这些机制的设计，一律标注"触线，不做"，仅作为"行业普遍做法"记录，不作为落地项。

| 编号 | 差距描述 | 证据来源 | 建议落地形态 | 是否触红线 |
|---|---|---|---|---|
| G01 | 全局悬浮播放入口：孩子在任意页面都能一步回到正在听/读的内容 | 凯叔讲故事"整个产品的每个页面都有正在播放的图标入口"（简书报告）；少年得到"切换其他页面时正在播放按钮悬浮在屏幕上"（简书报告） | 孩子端全局悬浮迷你播放器（可拖拽、可一键收起），点击展开播放页 | 否 |
| G02 | 续播提示：二次打开同一本书时提示上次位置 | 凯叔讲故事"上次听到这"提示 + 断点播放（腾讯新闻/简书报告）；少年得到底部中央播放按钮"快速进入上次没学完的章节" | 打开书籍时展示"上次听到 XX 章 XX 分"，提供「继续听」/「从头开始」双按钮 | 否 |
| G03 | 定时关闭入口层级：竞品均在播放页一级常驻 | 凯叔讲故事：播放页左下角闹钟按钮 → 二级"自定义时间"弹窗（百度经验）；微信读书：30/60 分钟档位（新浪 2025） | 播放器一级界面常驻"定时"按钮；档位化（如 15/30/45/60 分钟 + 自定义），选中后显示剩余时长 | 否 |
| G04 | 语音搜索：为不识字儿童提供找书入口 | 凯叔讲故事"特意开发出来了有声搜索"，搜索页突出位置提示（腾讯新闻/简书报告）；喜马拉雅"首页搜索框旁的小雅 AI"（什么值得买聚合） | 搜索框内嵌麦克风按钮；识别失败时给出儿童可理解的提示（如"没听清哦，再说一次吧"），不做冷冰冰错误码 | 否 |
| G05 | 多宝宝档案：一账号多个孩子独立进程 | 喜马拉雅儿童"一个账号可以设置 5 名宝宝，每个宝宝听的内容、收藏互不干扰，分别记录进程"（搜狐测评）；洪恩识字"支持二宝设置，可以同时登陆两个孩子账户"（网易竞品分析） | 家长端创建多个孩子档案（头像 + 年龄 + 进度独立）；切换入口浅、不要求重新登录 | 否 |
| G06 | 分龄 + 场景化分区 | 喜马拉雅儿童 0-2/2-6/6-12 三阶段分龄推荐（搜狐测评 + 商店描述）；凯叔讲故事场景分区"叫早/哄睡/0-2 岁"（简书报告）；宝宝巴士"选年龄分类后系统自动推送对应资源"（网易报告） | 首页按年龄自动适配内容池；低龄段突出"哄睡/叫早"场景入口 | 否 |
| G07 | 家长时长管控：档位化、可时段限制 | 洪恩识字：设置 → 功能设置 → 使用时长 → 30/45/60 分钟档位（百度经验）；宝宝巴士：禁止观看时间 + 每次观看时长 + 防蓝光（网易报告）；喜马拉雅儿童：把控使用时长、筛选内容、限定类目（什么值得买聚合） | 家长端"时长管控"：单次时长档位 + 每日时段禁听 + 可选护眼提示；家长端设置不要求孩子端可见 | 否 |
| G08 | 家长报告：周报式、可视化 | 喜马拉雅儿童硬件联动"智能家长端可获取每周收听报告，了解孩子的收听时长与内容喜好"（ZAKER）；叫叫阅读"阅读测评、阅读报告"（泡泡网 iF 报道）；伴鱼绘本【我的】→【宝贝学情】→【学习报告】（iu9 教程） | 家长端每周阅读报告（时长、册数、偏好词云、下阶段建议），卡片式而非纯数字；**反面教材**：少年得到三个圆角矩形的学习状态被批"不直观"（简书报告） | 否 |
| G09 | 支付/商城类儿童锁 | 凯叔讲故事"商城模块与商品支付前均启用了儿童锁，能够有效防止误点"（搜狐报告） | 孩子端任何涉及购买/外部跳转的入口前置儿童锁（如图形验证或长按确认）；桃阅读若无商城则可简化为"付费内容解锁需家长验证" | 否 |
| G10 | 纯净无广告作为产品承诺 | 喜马拉雅儿童"纯净内容无广告"（商店描述）；宝宝巴士详细信息标注"无广告"（商店页）；反面：宝宝巴士游戏内提示窗广告"无法关闭，遮挡主要内容"（网易报告） | 孩子端零广告写入产品说明；任何合作位仅放家长端 | 否（且桃阅读红线本就禁广告） |
| G11 | 朗读跟读 + AI 打分纠音 | KaDa 阅读"绘本、短文朗读功能，AI 实时打分与智能纠音"（商店描述）；洪恩分级阅读"每本绘本均搭配三种出声朗读模式，智能纠音及时反馈"（商店描述）；伴鱼绘本录绘本打分（简书测评） | 绘本/短文朗读跟读：逐句打分 + 纠音提示，结果用星级/表情而非分数呈现；**教训**：伴鱼被反馈"每次评分差别很大"，打分稳定性是体验底线，宁可保守也不要抖动 | 否 |
| G12 | 电子绘本自动翻页 + 标准朗读 | 喜马拉雅儿童绘本专区"标准中英文朗读，自动翻页，让孩子爱上阅读，减轻家长讲故事负担"（搜狐测评） | 低龄绘本模式：朗读与翻页自动联动，孩子可随时点屏暂停/复读单页 | 否 |
| G13 | 学习/阅读时锁定全屏，极简控件 | 叫叫阅读"点击上课的课程内容手机自动变成锁定全屏状态，可进行锁屏取消、暂停、进度选择及线路切换"（网易报告） | 孩子端阅读/听读全屏模式仅保留：播放/暂停、上一页/下一页、退出；隐藏一切与当前书无关的入口 | 否 |

### 明确未能取证的关键维度（供下一轮补充调研）
1. **全部产品的微交互层**：按钮按压动效、翻页动效曲线、成功/失败音效、振动反馈、加载动画形态、空状态与网络错误页的文案语气与插图 —— 无任何一手证据。
2. **全部产品的无障碍适配**：是否支持读屏、字号调整、色盲/弱视模式、左右手习惯 —— 无任何产品公开提及（宝宝巴士"大字 + 拼音"建议是唯一接近的证据，但属内容呈现而非无障碍功能）。
3. **状态覆盖**：加载中、空列表、网络错误、无权限、会员墙的具体页面形态与文案 —— 仅凯叔讲故事有会员墙的间接描述（红色按钮 + 价格对比），其余均未取证。
4. **朗读高亮**：KaDa/凯叔/喜马拉雅儿童是否字级或句级高亮、是否多角色/多音色选择 —— 均未取证（仅洪恩分级阅读的"三种出声朗读模式"可间接推断多朗读模式）。
5. **KaDa 故事的交互层**：完全未取证（官网 SPA、知乎 403、百科 403）。建议下一轮通过真机截图或应用商店评论截图补充。
6. **番茄畅听青少年模式的界面形态**：仅取证到开启路径，模式内界面未取证。
