## 二、逐产品档案

### 1. KaDa阅读（原咔哒故事）｜最贴近的图书馆型对手
- 来源：App Store 描述（v8.35.0，2026-09）、搜狐实测×2（2019、2021）
- 首页：2019 年为底部五栏「绘本/听书/首页/启蒙/家长」，板块图布局；**当前结构未查证**
- 分龄：2019 年三段「0-2/3-6/7+」；当前五段「0-2/3-6/7-9/10-12/13-15」；注册选填性别+出生年月自动匹配；兴趣领域 → 立即更新书单
- 内容规模：5万+ 内容、200+ 出版机构、170+ 国际大奖、100+ 成长主题；IP 有小鼠波波、巴巴爸爸、屁屁侦探、历史是一群喵、汪汪队
- 阅读器：护眼模式（暖色调减蓝光）、分角色配音 + 特色音效、互动提问；**当前新增「绘本/短文朗读」AI 实时打分 + 智能纠音**
- 听书：独立一级栏目
- 激励：知识盒（读完获得）→ 攒知识盒解锁勋章 + 阅读闯关
- 家长端：独立一级菜单；个性化阅读报告（阅读轨迹/能力进步/兴趣发展 + 定制提升建议）、时长管理、护眼功能、**内容黑名单**、绿色无广告、多设备同步
- 未查证：会员价格、翻页方式、拼音支持、书籍详情页字段

### 2. 叫叫｜课程化阅读标杆
- 来源：App Store（v2.35.0，2026-09-16）、官网、什么值得买（2024）
- 定位：3-12 岁中文分级阅读 L1-L9，「每天 15 分钟，每年 240 次阅读计划」；CIC 灼识认证「连续四年少儿数字阅读销售额第一」
- 首页 = 任务流：周课表（前 3 天绘本学习、周四复习、周五动画串联）；**每天 24:00 解锁新课，孩子无选择权**
- 单课闭环（闯关制）：趣味导读 → 互动阅读（点击触点触发动作/声音）→ 阅读大比拼（拼图/找不同/连线/听音判断，三颗星+语音鼓励）→「宝贝，来电了」（IP 视频通话式鼓励）
- AI：阿里云大模型 + 字记豆包双模型；北师大伍新春团队「儿童中文阅读能力测评体系」
- 价格：9.9 元五日体验、88 元月度包
- 槽点：题目纯文字不认字的孩子要家长协助；对已有阅读习惯的孩子深度/广度不够，缺科普类

### 3. 洪恩矩阵｜识字→阅读路径标杆
- 洪恩识字（3-8 岁，1800 字，130 本子集绘本）：五步法「认学读写练」；象形动画、AI 笔画纠错、AI 学伴；**学完 5 字过小测解锁下章节、学完 10 字解锁一本绘本**
- 槽点（鱼sir 2000 字测评，2020）：无拼音、无跟读；必须从第一阶段学起；做错无错题解析；低龄屏幕书写困难
- **洪恩 AI 快读 / 洪恩大阅读（3-9 岁，2026-07 新品，最值得对标）**：同步识字档案自动定级；**80% 熟字 + 20% 生字**配比；五阶成长体系；AI 双轨推荐；1000+ 定制互动；AI + 真人双师；版本历史明确「学习地图焕新上线，目标更清晰、进度更直观」
- 洪恩分级阅读（与牛津合作）：1000+ 牛津原版绘本、14 级平滑梯度；**OPERA 自适应评估**；每本配三种出声朗读模式 + 智能纠音；10 种思维导图；198 元/年
- 洪恩双语绘本：中英一键切换、专业配音员分角色演绎；**每本隐含 5 个「专属秘宝」待发现收集**；每本配趣味问答
- 第三方警示（2026-08）：真实长期口碑未沉淀，互动题型雷同，「AI 匹配可能变成来回换皮」

### 4. 伴鱼绘本｜游戏化激励 + 跟读打分标杆
- 首页（2020）：绘本馆/动画TV/自然拼读/每日学/商城/成长期/发现 7 栏目
- 难度标识：绘本右上角直接显示难度字母（如「H」）；每日学 Level A–R
- 三种学习方式：听绘本（外教朗读，图片随音频自动翻页）/ 录绘本（逐句跟读系统打分）/ 闯关赛（发音选图）
- 激励：任务得宝箱 → **分享朋友圈开启** → 得「贝壳」→ 兑换海底小动物（兑换后会在首页游动）；PK 竞技场每天 3 次
- 家长端：错题本 + 阅读报告，**绑定微信后自动推送**（每周书数、词汇量、阅读等级）
- 内容：4000+ 英文原版绘本 A–Z；700+ 中文图书 L1–L5；价格 428 元/年
- 槽点：VIP 不含自然拼读需单独付费；多次涨价；PK 对战变家长答题

### 5. 喜马拉雅儿童｜听书平台标杆
- 定位：0-12 岁，120 万+ 集音频，北师大独家分龄推荐；内置 1170 本牛津树线上绘本
- 官网卖点：分龄分性别量身推荐、**夜晚哄睡 + 起床叫早**、场景伴随（上学路途/亲子时光/长途旅行）、绿色护眼、内容专家督导复审、纯净无广告
- 家长控制：使用时长 + **筛选收听内容、限定可收听类目**
- AI 助手：波波（百科问答、成语接龙、AI 原创故事）、小雅（AI 荐书、听中问）
- 槽点：VIP/白金 VIP/儿童 VIP/儿童 SVIP/少儿 VIP/SVIP 大师课**复杂套娃式收费**

### 6. 宝宝巴士
- 2019 年「好看/好听/好学/我」四大板块；当前 18000+ 集动画、550+ 款互动、24000+ 有声故事，0-8 岁
- 分龄内容策略：0-3 习惯与语言 / 4-6 入学预备与自我保护 / 7+ 思维与品格
- IP：奇奇、妙妙；啦咘啦哆警长（安全教育，全球播放近 400 亿次）
- 家长端（2019）：禁止观看时段 + 每次时长 + **防蓝光模式**；历史播放、离线下载管理
- **至今仍有开屏广告、in-banner 广告、游戏内提示窗**——与头部去广告趋势相悖
- 槽点（woshipm 2019）：信息入口太多、分类重叠、新用户觉得杂乱；App 矩阵 160+ 款留存差

### 7. 番茄畅听 / 番茄小说
- **无独立儿童模式**，只有「青少年模式」（我的 → 设置，需时间锁密码）
- 反面对照：**「解锁时长」机制——看视频解锁听书时长**；签到福利、吃饭福利、提现等成人向激励
- 无分龄推荐、无家长端报告（未查证）

### 8. 微信读书｜BYOK 底座
- **没有任何亲子/儿童功能**：App Store 描述（v10.2.1）无相关字样；最近 25 个版本更新说明无任何「亲子/儿童/少儿/绘本」功能上线
- 可借鉴标杆：听书**定时关闭**（10.1.1 专门优化）、「阅读统计」小组件（打卡进度 + 阅读时长，9.3.8）、AI 问书、AI 导读、书中讨论、书单榜单
- 姊妹产品「微信听书」独立存在
- **含义**：BYOK 书架同步 + deepLink 跳转的差异化路线成立，微信读书不会自己做亲子功能

### 9. 少年得到
- 定位 7-15 岁（现改「综合素质培养平台」）；首页免费专区/学科/视野/名著精讲/能力/有声书 6 模块
- 功能：名著精讲、好书领读、有声书；播放进度断点续播（底部「正在播放」）
- 激励：积分系统（早期「积分暂无意义」）
- 槽点：应用内限定金额充值、与得到 App 账户余额不互通

### 10. 凯叔讲故事｜听书体验标杆（最值得逐功能对标）
- 首页：底部四栏「故事/任务/亲子/我的」；Banner + 年龄分类（0-2/3+/6+）+ 功能分类 + 热门 + 专题 + 猜你喜欢；**左上角「摸一摸」凯叔光头推送精选专辑**（IP 彩蛋）；**语音搜索**（照顾识字不多的孩子）
- 专辑详情页：试听、高清大图（边听边看插画）、用户评价、**「上次听到这里」进度指引**、批量/多选下载离线
- 播放器：状态栏悬浮操作、后台播放、**哄睡定时（可提前设置播完后收听「睡前诗」）**、收藏分享下载
- 激励：「任务」版块——多听故事解锁更高级任务/等级；《声律启蒙》**亲子对读**功能
- 商业：故事会员 30000+ 集，35 元/月；「请朋友免费收听」「为好友购买 VIP」

## 三、差距清单（三层）

> 前提：桃阅读是「睡前共读仪式应用」——不卖内容、不卖课程、无积分商城、无断签惩罚、无面向孩子的推送、无广告（产品红线，见 docs/02 §3.4）

### A 层：行业标配，但与红线冲突 → 坚持不做
| 功能 | 谁在做 | 如何回应 |
|---|---|---|
| 积分商城 / 阅读币兑换 | 伴鱼贝壳、宝宝巴士积分 | 红线；卖点改写为「成就纪念式，不养积分仓鼠笼」 |
| 打卡对赌 / 0 元返学费 | 伴鱼旧版、扇贝/薄荷阅读 | 红线；这正是家长焦虑的来源，可作差异化主张 |
| 看视频解锁时长 | 番茄畅听 | 反成瘾设计反面教材，可写进公关物料 |
| 面向孩子的推送 | 几乎所有对手 | 红线 |
| 开屏/in-banner 广告 | 宝宝巴士（至今） | 头部都已强调「无广告」，我们是盟友 |
| 重内容采购 + 付费课程 | 凯叔/洪恩/叫叫 | BYOK + 公版库路线零内容成本、零版权风险 |

### B 层：行业标配，且桃阅读应该补
**P0 孩子端选书与阅读**
1. **书籍详情页标准化**：难度标识 + 适龄标签 + 试读/试听 + 简介 + 章节列表——BYOK 书架同步后最缺的信息层
2. **语音搜索**（凯叔，为不识字孩子设计）
3. **分龄推荐引擎**（KaDa 按出生年月匹配、喜马拉雅分龄分性别、宝宝巴士智能分龄）
4. **阅读器互动触点**（叫叫点击触点、洪恩双语绘本 5 个秘宝、KaDa 互动提问）——v2「在工具里读」的核心留存点
5. **跟读打分 + 智能纠音**（KaDa AI 实时打分、伴鱼逐句打分、洪恩三种朗读模式+纠音）

**P0 家长端**
6. **阅读报告升级**：加阅读等级变化、理解题正确率、兴趣主题分布（哪些主题读得最久）
7. **家长管控**：补**内容黑名单**（KaDa 标配）和**类目筛选**（喜马拉雅儿童）
8. **阅读能力定级**（叫叫北师大体系、洪恩 OPERA、伴鱼免费定级测试）——轻量版：读完几本 + 理解正确率 + 生字量

**P1 听书与播放器**
9. **定时关闭**（凯叔哄睡定时+播完收听睡前诗、微信读书 10.1.1）——睡前场景刚需
10. **后台播放 + 悬浮控制 + 断点续播**（凯叔状态栏播放器、「上次听到这里」）
11. **内容预告 / 更新提醒**（凯叔）：「明天晚上可以读这本」

**P1 传播**
12. **微信社交链**：周报分享卡已是对的方向，可考虑直接推送给孩子爷爷奶奶

### C 层：差异化机会（对手没做好或完全没做）
1. **共读脚手架「讲什么、问什么」**——**最大蓝海**。10 个对手全是「孩子独立使用」或「纯听」，没有一家教家长「今晚这本书怎么讲、提什么问题」
2. **孩子真实选书权**：叫叫 24:00 解锁固定课表零选择权；KaDa/伴鱼海量但易迷失。桃阅读的「接着读/推荐/骰子/书架」切出独特位置，**骰子机制尤其珍贵**
3. **纪念式成就体系**：夜灯第 N 晚 / 最长连续 / 读完第 N 本 / 金句墙。**金句收藏没有任何对手做**
4. **无内容的阅读应用**：BYOK + 公版库 + AI 实时儿童化。规避翻译权地雷，翻转成本结构
5. **就寝窗口 + 5 分钟软封顶**：反成瘾内生设计，合规护城河
6. **IP 吉祥物缺口**：叫叫有小鸡叫叫、凯叔真人 IP、宝宝巴士奇奇妙妙、喜马拉雅波波/小雅。**桃阅读的「桃子」还没立起来**——P0 品牌资产
