# 桃阅读 TaoRead 🌙🍑

> 家庭的睡前共读仪式应用 —— 孩子选书、家长共读、阅读发生在微信读书与纸质书里。
> 孩子在「今晚读什么」里拥有真实选择权；家长拿到「讲什么、问什么」的共读脚手架；
> 读完的时光和金句被郑重收藏；每周全家看见自己的阅读足迹。
> 我们不卖内容、不卖课程、不设积分商城——我们负责让孩子爱上「和爸爸妈妈一起读书」这件事。

## 快速体验（演示模式，零配置）

```bash
npm install
npm run demo
# 打开 http://localhost:5173 ，家庭码输入 PEACH888
#   · 选「爸爸妈妈」：共读卡 / 书架管理 / 周报分享卡 / 设置
#   · 选「小朋友」：月亮门 → 选书（推荐/搜索/骰子）→ 出发 → 收尾 → 夜灯墙
```

演示模式使用 mock 网关（零真实出网）+ 预置两周共读账本（夜灯 11 盏、读完 2 本、金句 15 句）。

## 接入真实微信读书（BYOK）

1. 家长端「设置 → 绑定微信读书」，按向导粘贴自己的微信读书 API Key（`wrk-` 开头）；
   key 经 AES-256-GCM 加密落库，界面只回显尾 4 位。
2. 把想给孩子读的书加入微信读书书架，桃阅读自动同步（仅童书类目进入孩子世界）。
3. 阅读本身发生在微信读书 App（deepLink 跳转）或纸质书里；桃阅读负责仪式、记录与成就。

## 仓库结构

```
apps/
  server/   # Fastify 服务端：微信读书网关适配层（唯一出网通道）、家庭/共读/仪式/周报域
  web/      # React PWA：孩子端仪式流 + 家长端
packages/
  shared/   # 前后端共享常量（枚举单一来源）
e2e/        # Playwright 端到端（对演示模式，任意环境可重放）
docs/       # 全部文档与日志
scripts/    # npm run demo 入口
```

## 安全与隐私要点

- API Key 服务端加密存储，任何接口只回显尾 4 位；`.env` 永不入库。
- 儿童信息最小化：不收集儿童身份信息；注销家庭=物理删除全部家庭域数据。
- 防沉迷内生：就寝窗口（默认 21:30，家庭可调）+ 单次软封顶 5 分钟；无任何面向孩子的推送。
- 激励零物质化：成就为纪念式（夜灯第 N 晚/最长连续/读完第 N 本），无积分商城。
- 产品红线（永不做的）：正文分发、积分商城、断签惩罚、面向孩子的推送、广告。
