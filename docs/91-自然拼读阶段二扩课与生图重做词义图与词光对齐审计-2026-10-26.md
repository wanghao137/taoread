## 2. 阶段二/三扩课：24 课 → 41 课（docs/69 §6.3/§6.4 路线）

新增 17 课（L25–L41），`build-phonics-foundation.mts` 幂等生成：

- **新授 15 个映射（总 34 GPC）**：阶段二 j /dʒ/、v /v/、w /w/、y /j/、z /z/、**x /k/+/s/（一字素双音素，词尾）**、**qu /kw/（双音素，词首）**、ff /f/、ll /l/、ss /s/（三双写一课，词尾）、ck /k/、sh /ʃ/；阶段三 **ch /tʃ/、th /θ/（清音）、ng /ŋ/（词尾）**。x/qu 用 schema 的一字多音能力，落实 docs/69「不强做一块永远一个音」。
- **新词 35 个（总 89 词）**：jam/jet/jog、van/vet、wet/web/wig、yak/yes、zip/zap、box/fox/six、quiz/quit、off/bell/doll、sock/duck/kick、ship/shop/fish、chip/chin/chat、thin/moth/bath、ring/wing/sing。
- **词形白名单扩展**：L31/L33/L37 引入 CVCC（box/fox/six），L32 引入 CCVC（quiz/quit），L39/L40/L41 全 CVCC（bath/moth 与 ring/wing/sing 组合）。
- 结构：13 节新授课 + 3 节巩固课（L28：j/g/d 形近、w/v/r；L33：x/k/s、qu/k/w 拆解；L41：ch/sh、th/t 听辨）+ 2 节毕业课（L37 小书 `fox ran. / fox hid. / six fish.`；L41 小书 `sing sing. / ring ring. / chat chat.` 重复句式）。
- 生成器关键修复（实战发现）：**字素切分按映射表最长匹配**（quiz→qu,i,z；逐字符会切出 g-q）；**孤儿剥离按"解码引入课号"判定**（白名单漏删被删词残留，vest/yell 教训）+ 保留词音频槽缺失自愈（w-sam 三件套）+ Sam 词条大写与资产 id 小写双形式保留。课程设计漏洞修正：vest（CVCC 超前）、yell（含未授 ll）换词；L28 干扰项 y 超前换 d；L33 词卡补 CVCC 词形。
- **规模**：**41 课 / 89 词 / 333 任务 / 40 readers / 452 资产**。`validate-phonics` development 模式 **0 错误**。
