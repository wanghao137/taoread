# 桃阅读孩子端 UI 返工（2026-10-14）

## 问题与决策

用户截图暴露的核心问题是阅读任务被工具层抢占：弹窗内部重复标题、再套重边框卡片，选择按钮与普通操作等权；声音、语速和复选框挤在同一行。现有“控件存在、无横向溢出”的检查不足以证明视觉与使用体验合格。

本轮从孩子的三个任务出发：找到想读的书、舒适地读正文、需要时调整阅读方式。正文优先，常用工具可达，次要辅助按需打开。书架保留暖纸与封面识别，移除黑色硬阴影、旋转和重复装饰；阅读工具不再使用贴纸主按钮堆叠。

## 实际修改

- 公共书和家庭书复用 `ReadingAppearance`，统一主题、字号、字体、行距、阅读方式与图片亮度；选择状态同时使用底色、边线、字重与 `aria-pressed`。
- 家庭书工具分为排版、听读、书签。声音单独占行；语速独立选择；书签同步、空状态和帮助反馈放到对应组。去掉重复标题与内部 panel，弹窗只保留一个滚动容器。
- 公共书设置分为排版、听读、更多；收藏、书签、家长话题、反馈和本地录音从排版中移出，功能仍可达。
- 阅读正文使用稳定的内容宽度；家庭阅读器常用操作缩减为目录、阅读工具、朗读。保留章节导航、书签、触摸翻页与原有懒加载。
- 目录一章一行，长标题换行，当前章明确标记；家庭目录打开时定位当前章。portal 弹窗显式跟随纸白、暖纸、夜间主题。
- 首页、找故事、我的、书目详情、家庭书架与听读页统一按钮、卡片、导航、字号和留白。空书架提供找故事行动；每日小诗按句排版，避免末字独占一行。
- 保留 Dialog 的 Esc、Tab 圈定、背景 inert、滚动锁及焦点归还；初始化和还焦不使页面跳动。

## 验证与证据

隔离演示数据库、合成家庭书（370 章）和演示孩子用于全部交互检查。真实家庭、孩子、阅读记录、媒体供应商和存储配置不用于测试。浏览器证据保存在 `output/playwright/ui-rework-20261014/`，不提交会话文件。

已完成第一轮实际 Chromium 检查：首页、找故事、我的、家庭书架、连续听读、书目详情，320/390/820/1440px 均无页面横向溢出。家庭/公共阅读设置各分组均检查可见控件尺寸与交互；实际 CDP 触摸事件可推进公共书和家庭书页码；字体、行距、主题、阅读模式、370 章跳转、Esc 还焦和 Tab 圈定通过。页面异常为零。

已打开实际截图人工检查，发现并修正了窄屏分组标题折行、每日小诗末字单行、家庭目录按钮并排、续读卡片中的小封面标题挤压等问题。目录修正后已在生产构建上重新检查：370 行独占整行，当前章节位于弹窗可见区域。金句选择弹窗也显式传递夜间主题，并通过定向浏览器检查。

本轮本地类型检查、Lint、触达巡检通过；前端 120 项、服务端 480 项单测及 22 项隔离端到端测试通过。生产构建检查确认首页只请求一次公共书库，不加载未使用的阅读器、听读和家长代码块。浏览器检查还核查设置中的控件尺寸及代表性文字对比度，未出现页面运行异常。最终构建后的定向检查、远端 CI、部署与公网结果另写入本轮 `final-target.json`、`gates.json`、`deployment.json`、`public.json` 和 `final.json` 发布凭据；只有相应 `complete` 为真才代表该环节完成。

真实 iOS Safari、Android 设备和儿童任务观察尚未完成；不将模拟视口结果表述为真机验收。合成声音选项只验证控件显示和选择，不代表已对真实供应商发起收费朗读。

## 发布与回退

仅发布前端源码和构建资产。先通过本轮校验和远端 CI，再在服务停止期间制作当前数据库一致快照及静态资产备份，保留删除台账。快进生产源码并复制新资产，保留旧 hash 文件，重启服务更新 CSP。验证源站、公网 HTML 与所有新 JS/CSS 资产哈希。发生失败时只回退本轮源码与静态资产，保留当前生产数据库及删除记录。
