- 宋词语料确有 280 篇，本版改名《宋词选·亲子读本（280篇）》，不再用“三百首”暗示另外 20 篇已收录。

经典比对包括三字经、千字文、百家姓、朱子家训、弟子规、增广贤文、幼学琼林选篇、声律启蒙上下卷、唐诗三百首、千家诗、诗经、宋词。诗经 305 篇、宋词 280 篇的正文字串与选用语料一致。唐诗比对出现的“唯通惟”是已移至注释的异体说明，诗句并未缺失。千家诗保留全部选用语料并有额外标题／资料，不能称字数完全相等。没有把不同版本的所有古籍都宣称为校勘定本。

## 实现与验收办法

- `import-chinese-stories.mjs`：逐书授权检查、完整分页导入、原文哈希及权利说明。
- `audit-completeness.mjs`／`chineseLibrary.test.ts`：结构、233 页全文、故事顺序、独立场景及来源范围断言，不再用“至少几章”假判完整原著。
- `gen-art.ts`：按书／场景生成、实际文件存在才跳过、更新台账、HTTP 429／5xx 有限重试，失败返回非零；`gen-art-variants.mjs` 重生成比原图旧的变体。
- 语音覆盖与生成脚本保留选定数据库，避免 `.env.r2` 覆盖生产／待发布数据库。媒体同步必须成功查询私有场景排除集合，否则停止上传。
- `verify-chinese-media.mjs`：全中文逐块对照、原图和两个变体解码、真实运行缓存键的 MP3 大小与时长、上传状态、R2 对象列表及字节数核验。失败不能算齐全。
- `publish-chinese-content.mjs`：只发布 13 本修复和 20 本新增；旧版本 compare-and-swap；单事务发布，重排章节／拆章时保留旧章块 ID，迁移数字形式的进度与划线坐标。要求 API 停写；不对生产执行全库播种。

隔离浏览器使用演示库，不暴露复制了真实家庭数据的待发布数据库；配图和音频读取实际生成文件，供应商请求设为失败断言，证明播放使用已有公共音频。390×844 与 1440×900 均完成找故事搜索、完整页数说明、首章真实播放、末章和配图检查。播放时长 8.568 秒，播放位置实际前进。移动端触摸翻页抵达第 2／4 页；20 本新增书的目录、末章和末章正文接口均通过。证据 `output/content-20261009/browser-result.txt`，共 73 项检查。

生产库离线演练结果：23 张非内容家庭／业务表哈希未变，未涉及的书籍记录未变，全部旧章节、正文块 ID 保留，阅读进度／划线按预期迁移，SQLite integrity_check 为 ok。证据 `publication-rehearsal.json`。复制生产数据的演练库只在本机离线使用，不入 Git。
