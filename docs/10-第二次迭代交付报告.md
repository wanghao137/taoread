### 1.2 用户三项需求的差距闭环

1. **图文并茂 / 儿童审美**：书架空状态、加载态、详情页、吉祥物全部落为原创 SVG；书卡封面、章节题图、正文插图三轮「图文并茂」断言在 E2E 里锁死（`svg[data-art]` 必须真实渲染）。
2. **故事 / 古诗 / 英文读物**：书库 8 本 26 章——古诗 7 章（原文+拼音+译文）、蒙学 3 章、故事 4 章（西游记 3 + 寓言 1）、英文童话 12 章（4 本 × 3 章）。英文书逐字取自 Project Gutenberg，每本一行版权台账（pd-us 判据 + 作者卒年 + 源 URL）。

## 3. 本轮修掉的真实缺陷

按「缺陷优先于功能」的原则，以下都是影响数据正确性或体验的真 bug：

1. **周报暴露内部 id + 少算时长（C1+C2）**：内容域会话的 bookId 是 `cbf:xxx`，周报直接回退显示原始 id；且内容阅读在进入阅读器时未开会话，durationSec 系统性偏小。修复后家长看到的是真实书名与真实时长。
2. **TTS 分句两个 bug（C5，被新单测抓住）**：`splitSentences` 的标点正则漏了 ASCII `.`（英文永不在句号处切分）；空白折叠先于切分执行，`\n` 被吃掉导致诗歌行首尾相连。重写为「先按行切、段内再折叠」。
3. **续读位置永远是章首（C3）**：blockOrder 上下文已存在但从未消费；现在滚动上报 + 打开时按块恢复。
4. **作者行缺失（C7）**：公版书作者为空时显示空串，现按语言回退「English / 佚名」。
5. **E2E 跨用例就寝窗污染**：家长端用例点「21:00」护眼预设后不还原，22:38 跑批时后续孩子端门屏被就寝窗闸住。修复：用例末尾断言选中态后还原「跟随默认」。
6. **E2E 限流桶耗尽（潜在 flaky）**：演示库单家庭 + mock 网关，join 无爆破面，但 5 令牌桶在同 IP 串行登录下会被打空。修复：演示入口注入宽松桶（生产仍是 5/分钟）。

## 4. 安全与红线复核

- **无 key 进源码/进库**：本轮新增与改动文件已扫描（`sk-*` / `AKIA*` / 明文 key 模式零命中）。
- **内容版权**：本轮新增正文全部逐字取自 Project Gutenberg 公版电子书（#11 Alice、#16 Peter Pan、#2591 Grimm、#14838 Peter Rabbit），下载留痕在调研目录；rights 台账逐书写明 workTitle / 作者卒年 / jurisdiction / basis / sourceUrl。Grimm 译文为 pre-1929 英译本，pd-us 判据成立。
- **儿童文案无焦虑诱导**：无正文分发、无积分商城、无断签惩罚、无孩子推送、无广告；睡眠定时到点只说「时间到啦，今晚的故事先到这里，晚安 🌙」，无催促语义。
- **deepLink** 仍只消费网关返回值；内容域阅读器不需要 deepLink。
- **调研淘汰项已文档化**：积分商城 / 打卡对赌 / 连胜火苗 / 面向孩子的推送 / Learn-First 解锁——不是差距，是护城河的另一侧（docs/09 §4.4）。
