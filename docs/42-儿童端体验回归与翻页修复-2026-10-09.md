# 桃阅读儿童端体验回归与翻页修复

日期：2026-10-09。范围：公共电子书、家庭书架、公共文字离线阅读，以及儿童端 PC／手机／窄平板的主要旅程。用户反馈：划不动、文字裁切、页码错乱。

本报告记录当前源码、隔离演示库和真实 Chromium 浏览器的证据；历史 docs/34—41 的结论不能代替本轮验证。修改尚未提交、推送或部署。

## 环境与证据边界

- 使用独立 API 8798、前端 5184、`e2e-run-product-20261009.db`。家庭书测试是自行编写的两章《翻页体验验证书》，没有读取或改写真实家庭书库。
- 演示入口开启 `TAO_E2E_ISOLATION=1`，真实 TTS／生图／视频供应商被禁用；微信读书走 mock。没有验证真实付费生成或供应商音频质量。
- 浏览器宽度：390×844、320×568、768×1024、1440×900，阅读器另查 844×390 横屏。触摸用 Chromium CDP 的真实 touchStart／touchMove／touchEnd／touchCancel，经过浏览器 Pointer Events 和事件捕获流程，不用直接调用翻页函数代替滑动。
- 28 张页面截图及几何探针覆盖今天、找故事、我的、家庭书架、家庭书详情、家庭阅读器、英语练习入口。交互回归另有最终截图。截图发现与功能回归分别记账。
- 未连接实体 iPhone／Android；Safari、微信内置浏览器、系统字体差异、低端手机长书性能与真实语音需要设备验证。

## 发现与已实现的修复

| 分类 | 问题与证据 | 原因 | 本次实现 |
| --- | --- | --- | --- |
| 影响体验 P0 | 公共书／家庭书手势可能划不动；滑动后首个按钮点击被吞掉 | 段落的隐式触摸捕获转移到阅读视口时，子元素冒泡的 lostpointercapture 被当作取消；防拖动误点击的标记会残留到下一次按钮点击 | 仅真实横拖时捕获；忽略子元素的捕获转移；稳定回调；新点击清除上一手势的防误触标记，保留键盘按钮激活 |
| 影响体验 P0 | 正文裁切、列边界错位、页码有空白页 | 用含 padding 的视口宽度计算列宽，实际正文更窄；整数 clientWidth 丢失小数；offsetLeft 不可靠；插画溢出墨迹被计成新列 | 以正文实际小数宽度算列步长；按元素片段矩形定位；按列步长舍入页数；约束分页图片高度 |
| 影响体验 P0 | 调字号后页码和正文不同步；切回滚动模式偏移残留 | 独立重置页码没有同步 transform；命令式 columns／transform 没有随模式清理 | 内容章节键与排版重算键分开；按段落及段内列位置保留锚点；滚动模式主动清除翻页样式 |
| 影响体验 P0 | 家庭书连续翻页保存旧位置 | 原节流直接丢掉快速翻页；并发请求用旧版本；首读的保存响应会再次触发续读定位 | 每次翻页记录当前段落；顺序提交并更新版本；初始位置只恢复一次，包括空进度和零偏移；显示保存状态 |
| 影响体验 P1 | 公共书停在新页后，节流期间的位置可能被旧保存响应清空 | 旧请求成功后清空的是可变的最新 unsavedRef；没有节流尾次提交 | 只清空该请求实际保存的 payload；补 5 秒窗口后的最后一次保存，保留离开时兜底 |
| 影响体验 P1 | 标题／插图独占一页时，新读的书被报成章节末段 | 找不到当前页正文就直接返回最后一段 | 先选择当前页正文，再选择下一页的正文，只有已越过全部正文才回退末段；实际检查开头页上报 blockOrder 为 0 |
| 影响体验 P1 | 家庭书底部按钮被正文高度挤出屏幕 | 固定 `100dvh - 168px` 忽略顶部工具换行与按钮高度 | 全高 flex 布局，正文弹性占剩余空间；章按钮和页按钮在实际视口内 |
| 优化 P1 | 公共书横屏正文空间过小 | 章导航预留大块固定 padding，再叠加页导航与底栏 | 页导航改为正常布局；短横屏并排放章导航、页导航，扩大正文，保留全部操作 |
| 缺少功能 P1 | PC 缺明确章内键盘翻页；孩子不容易发现滑动功能 | 原左右键直接跳章；缺章内导航 | 公共书／家庭书提供上一页、下一页及实时章内页码；分页模式左右键翻页，避免编辑框／弹层误操作 |
| 影响体验 P1 | 家庭书架加载时显示空书架，部分进度失败产生未处理拒绝 | 没有加载状态，Promise.all 整组失败 | 明确加载、失败、重试；部分进度失败保留能看的书；可返回今天 |
| 优化 P2 | 小屏“帮我挑一本”挤成多行、窄平板侧栏压缩书卡 | 搜索 flex 子项缺 min-width；平板仍保留 190px 侧栏 | 搜索宽度可收缩，极小屏调整行布局，按钮不拆字；761—900px 使用完整内容宽度和底部导航 |
| 影响体验 P2 | 封面慢载／坏图时变成缺标题的色块 | src 存在就隐藏文字、显示 has-art | 图片真正加载成功后才切 has-art 与 AI 角标；保留慢载和失败时文字封面 |
| 缺少功能 P1 | 离线电子书没有左右翻页和本机续读 | 离线页直接堆整本正文 | 独立分页阅读界面、章节选择、触摸／键盘／按钮翻页、IndexedDB 位置恢复、来源版本信息、返回与删除；书架在阅读期间隐藏并退出后恢复 |
| 影响体验 P1 | 生词“再看看”和“认识啦”都直接跳过，缺暂停出口 | 两个动作调用同一 advanceReview | “再看看”在本轮末尾重看一次，每词最多追加一次，防止无限循环；增加“先休息一下”；完成按去重词数反馈 |
| 影响体验 P1 | 英语练习提示“下次接着练”，实际上暂停后从头开始 | active 只查询 started；paused 不允许答题且没有恢复动作 | 查询可恢复的 started／paused；新增授权的显式 resume，恢复保留答案，已完成和跨家庭尝试不可恢复 |
| 影响体验 P1 | 无配套短文的英语课程答完后卡“正在准备” | reader 分支要求 active.reader，空短文没有结束路径 | 无短文课程也能结束；完成记录仅在确有短文时说明读过短文 |

## 验收建议与尚需外部证据的部分

1. 在实际出问题的手机／浏览器打开公共长篇书与家庭长篇书，正反方向连续滑动、调字号、横竖屏、刷新续读，检查页内换行和末页内容。
2. 续读坐标按段落保存；跨列的长段落重新打开可能从该段落所在的前一页开始，避免漏读。页码是当前排版的章内页码，字号／尺寸变化后总页数自然变化，不能作为跨设备不变的书籍页码。
3. 英语课程仍为草稿。标准音素音频、口型与教师签认没有因为本次流程修复而完成；继续保留默认关闭和家长开关。
4. 真实语音回退取决于系统语言包；麦克风权限、真实生成与教学质量不能用 mock 和 Chromium 测试替代。
5. 家庭私有书离线下载尚未实现；此次修复在线家庭阅读的滑动。公共离线文字继续遵守现有版本／七天期限，不缓存私有 API 或扩大授权内容范围。
