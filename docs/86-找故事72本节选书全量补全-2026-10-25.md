## 执行方式与并发实测

- 子代理滚动并行，**实测并发上限 2-3**（第 4/5 个派发即报 user/model concurrency limit exceeded）；单代理任务书一律「读 N 个 pack 文件、写 M 个 JSON 即完成，不要做多余验证」控制 token（大书 100-400 万 token/本）。
- 大部分代理死于收尾阶段（限流/配额），**parts 文件已落盘即成果有效**——以 parts 落盘为准验收，死代理无需重跑。
- 两个代理分段写同一本书会撞车（wizard-oz 首次翻车：两段都写到结局）。书级派发+明确段落边界（「你的最后一章必须停在 X」）后解决。

## 坑位速查

1. Prisma SQLite 相对路径相对 `prisma/schema.prisma` 目录解析，绝对路径 URL 会静默连空文件。
2. 本仓库 `apps/server/dev.db` 与 `prisma/dev.db` 并存，seed-dev 用后者。
3. `nssm restart` 的 cmd 脚本经 Git Bash 调用 `/t` 被 MSYS 吃掉——直接跑脚本再手动 curl 验证。
4. lamejs 1.2.1 需预注入 `globalThis.MPEGMode/Lame/BitStream`（issue #86）。
5. MiMo TTS：`POST api.xiaomimimo.com/v1/chat/completions`，文本放 assistant 角色、user=风格指令、`audio:{format:'wav',voice}`，仅出 24kHz WAV。
6. ArtAsset 的 scene 键=art 键本身（如 `oz-green-gate`），不是 `chapter:<id>:<n>`（后者仅 art 缺省时的 fallback 命名）；urlPath 扁平存 `art/chapters/<scene>.webp`。
7. pregen `--retry-upload` 按当前音色键查清单，英文段必须 `--lang=en`。
8. `media/.tts-public-state.json` 单写者原则：pregen 与自定义脚本不可并发。
