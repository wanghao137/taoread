# 41 · 书架筛选修复整合与移动端滑动翻页（2026-10-09）

> 用户反馈四项：①找故事心情/书单按钮「不生效」、书单点击先出「没找到，换个词试试」；②筛选按钮多而功能不明确；③移动端所有电子书（含家庭书架）要滑动翻页；④阅读体验自分析优化。
> 方法：本地复现取证 → 第一性原理方案 → 实施 → 对抗式审查 → 部署。

## 一、问题 1 取证（真实浏览器）

- **数据层健康**：collections 5 个书单 totals 21/45/146/108/10；`/api/content/collections/:id` 返回正常（bedtime-poems=12 本）；category 分布 story 35/tale 124/poetry 19/primer 10。
- **书单空态误报（实锤）**：V8App 空态「没找到，换个词试试。」的条件是 `v.loaded && filtered.length===0`——书单模式点击后 `collectionBooks` 尚为 null（家庭上行 ~95KB/s 下 1-3s），filtered 恒空 → **加载窗口内先闪「没找到」**，书到了又替换。用户感知=「点了书单 → 没找到」。
- **心情筛选「不生效」= 感知问题（实锤）**：本地全新链路实测 setMoodKey→setSearchParams→URL `?mood=funny` 全通（此前探针「不生效」是 dev 长时 HMR 陈旧闭包假象）。真实成因三合一：
  1. 无醒目结果反馈：结果数那行是 12px mono 小字，书网格前几屏与未筛选视觉几乎一样（189→35 本，前 4 列没变化）；
  2. **选中的 chip 可能在横滑容器视口外**（点右侧 chip 后容器不自动滚动到选中项）；
  3. 空态误报（同上）叠加「坏了」的印象。
- 修复：空态排除「书单加载中」；选中 chip 自动 scrollIntoView；新增醒目「已选 ✕」结果条（贴纸风、含本数、一键清除）。

## 二、问题 2：chips 整合（13 → 7）

现状两行 13 个按钮（全部+5 心情+中文+英文 ｜ 5 书单），职责重叠（想听英文 vs 英文）、横滑不可发现。
方案：
- 心情行保留：`全部` + `想笑一笑/想去冒险/想安静一下/想知道为什么/想听英文`（孩子的选择语言，核心交互）
- 撤掉独立语言 chips（中文/英文）——「想听英文」已覆盖 en 需求，默认书架中文优先
- 书单收进行尾「书单 ▾」chip：点击弹底部面板（大图标+标题+简介+本数，单选可再点取消）——从「平铺 13 个」变「7 个 + 一个收纳」

## 三、问题 3：移动端滑动翻页（≤760px）

第一性原理：孩子拇指横向滑动=纸书翻页的身体记忆；滚动模式的长文定位对孩子更难。
方案（公共 usePagedReading hook，公共书 ReaderPage 与家庭书 FamilyReaderPage 共用）：
- **分页**：正文容器 CSS multi-column（column-width=容器宽、gap=48px），内容横向铺开，外层 translateX 切页；容器高度=视口减顶栏与控制条避让。
- **手势**：左右 swipe（阈值 48px）翻页；末页右滑=下一章、首页左滑=上一章；点击左/右页边（各 22%）翻页，点击中间=呼出/隐藏控制条（与专注模式兼容：翻页模式下点中=切控制条，不再触发专注）。
- **指示**：页码「N / M」浮标（半透明，几秒后隐去）；排版/字号/行距变化即重排并保持当前段位置（按当前块 anchor 定位回页）。
- **朗读联动**：高亮段推进时自动翻到所在页；点段跳读跳页。
- **开关**：排版面板新增「翻页/滚动」（记住偏好；移动端默认翻页，PC 恒滚动）。
- 划线长按在翻页模式下保持（pointermove>10px 取消已有）。

## 四、问题 4：阅读自分析优化（随翻页一并落地）

- 滚动模式补顶部阅读进度细条（当前章内进度，1.5px 不可抢焦点）。
- 翻页模式自带页码与章界手势；控制条在翻页模式下默认隐藏（点击中间呼出），阅读沉浸面更大。
- 章节加载失败重试保留（既有）。

## 五、验证计划

verify + e2e 全量；真浏览器复测：书单点击全程无「没找到」闪现、选中 chip 可见性、结果条、7-chip 布局、公共书/家庭书翻页手势与页码、朗读自动翻页、偏好记忆、PC 滚动不变。

## 六、执行记录（2026-10-09）

### 修复 1+2（筛选体验与整合）
- **根因修复（心情 chip 不生效）**：chip onClick 连续两次 setSearchParams，第二次用本渲染旧 searchParams 快照构建参数，把第一次写入的 mood 覆盖——全新 context 实测复现并实锤；统一改 `applyFilters(patch)` 一次成型。复测：点「想笑一笑」→ pressed=true、结果 188→35 本。
- **书单空态防闪**：`filtered.length===0` 空态排除「书单加载中」（collectionBooks 未到）；书单内为空时文案改「这份书单里暂时没有适合你的书」。复测：书单点击全程无「没找到」闪现，12 本正确展示。
- **感知强化**：选中 chip `scrollIntoView({inline:'center'})`（横滑容器不再把选中态留在屏幕外）；新增 `.filter-active` 结果条（已选：X / N 本 / ✕ 换换 一键清除）。
- **整合**：撤「中文/英文」chips（「想听英文」已覆盖 en）；5 枚书单 chips 收进行尾「书单 ▾」→ Dialog 面板（图标+标题+简介+本数，可再点取消）；13 → 7。

### 修复 3（滑动翻页）
- `apps/web/src/lib/pagedReading.ts` 新 hook：CSS columns 分页（measure 设 columnWidth/Gap，scrollWidth 推页数，锚点保持重排位置）、translateX 切页、指针手势（swipe 48px 阈值、跟手拖动、页边 22% 点击翻页、中间非正文点击回调）、setPointerCapture（鼠标拖出视口不泄漏）。
- 公共书 ReaderPage：pageMode（≤760 默认翻页，偏好持久化 `taoread-reader-pagemode`）；main 双模式结构（滚动=scroll+点击切专注；翻页=overflow hidden+viewport/track）；尾部导航移出分页流两模式常驻（e2e 兼容）；页码指示 N/M；排版面板加「左右翻页/上下滚动」；朗读高亮双模式跟随（scrollIntoView / goToElement）；翻页进度上报接入 unsavedRef 离开兜底（单次翻页落在节流窗内不再丢）。
- 家庭书 FamilyReaderPage：article 翻页模式 flex 列（track 弹性+按钮行可达）；续读定位双模式（按 progress.offset 找块设锚跳页）；翻页上报 save(当前页首块 cleanStart)；图片 aspect-ratio 占位防列重排；模式切换按钮。

### 修复 4
