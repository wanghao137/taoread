## 0. 最重要的一条发现：当前「深蓝夜空」主题可能用错了颜色

这是本次调研**唯一与主流 dark mode 审美相悖、但有儿童褪黑素研究硬支撑的结论**：

> Sleep Foundation（引用 Higuchi 2014 / Crowley 2015 / CDC 2020）：**儿童晚间光线对褪黑素的抑制是成人的两倍**；儿童瞳孔比成人大、青春期前光敏感度显著更高；夜灯/阅读灯应使用**红、黄、橙长波长光**（不抑制褪黑素）。
> 来源：https://www.sleepfoundation.org/children-and-sleep/how-blue-light-affects-kids-sleep

桃阅读当前底色是 `#0E1A38`（深靛蓝）——**蓝色系的暗模式在睡前场景是反科学的**。正确做法是**低亮度暖色（琥珀/深暖棕）底色**，主动压低蓝光成分。

反向证据（诚实标注冲突）：Minguillon 2017（PLOS ONE，PMC5648169）发现 471nm 蓝光照明让人**更快放松**（1.1 分钟 vs 白光 3.5 分钟达到最低压力）。但该研究样本仅 12 人、平均 25.3 岁、非睡前场景，作者自陈需扩展。**取舍：睡前场景以褪黑素研究为准。**

## 1. 六条可落地到 Tailwind 层面的规范

### 1.1 触达区域（WCAG 2.2 AA + 儿童增强）

| 规范 | 数值 | 来源 |
|---|---|---|
| WCAG 2.2 SC 2.5.8（AA 强制） | ≥ 24×24 CSS px | W3C |
| W3C 移动无障碍 | ≥ 9×9 mm | W3C |
| Apple HIG | ≥ 44×44 pt | Apple |
| **儿童产品推荐** | **≥ 48×48 dp** | Ungrammary |
| **儿童按钮间距** | **≥ 64 px** | Ungrammary |

落地：主操作按钮 ≥ 64×64px（`min-h-16 min-w-16`）；间距 ≥ 16px；翻页热区 = 整页。
**桃阅读现状**：`min-h-touch` = 64px 已达标，本轮修复了收藏按钮 40px 的违规。

### 1.2 色板（双主题：日间 + 睡前）

**睡前模式（核心）**——低亮度暖色，压低蓝光
```js
// 不用纯黑 #000（刺眼 + 加重光晕 halation），用极深暖棕
night: { 900:'#1A1410', 800:'#241D17', 700:'#332A21', 600:'#443829' },
// 暖色前景：红/黄/橙长波长不抑制褪黑素
nightText: { DEFAULT:'#F5E6D3', muted:'#C9B79E' },
nightAccent: '#E8A04C',  // 琥珀色强调，低饱和
```

**色彩心理学依据**（两项实证，均为物理空间研究，迁移到屏幕需自行验证）：
- 冷色显著提升平静（β = −0.365, p = 0.041），暖色更易引发躁动（β = 0.186, p = 0.099）——Sun 2024, *Buildings* 14(10), MDPI，银川 123 名小学生
- 儿童偏好暖色 + 高亮度；最受欢迎饱和度是 25，其次 75，最不喜欢 50——Hao 2025, PMID 40130501
- **折中**：低饱和中亮度冷色为主基调 + 小面积暖色用于角色与成就反馈

### 1.3 排版（分龄 + 加宽字距）

| 年龄段 | 正文字号 | 依据 |
|---|---|---|
| 3-5 岁（前阅读者） | ≥ 24pt，语音朗读为主 | Ungrammary / NN/g |
| 6-8 岁（独立阅读萌芽） | ≥ 18pt | NN/g：较大儿童 12pt 起步，本场景上调 |

- **字距加宽能显著帮助阅读障碍儿童**；且加宽字距可消除斜体/装饰字体的负面影响（Duranovic 2018, PMID 30094714）
- 「Dyslexie 字体」相对其他字体**无额外收益**——起作用的是**间距**而非字体本身
- **禁用**：斜体、装饰花体、衬线对比强烈的宋体；中文用圆体/几何无衬线
- 行高 1.7-1.8；流体排版 `clamp()` 下限不得低于 18px
- **桃阅读已落地** `letterSpacing: 0.04em`（docs/17 P0-3），方向正确

### 1.4 动效（功能性 + 可关闭）

- 只保留功能性微动效（翻页确认、按钮态变化），**砍掉庆祝类全屏动效**
- NN/g：动画和声音被儿童**喜欢且被期待**（与成人相反），但睡前场景需抑制唤醒
- 全站遵循 `prefers-reduced-motion`；睡前模式额外降速 50%
- Calm UX 核心原则：**无突然 UI 跳变**（highly predictable behavior）

### 1.5 布局与认知负荷（NN/g，125 名儿童三轮研究）

| 年龄段 | 特征 | 设计含义 |
|---|---|---|
| 3-5 岁 | 前阅读者；**不滚动**；偏好大而简单的触屏动作 | 无文字导航、全屏触达、强视觉提示「下面还有」 |
| 6-8 岁 | 独立阅读萌芽期，会**扫描**内容 | 可配文字 |
| 9-12 岁 | 熟练阅读者，会滚动、会搜索 | 标准手势 |

其他关键结论：
- **冗余菜单对儿童「非常困惑」**（成人只是轻微困惑）→ 导航必须极简且唯一
- 低龄儿童「依赖书签/点击而非搜索」→ **不要给搜索框**
- **家长区入口藏进纯文字页脚**（NN/g 明确「text-only footers worked well」）
- 每屏选项 3-5 个（Ungrammary）

> **与桃阅读现状的冲突**：docs/11 P0-1 做了搜索框给 3-5 岁孩子。按 NN/g 这条，低龄儿童不该有搜索框。需重新审视。

### 1.6 家长门（Apple Kids 类目硬性要求）

- 外链、购买、设置入口必须先过家长门
- 对 pre-literate 儿童建议用**语音提示**「需要家长操作」
- **不要用算术题**（3-8 岁孩子可能比家长算得还快）
- Kids 类目 App 不得向第三方发送 PII；原则上**不应包含第三方分析或第三方广告**
- 来源：https://developer.apple.com/kids/

## 2. 2025-2026 通用趋势（哪些该用、哪些该限）

| 趋势 | 适合桃阅读？ | 限制条件 |
|---|---|---|
| 液态玻璃 Glassmorphism 2.0 | **部分适合** | 只用于翻页指示条/播放浮层/家长门弹窗；正文页一律不透明（Intuitia：在文字密集屏「kills readability fast」） |
| Bento Grid 便当网格 | **仅书架页** | 阅读页禁用（视觉竞争与睡前降温目标相反） |
| 手势优先导航 | **非常适合** | 睡前精细控制更弱，左右滑翻页远优于点小按钮；控件闲置 3 秒自动淡出 |
| Dark Mode 2.0 自适应 | **核心刚需** | 必须是**暖色暗模式**，非冷调深蓝（见 §0） |
| Calm UX 低刺激 | **设计基调** | 更少选择、柔和转场、渐进披露、低饱和、无突然跳变 |
| 功能化动效 | 适合但参数调低 | 150-200ms 微动效；砍庆祝类全屏动效 |
| 人味质感 Anti-Perfect | **高度适合** | 颗粒叠加、手绘质感对抗 AI 冷感（Moshi 改版全面移除库存图） |
| 流体排版 | 适合 | `clamp()` 下限 ≥ 18px |

## 3. 获奖案例拆解

### 2025 Apple Design Awards（儿童/阅读相关）

| 作品 | 奖项 | 可借鉴 |
|---|---|---|
| **CapWords**（中国） | Delight and Fun 获奖 | 拍身边物品生成互动闪卡；快照动画+真实音效转场 |
| **Speechify** | Inclusivity 获奖 | Dynamic Type + VoiceOver；UI 明确「降低认知负荷」为目标 |
| **Art of Fauna** | Inclusivity 获奖 | 多套配色主题、完整 VoiceOver、**恐吓内容开关** |
| **Vocabulary** | Visuals 入围 | 「一致的插画体系创造干净的视觉节奏」；多主题+轻柔触感反馈 |
| **puffies.** | Inclusivity 入围 | Reduce Motion、高对比度模式、轮廓线开关 |

**启示**：2025 ADA 最明显的趋势是——**多主题切换、Dynamic Type、VoiceOver、reduced-motion 开关、内容恐吓开关**，全部是获奖标配，且可做成「家长可配置」。

### Moshi（0-10 岁儿童音频助眠 App，Fiasco Design 改版）

与桃阅读场景最接近的真实商业案例：
- audio-only 定位（睡前听 > 看屏）
- 弃用 Calibri 改 Chromatica 字体（「温暖、有人情气的无衬线体」）
- **全面移除库存图**（「缺乏真实性、削弱使命」），改真实摄影 + 手绘注释
- 色板「从一开始就以可及性为考量」开发
- 双受众设计：孩子用 + 家长（付费决策者）买单

### Awwwards UI KIDS（SOTD 2022，7.44/10）
- 把 UI 元素拟人化成漫画角色
- 三色鲜艳色板 Teal #49C5B6 / Red #D14836 / Yellow #ECD06F
- **注意**：高饱和三色板不适合睡前模式，仅日间模式保留

## 5. 一句话结论

3-8 岁睡前阅读 App 的设计基调应是「**Calm UX + 暖色低亮暗模式 + 超大触达区 + 分龄排版 + 家长门合规**」——把液态玻璃/Bento/鲜艳渐变**限制在日间书架页**，阅读页严格执行低刺激、可及性优先的规格。
