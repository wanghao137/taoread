## 3. 过程中发现的真实缺陷

| 缺陷 | 严重度 | 处理 |
|---|---|---|
| 搜索只匹配书名时，孩子搜「静夜思」搜不到（它收在唐诗集子里，是**章节**标题） | 高（功能错误） | 搜索范围扩到章节标题。这不是「多做一个功能」，而是**只搜书名本身就是错的**——孩子脑子里记的是诗名，不是集子名 |
| 孩子端 4 处次按钮 48px，低于儿童 64px 红线 | 中（可及性） | 全部提至 `min-h-touch`；并写入巡检脚本防回归 |
| 阅读器弹层关闭钮 36px | 中（可及性） | 提至 64px |
| iOS 26 朗读含 `<` `>` 的中文文本会崩溃（BYOK 书名/笔记可能含） | 高（可用性） | utterance 前消毒 |
| 孩子端「换家庭」一键退出，误触即丢会话 | 中（容错） | 二次确认层 |

## 6. 明确未做（诚实声明）

| 项 | 为什么本轮不做 |
|---|---|
| 服务端 TTS（拟人音色 / 字级高亮 / 锁屏控件） | Azure F0 免费层方案已定（docs/11 §6），但需注册国际账号 + 出网 + 数据出境告知，且**本环境无浏览器、无法验证出声**。做一个无法自测的语音链路不符合「严格认真」。留 v4 |
| 拼音搜索 | 需全量拼音表；且语音搜索证据（iOS WebKit bug 317741）指向「孩子更该用拼音/语音而非打字」，拼音输入法由系统键盘提供，应用层做首字母索引收益有限 |
| 悬浮播放器 / 听读双首页 | 信息架构级改动，桃阅读阅读器即全屏，无跨页播放场景 |
| 音量上限 / 家人录音 / 跟读打分 | 需硬件层或实时通道；跟读打分稳定性无可靠方案（伴鱼被批评分不稳） |
| 图像级视觉评审 | **本环境模型与评审子代理均无图像输入能力**（已实测：PNG 读取被 provider 拒绝）。所有视觉层差距均以结构断言（DOM/几何/对比度/构建产物）论证，非像素级 |
