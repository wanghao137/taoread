# 自然拼读仅本家庭体验

2026-10-20：用户指定目前自己使用，因此采用独立的单家庭体验权限。8 课内容可供本人查看与操作，不等同于对外正式发布；不修改教学、发音、权益、真机或家庭试用的审核记录。

## 访问条件

- 服务器同时设置 `TAO_PHONICS_SELF_USE_FAMILY`（单个家庭内部 ID）和 `TAO_PHONICS_SELF_USE_HASH`（准确内容 SHA256），不能填写家庭码或家长 PIN。
- 数据库版本状态为 `self_use`，内容哈希一致；全站 `TAO_PHONICS_ROLLOUT` 保持 `off`。
- 课程结构、内容哈希和全部实体素材的路径、哈希、容器签名必须通过验证；fixture、缺文件或任何非人工审校问题都会拒绝开放。
- 开启孩子的 v2 enrollment 后，原有家庭所有权、设备会话、媒体签名、进度修订与幂等协议继续生效。
- 仅允许未完成的教学、权益和语音人工审校进入体验；原始审核结论保持不变。家长端显示体验范围和发音待修正说明。

## 操作与回退

先完成停服一致性数据库备份与原始媒体校验，再安装准确提交、前端构建和课程媒体。发布工具使用显式数据库 URL、媒体目录及 `--expect-hash`，执行 `open-self-use`。该命令不授予家庭权限、不设置默认正式版本、不产生虚构验收凭据。

家长端“英语自然拼读”可暂停课程；孩子端 `/child/phonics` 进入体验。删除两项 self-use 配置并重启即可撤销整个家庭的体验访问，进度保留；或使用 `withdraw` 撤回版本。将全站 rollout 改为 `all` 也不会把 self_use 版本开放给其他家庭。

## 验证范围

覆盖家庭隔离、哈希绑定、撤回、配置撤销、事务中的学习请求、签名媒体、fixture、缺素材和过期清单拒绝。现有课堂浏览器验收覆盖 390px / 768px、暂停续练、保存重试和重读。实体媒体技术验证不能证明发音准确或教学效果；纯音 p/n/m 等候选素材仍需修正和人工听审，个人体验暂不作为孩子独立模仿发音的示范。

对外正式发布仍使用原有 publish-pilot / publish 审校与验收门槛，个人体验无法绕过这些门槛。
