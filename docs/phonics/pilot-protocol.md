# 首八课受控试点执行规程

状态：执行规程已准备；真实家庭观察尚未执行。不能将本文件作为 familyPilot 通过报告。

## 开始条件

八课教学、逐文件语音、素材权利、技术和真实设备验收已通过，并绑定同一 versionId/contentHash。试点发布使用 `publish-pilot`；运行配置必须为 `pilot`，指定家庭范围，家长主动开启。不得为了开展试点提前使用 rejected/pending 音频。

试点约 6–10 个家庭，覆盖 5/6/7 岁、不同英语基础和陪伴条件，进行 1–2 周多次短练习。邀请和家长同意须实际发生；不默认录制儿童音视频，不保存真实姓名。参与者可随时停止，不以完成八课交换奖励。

## 每次观察

使用去标识家庭编号，记录日期、年龄、基础、设备/浏览器、实际次数、时长、退出位置和原因。首两次可当面或在线观察，之后家长简短补记。

| 项目 | 必须记录 |
|---|---|
| 家长开启、选择起点 | 是否需要开发者解释，是否混淆开启与掌握 |
| 首次操作 | 开始、重听、点选、求助、暂停是否能完成；额外成人提示次数 |
| 词义与示范 | 分开记录不懂意思、听不清声音、跟不上合成及操作困难 |
| 卡住与退出 | 提示后能否继续，挫败/疲劳表现，是否知道可暂停 |
| 跨日恢复 | 是否回到正确步骤，帮助状态与既有记录是否保留 |
| 未带读组合 | 是否刚听过答案；独立、帮助后、自述、未观察分别记录 |
| 家长摘要 | 能否区分点选结果、家长观察、未观察；更正是否留痕 |

## 停止与出口

出现越权、隐私泄露、记录串乱、无声/叠播、恢复错题、帮助后冒充独立等严重问题，停止受影响版本的新学习，保留历史记录。修复后重新验证并回访。

全部阻断问题清零；至少 80% 的参与孩子在一次操作引导后，无需开发者现场指挥可完成核心五项操作。正常家长陪伴允许，但额外提示如实记录；不足 80% 时修改并重新观察，不删除困难样本。报告同时保留达标人数与总人数，小样本比例不代表教学效果。

家长对三类记录的误解逐项修订回访；跨日及未带读组合有实际观察。单次 5–8 分钟仅为观察起点，疲劳应缩短，不设“读对多少才上线”的学习增益门槛。

最终 familyPilot 证据须含本次版本、内容哈希、实际使用与问题记录、修订及复测证据。只有实际完成出口条件后，才可填写 `complete: true` 和 `result: passed`。
