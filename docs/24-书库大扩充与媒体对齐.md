## 三、图片严格对齐：发现并修复的三个缺口

### 缺口 1：旧包章节缺 artPrompt（插画退化）

校验器扫出 105 个旧章节没有 `artPrompt`，gen-art 只能退化成通用提示词「与内容相符的安静优美画面」——图片与内容对不上。已全部按章节内容补写具体画面描述。

### 缺口 2：6 组跨书场景键撞名（两本书共用一张图）

`primer-scroll` 被五本蒙学书共用当封面、`moon-window`/`goose-pond`/`rabbit-hole`/`spring-rain`/`sunrise-hills` 各有一组跨书复用——两本书指向同一张生成图。已逐个改键并重新生成。

### 缺口 3：image 块只有 40 张手绘 SVG 可用（结构性缺陷）

阅读器里章节正文中的插图（`kind: 'image'` 块）此前**只走 SceneArt 手绘 SVG 库**，而该库只有 40 个场景；新书 400+ 个 image 块绝大多数会回退成通用「书架」图。

修复（四端联动）：
1. `content/service.ts`：取章节时批量收集 image 块场景键，查媒体台账回填 `artUrl` 注入 block DTO
2. `web/lib/api.ts`：`ContentChapterDto.blocks` 增加 `artUrl` 字段
3. `ReaderScreen.tsx`：image 块改用 `BookCover`（与封面/章节题图同一组件），有 AI 图出 AI 图、无则静默回退 SVG
4. `gen-art.ts`：遍历 image 块独立场景键一并生成，幂等跳过

结果：**103 本书 663 张插画，逐一核对 0 缺失、0 空 url**。note 块（生词提示）统一用 `lamp-hint` 小图，3 个历史 outlier 已对齐。
