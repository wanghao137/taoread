## 1. UI 全面重构（「纸与桃」v2）

### 1.1 设计方向

frontend-design 技能加载后确定方向：**温暖编辑风（warm editorial）**。Anthropic Cowork 页面的设计语言——暖米白底、赤陶橙单强调、衬线大标题、边框承担结构的细线卡片、药丸按钮、克制线性图标——与儿童睡前阅读的「安心、睡前、亲子」气质天然同构。全部无蓝光波长，不违背褪黑素红线（docs/21 §0）。

### 1.2 设计令牌（tailwind.config.js 全面重写）

- `paper` 100–300：#FAF9F5 / #F5F3EC / #EFEBE0（暖米白纸感三层）+ `border` #E5E1D5 / `border-strong` #D6D1C2
- `ink` 900/700/500/300：暖黑到浅灰四级文字
- `terra` 50–700：赤陶橙家族（#D97757 主强调，#C15F3C hover）
- `kraft` 300–500（牛皮纸黄装饰）、`moss`（低饱和橄榄绿成功色）
- 字体：`font-display` 衬线标题栈（Tiempos → Georgia → 思源宋体/宋体）；`font-kai` 楷体（预留阅读正文，语文课本标准字体）；圆角降档（xl=12px…4xl=28px）；阴影 `card`/`lift` 两档极轻
- index.css：纸面微渐变 + SVG 噪点纸纹颗粒（opacity 0.5、纯装饰）+ 赤陶焦点环 + `.bg-terra` / `.bg-terra-gradient` 工具类
- PWA manifest theme_color/background_color 换 #FAF9F5

### 1.3 组件层

- **TaButton**：药丸形，四变体（primary 赤陶实底 / ink 墨色实底 / secondary 细线描边 / ghost），触达红线不变（lg=64px，md=48px）
- **TaCard**：paper-200 + 细线边框 + 极轻浮起阴影
- **TaSheet / TaSticker / Loading / ErrorState / EmptyState / ChildTabBar**：全部亮色化；ChildTabBar 换用图标系统
- **icons.tsx（新增）**：26 枚语义化线性图标（Moon/MoonStar/Book/BookOpen/Shelf/Lamp/Star/Sparkle/Heart/Play/Pause/Chevron/ArrowLeft/Gear/Family/Search/Close/Check/Clock/Volume/Type/Palette/List/Shield/Compass/Plus/Minus），统一 24 视框、1.5 描边、圆头、currentColor

### 1.4 emoji 清零

全部 UI 按钮/图标位的 emoji 替换为图标组件：错误边界 🌙、夜灯 ✨、试听 ▶/■、朗读 ⏸/🔊、听词 ▶、金句 ⭐、讲什么 📖、图书 📖、成就 🕯️🔥📚、骰子 🎲、孩子选择 👧🧒（改首字头像）。e2e 依赖的可访问名称全部保留。

### 1.5 页面层

- 全局令牌迁移 269 处（特殊 case 优先的有序替换，含 BookShelf 头图/遮罩/内联色）

### 挖出并修复的缺陷

| # | 严重度 | 缺陷 | 修复 |
| --- | --- | --- | --- |
| A1 | **高（产品级死路）** | 出发屏对 cbf: 自研书显示「请爸爸妈妈在微信读书里找到这本」——自研书不在微信读书，M2 选书流/超时续读无进阅读器通道 | DepartureScreen 增 `onStartReader` 通道；ChildHome resolveBook 对 cbf: 前缀走内容域接口并携带 ContentBookDto；「开始阅读」直达阅读器 |
| A2 | 高 | 自研书书名解析错走微信书 info 接口（`cbf:xxx` 必 404）；且服务端 `{book}` 包裹未拆包导致出发屏书名空《》 | ChildHome 按 `cbf:` 前缀分流 + api.contentBook 拆包 |
| A3 | 高（隐私+稳定） | 孩子端选书流/就绪/出发屏裸渲染微信 CDN 外链封面 → ORB 拦截成 5 张坏图，且向第三方泄露孩子 IP | BookPicker/ReadyScreen/DepartureScreen 只挂载 `/api/` 本站封面，外链一律走本地 SVG 场景回退 |
| A4 | 中 | BookDetail 吸底渐变引用不存在的 `night-bg` 令牌，渐变静默失效 | 换 paper-100 渐变（重构中一并修复） |
| A5 | 中 | 阅读器朗读主按钮紫色 #7E57C2、旧蜜桃渐变，离谱配色 | 赤陶纯色（重构中一并修复） |
| A6 | 低 | 视频探测路由对新场景回 404 打进 console 噪音 | 无记录回 `200 {status:'none'}`，前端静默回退 |

e2e 断言更新（原先假设无 AI 媒体）：封面/插图断言接受 `img[src*="/api/media/art/"]、svg[data-art]、video[src]` 三种形态（红线是「不得空白」而非「必须是 SVG」）；家长端选中态断言 `bg-peach-gradient` → `bg-terra`。
