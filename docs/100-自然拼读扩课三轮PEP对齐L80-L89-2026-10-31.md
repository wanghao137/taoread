## 缺口分析 → L80–L89（10 课 29 词 2 新映射）

对照安装词表（241-29=212）与 PEP 三上-四下词簇，缺口=辅音簇（bl/gl/tr/pl/sk/nd）、
长音 ue /uː/（g-ue 是 huge/cute 的 /juː/，不能混）、软音 g、双音节闭音节、天气 -y、人物弱读 er、
身体 th。纯应用课沿用 L60 先例（辅音簇拆单字母映射）。新增映射：g2（g=/dʒ/）、ue2（ue=/uː/，词尾）。

| 课 | 内容 | 词 |
|---|---|---|
| L80 | 开头的 bl/gl | black, glad |
| L81 | 开头的 tr/pl | trap, plum, plane |
| L82 | 结尾的 sk/nd | desk, hand, sand |
| L83 | 长音 ue2 | blue, glue, true |
| L84 | 会变声的 g | gem, page, cage |
| L85 | 双音节闭音节 | pencil, picnic, pancake, insect |
| L86 | 天气词（-y） | windy, cloudy, rainy |
| L87 | 人物词（弱读 er） | farmer, father, cooker |
| L88 | 小应用 | sheep, window, snowy |
| L89 | 身体词（th 轻音） | mouth, tooth |

**设计纠错记录**（校验器拦下的真错误）：拆分字素标记 `ae!` 只支持"词尾 e"（baker 的 e 后还有 r
→拼写对不上→换 cooker）；g-ng/g-ll 是 final 位置映射（singer/yellow 中缀冲突→换 cooker/snowy）；
desk/hand/sand=CVCC、insect=VCCVCC、snowy=CCVV 等形状表逐一修正。
