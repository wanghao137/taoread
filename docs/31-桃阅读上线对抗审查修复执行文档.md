### R-01 [P0] 家庭注销的端到端删除语义

### R-07 [P1] 依赖漏洞、浏览器安全策略与会话存储

**证据** `S+P`：本轮锁文件生产依赖审计报 6 项（4 high、2 moderate）：`@fastify/static`、`fastify`、`find-my-way`、`glob`、`react-router`、`react-router-dom`；不是生产已利用证据。`apps/server/src/app.ts:89-93` 只显式设置 `Referrer-Policy`；匿名线上 HTML/API 的有限采样未见 CSP/HSTS，需要复测 CDN/Tunnel 实际响应。`apps/web/src/stores/session.ts` 将 token 持久化到 localStorage，属于 XSS 冲击面，不等于已证实 XSS。

**实施** 获取最新锁文件、公告、可达性、修复版本和破坏性差异；Fastify/Router 主版本升级拆为兼容性变更，禁止盲跑 `npm audit fix`。核对所有入口（HTML、静态资源、API、媒体、错误页）在 Cloudflare 与源站的最终头部；设计 CSP（先 report-only，再收紧 nonce/hash/allowlist）、HSTS（确认所有子域与 HTTPS 再考虑 includeSubDomains/preload）、nosniff、frame 限制与缓存/权限策略。排查本地 token 暴露、第三方脚本、XSS sink、登出及设备撤销后的残留，提出 HttpOnly cookie 或现有方案的风险/迁移设计；不得无评估改 auth 契约。

**测试/验收** 锁文件审计输出与每项处置理由，零未解释 high；路由/静态/登录/上传/媒体票据回归测试；实际边缘响应头采样与 CSP 违规监控，不破坏阅读、TTS、图片、视频。双家庭越权、过期/撤销 token 和 XSS 基本路径专测。**回滚** 依赖变更保留锁文件和迁移兼容性；头部按策略可独立撤销，HSTS 长 max-age 不可立即收回，故先短 TTL 灰度。

### R-08 [P1] 恢复 lint 发布门禁

**证据** `S`：本次 `npm run lint` 在 `apps/web/public/sw.js` 六处 `no-undef` 失败，使 `npm run verify` 不能作为绿灯；其余修复前单项检查的通过不替代全链路验证。

**实施** 识别 service worker 环境全局、作用域与 ESLint 配置，局部声明/配置准确的 worker globals；检查 SW 的更新、离线缓存、旧版本清理与敏感 API 缓存策略。不要把整个文件排除或全局关闭 `no-undef`。

**测试/验收** `npm run lint`、`npm run verify` 全绿；浏览器测试 SW 首次安装、刷新升级、断网阅读与重联网，验证不会跨家庭缓存授权响应或保留注销后的敏感内容。**回滚** 局部 lint 配置可回退；若 SW 缓存契约变更，必须有旧客户端升级验证。

### R-09 [P1/P2，先测量] 性能、容量、可观测与灾备

**证据** `P+U`：当前仅有匿名首页少量 TTFB/页面采样；尚无足以声称 Core Web Vitals、登录后完整旅程、低端机、冷缓存、并发容量和真实 RPO/RTO 达标的数据。生产记录称 R2 每日备份、RPO ≤24h、RTO ≈1h，但整机恢复未在本轮独立演练；生产日志为追加方式，轮转仍需确认。

**测量计划** 在批准的低风险窗口用生产匿名页与隔离登录态各测冷/热缓存：导航、登录、首页、书架、长书章节切换、插画/视频、TTS、进度保存；在 320/390/桌面与中低端手机采集 LCP/INP/CLS、资源大小、long tasks、请求瀑布和 p50/p95 API 延迟/错误率。先定预算与目标（建议 LCP≤2.5s、INP≤200ms、CLS≤0.1 作为体验参照，现场按实际分布定阈值），记录网络/设备/区域/缓存；不把合成跑分等同真实用户指标。SQLite 测查询计划、WAL/锁等待、备份期间延迟和容量；真实上游仅在授权的预算和隔离家庭下测，不在负载测试中计费。

**优化/验收** 每个瓶颈给基线、触发链、最小优化、相同条件对照及回归测试；覆盖缓存键/隐私边界、懒加载、图片尺寸/格式、视频自动播放、无障碍降级、错误与超时。建立无敏感字段的错误率/延迟/备份成功及容量告警。隔离环境演练任意日快照+媒体+密钥恢复、服务/隧道自动启动，测实际 RPO/RTO；验证备份失败不会报成功、磁盘/日志增长有上限。**回滚** 每项优化独立开关或可回退，性能回归/缓存串户即终止发布。

### R-10 [P0 发布决策，U] 内容权利、儿童体验与生产运营

**验收** 每项有负责人、日期、真实设备/地区、录屏/日志（脱敏）、结论与阻塞项；未完成的内容与渠道明确限制可见范围。**回滚** 建立单书/单功能撤下、供应商熔断和服务回退的可执行演练，不能以删真实家庭数据代替回滚。
