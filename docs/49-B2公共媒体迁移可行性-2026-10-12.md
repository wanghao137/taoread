# B2 公共媒体迁移可行性

2026-10-12 核查。用户已授权 R2 语音压缩，随后明确要求“严格认真完成迁移”。当前实施范围为全部公共音频迁至独立私有 B2 桶，通过独立 Worker 提供访问；图片继续使用 R2。实施进度见 docs/50。迁移必要的上传、Worker 发布及音频地址切换已获授权；Git 提交/推送不在授权范围。

## 结论

**容量和上传工具链可行，9,681 个音频已上传；当前未付费账户的每日读取上限使冷音频返回错误，尚不能作为生产音频入口。** R2 压缩已将实际账户容量降至 9.463 GB，线上继续使用 R2。用户没有信用卡，本轮没有绑定支付方式、购买套餐或提高收费上限。

迁移是可实施方案，尚未完成公共访问、缓存、Range、浏览器及真实运营商网络验收。是否保持零费用还需核实 B2 全账户其他桶、现行账户 Caps、Cloudflare 当前 Workers 用量和 DNS/Worker 权限。

## 1. B2 实际状态

当前 `.env.backup` 使用 `s3.us-east-005.backblazeb2.com` 的 `taoread-backup` 桶。

| 统计口径 | 对象/版本数 | 实际字节数 | GB |
| --- | ---: | ---: | ---: |
| S3 当前可见对象 | 9,235 | 2,971,004,637 | 2.971 |
| Native API 包含历史版本 | 9,286 | 3,009,188,089 | 3.009 |

历史版本比当前列表多 38,183,452 字节。桶类型为 **allPrivate**；生命周期规则为空。当前可见对象包含：

- `media-archive/`：4,330 个，1,422,509,385 字节。
- 旧 `media/`：4,881 个，1,356,073,345 字节。
- `db/`：13 个，180,023,296 字节。
- `recovery/`：11 个，12,398,611 字节。

旧 `media/` 与归档层占用了两份空间，但本轮不删除它们；删除前需要逐条证明历史恢复点均可从归档层重建。容量够用时，迁移不应同时混入历史备份清理。

凭据限制在 `taoread-backup`，虽包含若干桶/文件管理能力，却不能列出全账户其他桶：不带受限 bucketId 的 Native list-buckets 返回 401，指定该桶后成功。**因此 3.009 GB 是已核实备份桶容量，不是已确认 B2 全账户总容量。** 新媒体桶应使用独立权限和凭据。

当前最新恢复清单实际 GET 返回 200，下载 1,177,233 字节，JSON 有效，完整请求约 3.5 秒。这证明本次读取可用；不是完整恢复演练，也不是公共音频冷缓存首字节速度测试。

证据：`output/r2-audit-20261012/b2-current-inventory.json`、`b2-version-inventory.json`。

## 2. 当前官方免费规则

本日重新读取 Backblaze 官方 pricing 与 transaction-pricing 页面：

- 前 **10 GB 存储**免费，按账户而非按桶划分。
- 普通 Pay-as-you-go 当前列 **A/B/C 类 API 请求免费**；S3 GET/HEAD 属 B，列表属 C。
- D 类事件通知为前 2,500 次/天免费，超过后收费。
- 普通出网每月免费到月均存储的 3 倍，超过部分定价；通过包括 Cloudflare 在内的指定 CDN/计算合作方可免费出网。
- 官方 pricing 主页面当前列超额存储从 $6.95/TB/月起；transaction-pricing 页面附注仍残留 $0.005/GB/月，存在页面数字不一致。涉及超额预算应以账户和主定价页面确认，不将旧附注默认为当前报价。

**随后实际后台和调用结果修正了初步判断：普通 Pay-as-you-go 定价不能当作未付费账户无调用限制的证明。** 本账户后台仍显示 B/C 类各 2,500 次/天、下载 1 GB/天和存储 $0/10 GB；修改上限要求先绑定付款方式。上传校验消耗读取后，B2 GET 返回 403 AccessDenied 并明确指出读取额度超限。Cloudflare 冷 Range 同样返回 502；已缓存样本可读不代表未缓存文件可用。证据详见 docs/50。免费合作出网不等同于取消每日请求上限，不能承诺通过 Worker 绕过。

Cloudflare Workers Free 当前列 **100,000 次请求/天、10 ms CPU/次**。Worker 缓存命中仍计入请求量；存储充足不代表 Worker 请求量无限。API Cache 是边缘机房本地缓存，不自动跨机房复制；Range 的缓存处理也必须实现并测试。

## 3. 容量模型

以下以备份桶 3,009,188,089 字节为基线。随后完整后台核实账户仅有备份与音频两个桶，Native API 计入全部历史版本；全量音频上传后账户实际为 6,328,411,720 字节。R2 压缩精确释放 1,230,124,028 字节，全账户重清点为 9,462,983,732 字节。下表的 R2 迁移后值仍是预测，源文件尚未删除。

| 方案 | B2 已知合计预计 | R2 剩余预计 | 判断 |
| --- | ---: | ---: | --- |
| 未压缩，整个桃阅读媒体迁 B2 | 9.070 GB | 4.632 GB | 接近 B2 免费线，未来增长余量不足 |
| 九部新书压缩后，整个媒体桶迁 B2 | 7.840 GB（7,840,128,872 字节） | 4.632 GB | 已知容量可行，约 2.160 GB B2 余量 |
| 九部新书压缩后，只迁公共语音 | 6.328 GB（6,328,411,720 字节） | 6.144 GB（6,143,760,101 字节） | B2 余量更大，需独立语音域/基址配置 |

按长篇正文扩库继续增加，B2 也迟早逼近免费线。应同时保留上传前预算、计入旧版本、保持合理版本生命周期，不能只把容量问题换一个服务商。

## 4. 推荐实施路径

### 阶段 A：当前减容

已完成九部新书 64 kbps 转码、R2 完整 GET 核对、生产清单更新和全账户容量复验，R2 实测降至 9.463 GB。独立 CDN 的 3 个完整文件/Range 样本也已通过。浏览器交互播放仍因 webview 连接失败而未验证；B2 临时域灰度时必须补足真实播放和主观音质验收。

### 阶段 B：独立媒体桶与临时域验证

1. 核实 B2 账户是否存在其他桶/历史版本及当前 Caps；确认整体容量预算、Cloudflare Workers 剩余配额、域名当前全部相关配置及变更权限。
2. 新建独立私有公共素材桶。备份桶继续私有，不改变备份任务；生成“写入媒体桶”与“Worker 只读媒体桶”两种最小权限凭据，Worker 只读密钥放 Secrets，不进 Git、清单或日志。
3. 在临时验证域部署 Worker；只允许媒体桶中已获发布许可的 `art/`、`tts-public/`，拒绝桶列表、`db/`、`recovery/`、家庭私有路径、任意上游地址和路径越界。Worker 绝不持有备份桶读权限。
4. 全量上传前锁定当前媒体清单，保留 key、Content-Type、Cache-Control、大小与源 SHA256；只同步可公开资产。保留当前上传失败不推进索引的语义。
5. 上传后用列表和完整 GET 对账；不是只看上传返回 200。Native API 计入历史版本，不把 S3 当前列表当计费总量。
6. 保留音频 Range/HEAD/206/Content-Length/Content-Type/CORS 的正确语义，缓存完整 200 响应，再按 Range 返回；不能把 206 直接写入 Cache API。正确隔离带鉴权的上游请求与可公开缓存的响应。

### 阶段 C：灰度与切换

- “整个媒体桶迁移”可沿用当前 `TAO_MEDIA_PUBLIC_BASE` 和对象路径，临时域验证后再切当前公共媒体域；应先排查 R2 自定义域当前绑定和 Worker Route/Custom Domain 关系，不覆盖主站 DNS。
- “只迁语音”增加独立公共语音基址，图片继续使用原 R2 域；改动集中在公共语音 URL 的生成与上传配置。不要为了语音迁移让所有图片多走一层路由。
- 参数化 `pregen-tts.mjs`、`sync-media-r2.mjs`、`sync-classics-release.mjs` 和自动图上传的目标；迁移期间不能出现“URL 指向 B2，但后台仍只上传 R2”的断链。
- 同一内容与素材哈希在新旧域对照；验证九部新书、旧中文、英文、短诗，以及所有尾段完整结束。使用真实浏览器检查起播、暂停/继续、切段、进度拖动、图片、手机横竖屏。
- 先做限定请求灰度，实测多地区/运营商冷、热缓存延迟及错误率，至少与当前 R2 基线比较。当前 B2 直连清单下载时间不能替代 CDN 灰度结果。

### 阶段 D：观察和旧 R2 清理

保留旧 R2 媒体 7 天供回滚；压缩后 R2 已低于免费线，观察期不需要立即删除旧桶。完整读取、缓存、容量和业务验收通过，且用户确认迁移收尾后，才按冻结清单清理迁走的旧对象。不能按“现在未被访问”删除。

迁移前保留旧环境值、Worker 路由/DNS 基线、对象清单与 SHA256、新旧桶恢复核验记录。回滚只恢复媒体 URL/路由和上传目标，保留真实家庭数据与后续阅读操作，不回退数据库。

## 5. 当前决策

公共音频全量复制已经完成，存储在免费容量内；**生产切换被真实冷读取失败阻断**。无需信用卡的剩余完整校验可按每日免费额度分批续验，但仅验完文件不能解决日后冷缓存读取上限。当前不能把该未付费 B2 桶直接认定为可靠的生产音频源。不得通过公开备份桶、自动绑定支付或缓存成功样本来掩盖限制。

本文件记录调研阶段的容量和方案；后续用户已明确授权迁移。新音频桶已由用户创建，实际上传、发布、切换和验证以 docs/50 的证据状态为准。
