### 1.5 儿童动效（用户要求①②）

`apps/web/src/lib/motion.ts` —— 12 条预设 + `useReducedMotion` hook + `reducedAware` 降级工具：

| 落地点 | 效果 |
| --- | --- |
| TaoMascot 吉祥物 | 呼吸（2.8s 周期，3% 幅度），全产品 IP 「活着」 |
| 书架卡片 | 错峰进场（60ms 间隔，8px 淡入上浮） |
| 封面插画 | Ken Burns 极慢摇移（14s 周期，6% 缩放 + 3% 平移） |
| 阅读器翻页 | 方向感：下一章从右进、上一章从左进 |
| 弹层抽屉 | 底部滑入 + 0.97 缩放 |

研究依据（写在代码注释里，review 可核）：Kirkorian & Anderson 2018 眼动追踪（3-8 岁注意力被运动等低级显著性捕获，而非被理解引导）、Reich, Yau & Warschauer 2016（增强型电子书的无关动效分散对文字的注意、降低学习）。由此推出 6 条硬约束（时长 200-500ms、位移 ≤8px、缩放 ≤6%、循环 ≥2.4s、easeOut 缓动、翻页方向暗示），8 条单测守护。

> **引用诚实性修正**：早期版本曾把「慢」归因于 Lillard 2011（快节奏动画损害 4 岁执行功能）。同一实验室 2015 年的后续研究（Lillard et al., N=300，三组实验）因子式分离了节奏与幻想性，发现**只有幻想内容影响 EF，与节奏无关**——2011 年的结论不能外推到 300ms 的界面转场。规范已改用上述两项依据，并在 `motion.test.ts` 里留了一条守卫断言，防止该归因被重新写回。

**P1-C 安静模式**（动效可及性的收口）：

学前儿童找不到操作系统的「减少动态效果」开关，`prefers-reduced-motion` 这条 WCAG 2.3.3 要求在儿童产品里只能通过应用内开关落地。因此新增家庭级开关：

- `Family.calmMode`（迁移 `20260918000000_calm_mode`）
- `PATCH /api/family/:id/settings`（家长专写）；`GET` 对孩子角色开放——这是开关在孩子设备上生效的唯一路径
- 家长设置页「安静模式 / 保持活泼」两选一，写入会话 store 后本机 `MotionConfig` 立即切到 `reducedMotion="always"`
- 庆祝屏的弹簧与错峰动画原本绕过了 reduced 分支，已补齐门控
- 孩子端 App 启动时拉一次家庭设置写进会话 store（拉取失败不阻塞进应用）

## 3. 实施中的判断修正

1. **Prisma 不支持块注释 `/** */`**：schema 里写文档注释只能用 `///`，块注释会触发 P1012 校验错误。
2. **`Book.words` 字段名冲突**：Book 已有 `words Int`（字数统计），新关系改名 `wordCards`。
3. **迁移而非 db push**：测试库走 `prisma migrate deploy`，`db push` 不生成迁移文件，测试库拿不到新表 → 用 `migrate diff` 生成迁移 SQL 再 deploy。
4. **e2e 数据污染**：新增的阅读器测试若不收尾活动会话，会污染后续家长端「今晚还没开始」断言与视觉终扫的门屏 → 每个进阅读器的用例都必须走完收尾流。
5. **aria-label 与按钮文本**：Playwright `getByRole('button', {name})` 匹配的是 accessible name（aria-label 优先），按钮可见文本变化不会改变 name → 状态断言要用 `toContainText`。
6. **dev.db 与 test.db 的迁移分叉**：dev 库早先用 `db push` 同步过 schema，补迁移时会因「表已存在」在 `migrate deploy` 里留下 failed 记录（P3009），新迁移被卡住。正解是 `migrate resolve --applied <name>` 把已存在的标记为已应用，而不是反复重放。
7. **Playwright 配置不在根目录**：`npx playwright test` 只在 cwd 找配置，仓库根没有 `playwright.config.ts`，必须 `--config e2e/playwright.config.ts`，否则静默退回默认配置（baseURL 丢失，报「Cannot navigate to invalid URL」）。
