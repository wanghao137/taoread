# 84 · APK 根修（远程壳 0.1.6）+ 《阿凡提的故事》（2026-10-25）

## 1. 「APK 每日一诗还是不对」—— 真正的根因（两个实锤）

用户在 APK 上反馈夜间诗词卡 bug 仍在。web 侧已三层核查无误，差异必在壳层。
取证：

1. **APK 打包的 capacitor 配置没有 `server.url`**——APK 加载的是**打包日
   （10-18）的本地 web 快照**（CSS hash `index-BLIX-1eQ.css`，旧版）。
   此后所有 web 修复（夜间七修、诗词卡夜景）APK 用户**全部不可见**。
   （memory 里「APK 远程轻壳」的说法与实际不符——远程壳只停在设计上。）
2. 壳主题无 Force Dark 声明：`DayNight` 主题 + API 29+ = 系统深色时
   WebView 对亮色页面**算法强制暗化**（位图与颜色被算法处理），即使网页
   自己有正确的暗色 CSS 也会被二次加工。
