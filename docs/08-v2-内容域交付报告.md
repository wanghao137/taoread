## 2. 三项需求达成方式

### 2.1 图文并茂（UI 儿童审美）
- 书架每张书卡必带封面插画；阅读器章节题图 + 正文插图 + 小贴士插图三层。
- 插图全部为**项目内原创 SVG**（30 场景：月窗、花果山、水帘洞、瀑布山林…），确定性伪随机排版，随阅读器主题换色。
- 无光栅图片生成依赖：本环境无图像生成 API key，且矢量方案**零版权风险**，矢量缩放无锯齿。
- **回归守卫**（`e2e/demo-content.spec.ts`）：书卡封面 `svg[data-art]` 必须存在；诗章题图 `moon-window` 必须渲染；故事章插图 ≥2 处；朗读栏高度不得超过正文容器底部留白（防遮挡末行）。

### 2.2 书籍内容（故事/古诗/英文）
| 书 | 语言 | 类别 | 分级 | 版权台账 |
| --- | --- | --- | --- | --- |
| 三字经·人之初 | zh | 蒙学 | 3-5 | 原文 + 拼音注音，pd-70 |
| 唐诗三百首·星星篇 | zh | 古诗 | 3-5 | 原文 + 拼音 + 译文，pd-70 |
| 西游记·美猴王出世 | zh | 故事 | 6-8 | 平台改写本（adapted），吴承恩 pd-70 |
| 刻舟求剑 | zh | 故事 | 3-5 | 平台改写本（adapted） |
| Alice in Wonderland | en | 童话 | 6-8 | Gutenberg #11 逐字，pd-us |
| Peter Pan | en | 童话 | 6-8 | Gutenberg #16 逐字，pd-us |
| Grimm's Fairy Tales | en | 童话 | 9-12 | Gutenberg #2591 逐字，pd-us |

- 英文文本为 Project Gutenberg 实测可达（pg11/pg16/pg2591 均 HTTP 200）后逐字收录；中文经典为原文/注音或明确标注的改写本。
- 每本书一行 `RightsLedger`（workTitle/author/authorDeathYear/translator/jurisdiction/basis/sourceUrl），「only public-domain or self-authored」红线可审计。
- 分级过滤：stageRank {3-5:1, 6-8:2, 9-12:3}，孩子只见 rank ≤ 自身阶段的书（3-5 岁看不到西游记，单测覆盖）。

### 2.3 拟人化 TTS 听书
- 语音优选评分：神经网络系（Google/Microsoft/晓晓/云希/Siri/natural）+100，语言匹配 +50，`local|standard|default` −20；无可用语音时温和降级，不阻塞阅读。
- 分句队列（`。！？；` 等切分，超长句二次切分），句间 90ms 停顿，模拟自然讲话节奏；中文默认 rate 0.92 / pitch 1.05。
- 朗读时当前句卡拉OK 高亮（SpeechSynthesisEvent boundary 回调），正文与语音同步。
- 底部悬浮朗读栏：朗读/停止、声音选择器（「自然语音」徽标）、不可用提示。

### 本轮修复的真实缺陷
1. **跨测试会话污染**：demo-content「西游记」用例点「读完啦」开出 cbf 共读会话却未收尾，后续视觉用例的月亮门变成续传卡。修复：该用例走完整收尾闭环（进度+心情+盖章→庆祝），既关掉会话又补上 cbf→收尾路径覆盖。
2. **阅读器退出回不到书架**：阅读器非读完退出原来回到月亮门，现回到桃书架。
3. **章节目录只显示当前章标题**：其余章只渲染「第 N 章 ·」，现加载全量标题列表。
4. **悬浮朗读栏遮挡顶栏返回按钮**：顶栏提 `z-20`。
5. **reports 单测日期 bug（预存）**：种子数据用 now() 但过滤 9/7 周，显式指定 createdAt 后修复。

## 4. 安全与红线复核
- 无 key 进源码/进库：本轮新增与改动文件已扫描（`sk-*`/`AKIA*` 模式零命中）。
- 内容全部公版或自研改写，版权台账逐书可查；未使用任何逆向私有接口的内容。
- 儿童文案无焦虑诱导：无正文分发、无积分商城、无断签惩罚、无孩子推送、无广告。
- deepLink 仍只消费网关返回值，内容域阅读器本身不需要 deepLink。
