# 桃阅读：零新增预算的子域名部署研究与开发接管

日期：2026-09-23。工作区：`D:\codesolo\taoread`。这是研究与实施边界，不表示已经改 DNS、开通云资源或发布。旧文档 `docs/29-线上部署方案-read.taostudioai.com.md` 使用付费 VPS，不能作为零预算执行方案。

## 当前结论

首选条件方案：**已有可常开的机器 + 本地 SQLite/媒体 + 同源静态站 + Cloudflare Tunnel**，域名 `read.taostudioai.com`。若无常开机器，零预算不能承诺完整、稳定的家庭数据服务；可先做免费的静态预览，但它没有持久 API、家庭账户、阅读进度、私有媒体等完整产品能力。主域 `taostudioai.com` 当前如何管理 DNS、是否已在 Cloudflare、现有机器与网络/电费承担情况，尚未获得账户级核验。

仓库服务端是持续运行的 Node/Fastify、SQLite 文件、磁盘媒体以及周报调度；前端是 Vite 构建产物。它不适合原样搬到无持久盘的静态站或按请求启动的免费函数。旧部署文档记录媒体约 1.7 GB、3321 文件，须在正式迁移时重新测量。当前 `src/index.ts` 已支持 `TAO_HOST`，默认 `127.0.0.1`；通过 Tunnel 时服务端保持本机监听，只允许反代访问。当前媒体票据在 URL 中，即使仅五分钟也可能被代理日志记录；需要边缘日志脱敏、全站 `Referrer-Policy: no-referrer`、短时效与会话撤销验收。

## 条件 A：自有常开机器与 Cloudflare Tunnel

1. 先确认 DNS 权限及主站现有全部记录（A/AAAA/CNAME/MX/TXT/CAA），不要为新增子域名贸然迁移根域 NS；若域名已在 Cloudflare，可在现有 zone 创建 Tunnel 并为 `read` 配 public hostname。若 DNS 在其他服务商，先评估 Cloudflare 的接入方式、现有站点/邮件迁移风险与是否必须切 NS；仅有免费 Cloudflare 账户不等于已有域名可直接使用其 Tunnel hostname。
2. 常开主机运行一个 Fastify 实例、SQLite 和媒体文件；反向代理按 `/api/*` 转到本地端口，其他路径服务 `apps/web/dist` 并回退 `/index.html`，Tunnel 仅连本地代理。服务进程可重启，SQLite 与媒体放同一持久卷并定期离机备份。主密钥单独安全保存，不写文档/仓库。
3. 部署前执行数据库备份与恢复演练、媒体清单校验、权限和日志检查；先在测试子域名验证注册/进度/屏蔽/家庭媒体/撤销、360–390px 手机、离线与浏览器朗读。最后才改 `read` DNS。不得假定家用机器的稳定性、供电和上传带宽，也不得称“零成本”：域名续费、设备、电费和网络已由用户承担。
4. `.env` 的生产最小值：`NODE_ENV=prod`、强随机 `TAO_MASTER_KEY`、`TAO_DATABASE_URL` 指向持久路径、`TAO_ALLOWED_ORIGIN=https://read.taostudioai.com`；AI 图像/视频/TTS 的 base/key 保持未配置，避免供应商费用。已有 BYOK 微信读书绑定仍由用户自行授权，网络/API 可用性须单独验证。
5. Cloudflare 免费服务有产品限制和公平使用条款，应以实际控制台、合同及流量形态复核；尤其大规模视频/媒体转发不能在未核条款前承诺免费无限量。Tunnel 是传输通道，不提供应用持久存储或备份。

## 条件 B：Always Free VM

Oracle Cloud Always Free 文档列出可用的计算与块存储额度，能承载 Node+SQLite+媒体的可能性较高，但注册可能要求银行卡验证，资源受区域容量、实例形态、闲置资源回收和额度/政策约束。不能保证申请成功、长期零费用或现有媒体必然装得下。只有在用户接受注册和额度风控，并完成私有测试后才作为备选；须监控账单与资源，禁止自动升级付费规格。

## 条件 C：免费静态预览

Cloudflare Pages 或现有 Vercel 账户可部署 `apps/web/dist` 和自定义子域，但需要一个可用、持久的后端。纯静态预览只能展示明确标注的演示内容，不能让用户以为真实家庭信息已保存。Vercel Hobby 的用途/额度限制需对照项目实际用途核查。不要把前端能打开当作全栈上线。
