- **新增阻断缺陷：跨家庭媒体 scene。** `apps/server/src/modules/media/artRoutes.ts:107-109` 和 `videoRoutes.ts:59-61` 中，任何客户端提交以 `fam:` 开头的 scene 都被原样接受；家长 A 可提交 `fam:<家庭B ID>:...`，绕过自身前缀。插画 `artRoutes.ts:135-145`、视频 `videoRoutes.ts:148-160` 的 GET 只鉴权、不核对 scene 与家庭；视频 GET 后续还会查询上游并回填。`/api/media/*`（`modules/media/routes.ts`）无鉴权且返回永久 public 缓存。由代码逻辑可确定前缀与读权限未隔离；未对真实供应商做越权调用，不断言已发生真实泄漏。修复时同时检查已有恶意/历史 `fam:` 记录和缓存 URL。
- **旧家庭迁移阻断：** `lib/auth.ts:88-90` 拒绝所有无 sid 的旧令牌；`family/service.ts:96-100` 旧家庭 `parentCode=null` 时家长无法凭第二码重新加入；`getParentCode` 仅供仍有效家长会话调用。已有家庭若无有效新家长会话，可能永久失去家长控制。交付 T02 也承认缺口。上线前给出经验证的旧家长恢复通道，不得凭儿童码自动提升。
