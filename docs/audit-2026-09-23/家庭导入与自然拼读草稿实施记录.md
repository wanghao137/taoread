# 桃阅读：家庭导入与自然拼读草稿实施记录

日期：2026-09-23。状态：本地开发闭环；尚未发布到线上，不代表教学课程或版权审签完成。

## 已实施（代码可核查）

- 数据模型：`ImportedBook`、`ImportedChapter` 单独存家庭私有正文；`PhonicsEnrollment`、`PhonicsAttempt`、`PhonicsResponse` 独立存试点数据。迁移见 `apps/server/prisma/migrations/20260923130000_imported_books_phonics_draft/migration.sql`。没有把导入正文混入全局公版 `Book`。
- 家长端内容中心：选择本地 UTF-8 TXT（512 KiB 上限）、录入书名/作者/语言/适龄、确认家庭阅读使用权、导入/去重/列表/删除。章节按“第…章”或 `Chapter N` 标题解析，最多 80 章、每章最多 30k 字。导入书只能在本家庭查看；孩子查询需携带同家庭档案 ID，按档案年龄段过滤正文。孩子端家庭书架可选章节并阅读私有文本。当前独立阅读页无共享书库的听读、书签、进度、收藏、共读等能力。
- 自然拼读：默认关闭，家长对每个孩子单独开启。当前仅一课 `s/a` **字形辨认**草稿，API 提供目录、尝试/作答、暂停/结束与汇总；目录不下发标准答案；重复请求保持幂等。孩子端有可选试题页。**不提供标准发音音频、音素教学或掌握度结论；不能称为完整自然拼读功能。**
- 对用户提到的资源聚合项目和 Z-Library 未接入任何自动抓取、下载、镜像或正文导入。用户本地合法持有文本由家长确认后直接进入私有库；这个确认不能代替真实版权授权。EPUB/PDF 尚不支持。

## 验证边界

- 新增接口测试 5 项：角色权限、使用权字段、体积、去重、家庭/年龄隔离、删除级联、开关与答题重试。后端全量 327/327，前端全量 125/125，lint、类型检查、前端构建通过（构建有既有模块动态/静态导入提示）。
- 尚未在真实浏览器、手机、200% 缩放或真实书籍样本中核对视觉/阅读体验；未验证大批量电子书、文件编码以外的格式或多机并发写入。已在预建的独立 migration-trial-20260923.db 空库演练 11 条迁移并成功（该演练文件位于 apps/server/prisma，需保留供复核）；生产库迁移/备份恢复需另行演练。不可把自动测试通过解释为上线可用。

## 发布前剩余工作（依赖顺序）

1. 先处理旧家庭家长恢复与旧令牌迁移死锁、媒体历史缓存隔离、版权内容逐本审签、数据库与媒体一致备份及恢复演练。公开域名不应在这些阻断项关闭前开放。
2. 自然拼读交付八课经编辑审核的 GPC 顺序与词表、正确音素/合成音频和授权台账、音频逐条听审与校验和、读词/分音/可解码短文的版本化课程，教学人员审查并试点后才可发布。现有一课仅供家长明确开启的内部字形体验。
3. 导入支持 EPUB 时，在本地解析、清理 XHTML、限制压缩炸弹/外链/脚本，明确插图资产存储、章节大小与资源上限、家庭删除与导出生命周期。TXT 的独立阅读页补进度/续读及多端阅读体验。
4. 在不占用现有用户服务端口的隔离实例完成浏览器及移动端阅读/上传/暂停试点；修复发现的问题并复跑相关验证。生产独立库与媒体卷从备份可恢复后再执行 Tunnel 公共 hostname。

## 零新增预算部署建议

保留本机 SQLite 和媒体文件，本机 Fastify 仅监听回环地址，经本机同源反代提供 `/api/*` 和静态 SPA，再由 Cloudflare Tunnel 发布 `read.taostudioai.com`。详细拓扑和核验门槛见 `Windows常开电脑-CloudflareTunnel上线清单.md`。不需要 Supabase，也不应在本机持有真实供应商付费密钥来满足首版。现有 cloudflared 服务可能还承载其他站点，必须先盘点它所属 Tunnel 与 `read` DNS 记录，不能覆盖主站或服务。生产域名、DNS、Tunnel 与数据库本轮均未改动。
