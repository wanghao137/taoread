# word-atlas 深度研究与自然拼读开发方案

日期：2026-10-26。性质：研究与方案建议，未修改产品代码与课程内容。

研究对象：[designfuchen/word-atlas「词光」](https://github.com/designfuchen/word-atlas)（MIT 代码 / CC BY 4.0 内容，1039 star）。本研究拉取并通读了其全部 72 个源码与文档文件（`src/`、`scripts/atlas/`、`docs/`、数据集 schema），核心学习逻辑（`srs.ts`、`store.ts`、`session.ts`、`gen_text.py`、`gen_word_audio.py`、`check-atlas.mjs`）逐行读完；37,584 个媒体资产未逐一检查。本地镜像在 `D:/codesolo/_research/wa-src/`。

## 1. 词光是什么，它做对了什么

词光是一个**成人自学**雅思词汇工具：7,298 词、一词一画、英美双音、14,596 例句、FSRS 间隔复习，纯前端静态站，无账号无后端，进度存 localStorage。一句话概括它的做法：**把"看过"变成"想得起来"，靠的是主动回忆 + 在快要遗忘时重逢（FSRS-6）+ 双编码增强（图+句）**。

它的工程质量确实高，但高在四个非常具体的地方：

1. **内容生产是管线，不是手工作坊**。五步脚本链（词头 → LLM 按严格编写规范生成词条 → 图像模型按统一画风画场景 → ElevenLabs 合成英美音 → 编译切块），全程断点续跑，最后有独立校验器查结构、引用和媒体存在性。7,298 个单元的一致性来自"统一规范 + 机器校验"，不是来自人力。
2. **学习编排有明确的第一性设计**：先复习（注意力新鲜时）再新授；新词 5 个一组"先初见、再打乱回忆"（interleaved retrieval）；题型按记忆阶段分配（新词认图认义，稳定了才拼写）；干扰项按认知学构造（听音/看图题加"首字母相同+长度相近"分，选义题加"同词性+同难度"分）。
3. **诚实的计分**：每个词每轮只有第一次作答更新记忆；答错的词在 4 步之后换一种题型重练（最多两次），重试不评分、不计入正确率；用提示最多计 Hard；单步时长封顶 90 秒防挂机膨胀。统计不说谎。
4. **对质量边界诚实**。22,905 段音频全部 ElevenLabs 合成（英音 Alice、美音 Sarah），README 与 pipeline.md 明确声明：自动校验不覆盖语义正确性，插画和例句**没有逐条人工审校**。

第 4 点是理解"什么能搬"的钥匙：这套无审校快跑管线，建立在"成人自学、错了成本低、用户可自行发现错误"的前提上。桃阅读是 5–7 岁儿童教学产品，这个前提不成立。

## 2. 第一性原理：词光和自然拼读根本不是同一种学习问题

把两个产品放到学习科学的基本面上对照，结论就自然浮现：

| | 词光（词汇记忆） | 桃阅读自然拼读（解码技能） |
|---|---|---|
| 学习对象 | 词形↔词义的**陈述性联结** | 字素→音素映射的**程序性技能** + 音位意识 |
| 核心困难 | 记得快忘得快（遗忘曲线） | 技能需要大量变式练习才能自动化 |
| 有效手段 | 主动回忆、间隔重复、双编码 | 明确教学、合成/分音变式练习、可解码文本迁移 |
| 单次接触成本 | 5–10 秒一卡，每天 30–50 张 | 5–8 分钟一课，每天一课 |
| 反馈形态 | 对/错二值，机器可判 | 多维（独立/提示后/未观察），发音质量首期靠家长观察 |
| FSRS 适用性 | **完全适用**（这正是 FSRS 设计的对象） | **只适用于其中的知识性成分**：GPC 掌握保持、可解码词与 tricky words 的保持 |

这个区分决定了一切迁移判断：**词光的可复用资产是它的工程方法论和编排模式，不是它的领域模型**。把"词汇 SRS"整体套到拼读课上（复习对象=课），对象就错了；把它精确套到"GPC/词的保持"上（复习对象=target），对象就对了。

## 3. 桃阅读自然拼读的真实现状（本轮核实）

自然拼读已有首轮开发和完整工程链（docs/69–73），不存在"从零开始"：

- **课程**：8 课 GB 草稿（`taoread-phonics-gb-v1`），7 个 GPC（s/a/t/p/i/n/m）、16 词、71 任务、7 份阅读材料；用户已批准产品方向与 GB 英式口音（记忆中"等口音定稿"的阻塞已解除）。
- **数据模型正确**：mappings 用 spelling→phoneme(s) 带 accent 与位置条件；words 的 spans 精确到字符区间映射 GPC——已具备"字母数≠音数"的表达能力。
- **工程链完备**：版本化课程包、课堂状态机（entry/lesson/review/reread）、pilot 灰度、发布门槛（内容哈希/听审/权利/试点证据，`releaseReady` 门禁）、attempt 记录与幂等。
- **复习规则**：`support-and-1-3-7-v1` 确定式（未完成→声音游戏→7 天内帮助目标优先→1/3/7 天到期→新授），课粒度，每天最多一次复习。
- **真正的卡点只有一个工程问题**：孤立音素音频。stepaudio 合成的 p/n/m 纯音（3.3/6.2/3.7 秒、读成字词或拖泥带水）已被拒；prompt 已极限优化（"Output ONLY the isolated phoneme, stop has one brief clean release"）仍不行。加上教学签认、真机、家庭试点等人工验收未完成，`releaseReady=false`，课程未对家庭开放。

一个重要的旁证：**词光合成 22,905 段音频，全部是整词（加句号）和例句，从不合成孤立音素**。两条独立证据链（桃阅读的失败实验 + 词光的刻意回避）指向同一结论：孤立爆破音（/p/ /t/ /k/）没有可持续的声学内容，任何 TTS 合成孤立音素都不可靠。这不是 prompt 工程问题，是声学本质问题。

## 4. 逐项迁移判定

### 4.1 直接可迁移（代码/模式可近乎照搬）

| 词光资产 | 迁移方式 |
|---|---|
| ts-fsrs FSRS-6 封装（`srs.ts`，97 行） | 服务端复用（MIT 许可）。复习对象改为 GPC/词（targetId 粒度），参数按儿童调优（见 §5） |
| 首答唯一计分（`graded` map + retry 永不评分） | 对齐 docs/69 已有的"求助后不恢复首次独立正确"，补到课堂状态机的作答记录 |
| 错题换题型重练（4 步后插入、最多 2 次） | 桃阅读题型（字形/合成/分音/听音）同样支持换式重练；与 docs/69 的"答错再教学"合并：重练前先重听示范 |
| 干扰项打分函数（`distractors`） | 候选池从 7,298 词换成"已授 GPC 可构成的词"，打分逻辑（形近/首音同/长度近）原样适用 |
| "先复习后新授、新授 5 个一组初见→打乱回忆" | 与 docs/69 课堂链天然同构，作为 review+lesson 混合日的组排参考 |
| 单步时长封顶 | 防挂机/家长忘关页面膨胀统计，直接采纳 |
| 编写规范式 SYSTEM prompt（`gen_text.py`：严格 JSON shape、flag 机制、场景描述字段） | 作为 24 课扩产的"课程脚本生成规范"模板；教学内容另有审校层（见 §6） |

### 4.2 改造后迁移（方向对，参数/形态要改）

| 词光做法 | 桃阅读适配 |
|---|---|
| FSRS 评分 Again/Hard/Good/Easy | Again=独立答错；Hard=提示后答对（词光 hinted→Hard 与 docs/69"提示后完成"完全同构）；Good=独立答对；**Easy 首期不用**（避免儿童跳级）；correct=null（未观察）**不更新 FSRS**——这是与词光最大的不同，必须容忍未知 |
| request_retention 默认 0.9 | 儿童启蒙调高到 0.92–0.95（高保持、低挫败）；禁用 short-term learning_steps（1m/10m 是成人快速闭环），最短间隔=跨日，符合 docs/69"跨日再观察"原则 |
| localStorage 本地优先 | **不搬**。家庭/多孩/家长报告/防篡改要求服务端记录；现有 attempt 体系保留，FSRS card state 作为服务端新表（或复用现有记录聚合），随课程版本号绑定 |
| 词汇星图（WebGL 掌握可视化） | 不搬 WebGL；"掌握可视化"意象可远期做轻量拼读地图，非优先级 |
| uk/us 双口音管线 | schema 已有 accent 字段；GB 版本验收后，US 版本是"音频管线×2 + 词义情境复核"的量产问题，排批次 D |
| 五步生产管线 + 断点续跑 + 独立校验器 | 24 课扩产的骨架（见 §6）；媒体侧桃阅读已有 assets.json 台账，无需搬它的 index.json 位掩码 |

### 4.3 明确不迁移（附理由）

- **无账号、无审校发布**：儿童教学产品红线；发布门槛体系（听审/签认/权利/试点）是资产不是包袱，不放松。
- **IELTS 内容资产**：词表、释义、插画风格、22,905 段音频对 5–7 岁拼读教学**零直接复用价值**。词光对桃阅读的价值是方法论与代码模式，不是数据集——这点必须说透，避免"CC BY 4.0 可以随便用"的误判。
- **成人向交互仪式**（开屏仪式、环境声、打字工作室）：不符合 docs/69 定下的"不加主导航、贴纸绘本视觉体系"方向。

## 5. 建议一：用 FSRS 升级复习调度（对象=targetId，规则保留兜底）

现有 `support-and-1-3-7-v1` 方向正确但有两个精度损失：间隔固定（1/3/7 天，不随掌握度伸缩）；粒度是课（一课 4–9 个目标共享一次复习判定）。词光证明了 FSRS-6 在生产中足够简单可靠（97 行封装），升级方案：

1. **复习对象**：`{targetId, kind: 'gpc'|'word'|'tricky'}` 粒度（review.ts 已有 targetId=wordId/mappingId 概念，顺理成章）。
2. **评分来源**：只吃已有作答记录的"首次独立作答"（独立对=Good、提示后对=Hard、独立错=Again、未观察=不更新）。不新增任何前端交互。
3. **推荐规则升级为两级**：support 目标（7 天内收过帮助）仍最优先（保留现有教学判断）；其后到期复习按 FSRS due 排序取前 2–3 个目标组题；无到期才推新授。`REVIEW_RULE_VERSION` 机制已支持并存与回退（`fsrs-target-v1`，保留 `support-and-1-3-7-v1` 兜底）。
4. **可解释性**（docs/69 的硬要求）：推荐理由直接输出 due 与稳定度的人话版——"m 的声音三天没练了，今天再听一听"。FSRS 是开源确定性算法，不是黑盒模型，满足"首期不引入黑盒推荐"的边界。
5. **家长报告**：输出"下次建议复习 m（预计 X 天后）"，不输出掌握率/词汇量/同龄比较——证据边界不变。

## 6. 建议二：解开音频死结——音素层换真人录音，词句层 TTS 管线化

这是当前唯一的工程硬阻塞，建议按音频层级拆策略：

| 层级 | 制作路线 | 理由与量级 |
|---|---|---|
| 纯音素（44 个 GB 音素，八课先用 7 个） | **真人录音**，逐条听审 | 行业标准做法（Jolly Phonics、ReadWrite Inc. 全是真人）。量极小：首批 7 条，全课程 44 条。一次制作、跨课程、跨版本长期复用 |
| 分音序列（w-sat-segment 等） | 真人音素拼接（0.4s 间隔音频工程合成）或真人连读直接录，二选一在录音时试验 | 比 TTS 模拟可控；16 词×1 条，全听审 |
| 连续合成（blend）与自然词音 | **TTS 管线保留**（词光已证明整词合成质量可靠），抽检听审 + 转写异常自动检测（docs/72 已在做） | 听审量从"117 条全审"降为"音素/分音层全审（约 30 条）+ 词句层抽审" |
| 中文指令 | TTS 保留，抽检 | 无音素难题 |

配套两个动作：① 录音资源与权利签认按现有 releasePolicy 门槛走（委托录音签权利记录，不能借用 CC BY 通道——词光的 CC BY 只覆盖它自己的资产）；② 把"p/n/m 纯音 rejected"的 TTS 路线正式关闭，不再投入 prompt 调优。

## 7. 建议三：24 课扩产用管线化生产，人只做机器不能做的审校

词光最重要的启示不是算法而是产能结构：7,298 个单元的一致性来自"统一规范 → 批量生成 → 机器校验 → （它的场景里省略了）人工审校"。桃阅读扩到 24 课（约 60–80 词、更多阅读材料）时的对应管线：

1. **课程脚本编写规范**（对照 gen_text.py 的 SYSTEM prompt 模式）：每课的新授 GPC、前置约束、核心词表、任务类型配比、阅读材料边界——全部形式化为可校验规则。docs/69 §2.3 列的审查项（未授字母干扰项、Pat 大写前置、答案暴露）大部分**可以写成校验器规则**而不是靠人眼。
2. LLM 批量生成课程草稿（课/任务/词表/短文，严格 JSON schema）。
3. `validate-phonics.mts` 扩展吃下上述全部前置约束（结构、GPC 范围、干扰项合法性、大小写、答案暴露、媒体引用）。
4. **教学编辑审校不可省**（与词光的本质区别）：机器过不了"sap 值不值得占孩子词义精力""Pin in tin 指代不清"这类判断。管线把人力从"生产 71 个任务"转为"审校 71 个任务"，成本可控且可追溯（现有 manifest reviews 字段）。
5. 音频按 §6 分层管线跟进。
