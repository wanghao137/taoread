**实锤缺陷 2 项（本轮修复，commit 3ef20b6）**：

1. **[UE] 翻页模式被设置面板遮挡**：弹层里选「左右翻页」后面板不收起，遮罩
   pointer-events 挡住翻页钮——用户启用翻页的第一步操作被挡（实测 Playwright
   对遮罩重试 30s×3 才暴露）。修复：ReadingAppearance 增 onModeApplied 回调，
   **仅左右翻页时收起**（上下滚动不收——upgrade.spec 的连续微调+焦点断言契约），
   ReaderPage/家庭阅读器两宿主接线。
2. **[功能] 诗歌类章节朗读无高亮**：poem 块 speaking 类挂 `<div>`，CSS 只匹配
   `.reader-text p.speaking`——古诗/三字经/百家姓朗读时孩子看不出读到哪。
   修复：选择器放宽为 `.reader-text .speaking`。

## 对抗式审查（六维度自查 + 审查中揪出的 P0）

审查代理被风控拦截，由主线按同等清单执行：作用域/调用点/契约/边缘/排版六维度。

**审查最大产出**：原高亮规则 `padding:4px 8px; margin:0 -8px` 会改块高——朗读中
高亮逐块移动时可能引发 columns 重分页（narration spec 的 `beforePages` 契约与
跨页跟随一直靠余量运气）。改为 `背景 + box-shadow:0 0 0 4px` 光晕：视觉等效、
**布局零影响**，顺带消除了 p.speaking 时代就存在的潜在重分页抖动。

其余维度：两宿主 close handler 均在持有 state 的组件内 ✓；全仓库仅 2 调用点 ✓；
已是翻页模式再点仍收起（一致可预期）✓；注音 ruby 不受 box-shadow 影响 ✓。

## 坑（本轮新增）

1. `new Audio()` 播放器不挂 DOM——TTS 探测以「暂停钮/高亮」为播放证据，
   `waitForSelector('audio')` 永远超时。
2. Overlay/Dialog 关闭后元素仍在 DOM（visibility:hidden）——「弹层已关」断言
   要查 `visibility/pointer-events`，不能查元素存在性。
3. Playwright 位置参数是正则：`upgrade.spec.ts` 会连 `offline-upgrade.spec.ts`
   及 output/ 下的副本一起匹配。
4. e2e 带 `resolve('apps/...')` 的用例必须从仓库根跑（e2e/ 目录下 CWD 错位）。
5. dev 库与生产库书目不同（dev 无三字经）——跨环境脚本的书目用候选列表探测。
