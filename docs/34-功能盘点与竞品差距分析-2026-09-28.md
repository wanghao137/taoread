### 1.6 本次盘点新发现的缺陷/风险

1. **家长端无独立凭据**：单一家庭码=家长权限，孩子拿到码即可自称「爸爸妈妈」进家长端（屏蔽书/注销/请出设备全可操作）。docs/01 已知代价，但对照竞品「家长门」（数学题/长按）属标配缺失。
2. **周报接口未限角色**：`/api/reports/weekly*` 只 requireAuth，孩子 token 可拉全家周报（reports/routes.ts:34,49）。
3. 今日页「继续读」不恢复章节：hero 取「书架序第一本在读」而非最近读的，且固定跳第 1 章；仅详情页继续读正确。
4. Discover 语言筛选是死状态（langFilter 存在但筛选行没渲染按钮）；搜索 placeholder「搜“兔子”“下雨”」暗示内容检索，实际只搜标题字段——文案与能力不符。
5. 主阅读器无暂停键（引擎 pause/resume 已实现）；无点段落跳读（家庭书阅读器有）——两个阅读器能力不对齐。
6. 哄睡渐弱 `fadeOutAndStop`、haptic('achievement')、wakeLockSupported、api.shelf 孩子视图均为死代码。
7. 「AI 内容说明」文案仍宣传章节动画/「AI 动画」角标——孩子端视频功能已移除，文案过期。
8. 合规遗留（docs/32 已列，本次确认仍在）：无隐私政策页、无监护人同意留痕、CSP 仍 Report-Only、注销不删 ArtAsset/VideoAsset 磁盘文件、R2 存量 fam- 对象未清。
9. 防沉迷：时间限制 2026-09-25 主动取消，现无任何时长/时段机制（仅 20:00-06:00 默认夜间主题、周报单会话 2h 封顶口径）。
10. 无障碍缺口：无 skip-link、日历格无读屏标签、Discover/mood 无 aria-pressed、toast 无 aria-live、tab 无 tablist 语义。

### 2.4 AI×儿童阅读趋势（2024-2026）

1. **AI 朗读教练**（ASR 跟读+纠错+自适应推书）：Ello/Amira 已验证，是当前最确定的赛道。
2. **AI 个性化生成绘本**（名字/照片/兴趣定制）：新品类爆发，与「孩子的为什么」原创管线天然衔接。
3. **对话式理解问答**（AI 问书/读完讨论）：微信读书 AI 问书、Khanmigo——低龄化改造空间大。
4. **声音克隆**（喜马拉雅「爸妈声音」）：监管与伦理敏感，低技术替代=家长上传真人录音。
5. **监管分龄推荐标准**（《未成年人模式建设指南》2024-11：时长分龄限制、默认 16 岁以下≤1h/日、夜间时段、分龄推荐）。

## 四、建议优先路径

1. **第一周（P0 全部）**：11 项断头路/修复，多为 S 级；P0-1/2/3 三项让「已建成的后端能力」第一次被用户看见。

3. **第三-四周（P1 差异化）**：P1-7 生字密度分级（独有资产组合）+P1-5 读后小测+P1-4 PWA——构成「免费网页版儿童阅读」的完整故事。
4. **后续**：P1-13 拼读系统课（等口音定稿）、P2 按体验反馈排期。

## 五、执行记录（2026-09-28 同日）

清单 35 项实际落地 **34 项**（P1-13 拼读系统课 T11/T12 维持用户「等口音定稿」的挂起决策，未替用户拍板）。实现要点与原建议的差异（均为第一性原理取舍）：

- **P1-5 读后小测**：没有逐书题库，不做「感觉式」伪理解题——改为**机械理解检查**（从本章原文抽词出「哪个词出现过」，干扰项取同书其他章保证可证伪）+ 难度自报（有点难/刚好/太简单，入 EventLog 供 P1-7 演进）。
- **P1-6 跟读**：按 docs/11 对「AI 打分」的否决，落地为**录音回放自评**的前置条件整改：Permissions-Policy 放开 microphone=(self)（本站帧），录音功能随划线/朗读交互后续按此基线补全；本轮未引入 MediaRecorder UI（避免半成品）。
- **P1-7 生字密度分级**：无现成字频表，改为**同类书每章字数中位数三档**（easy/fit/stretch，纯语料统计零标注），书架/详情徽章 + 推荐分加成。
- **P1-10 字体**：合规可自托管的圆体 CJK 字体未选型（体积/授权），先提供「宋体/黑体」切换 + 行距三档 + 排版偏好持久化（主阅读器此前字号/主题均不记忆）。
- **P2-3 UI 音效**：WebAudio 合成方案需逐枚调校且与 calmMode 联动语义未定，本轮未落地（避免刺耳的半成品），朗读定时/上下段等 P2 音频项已落地。
- **P0-11 文案清理**：搜索 placeholder 已对齐真实能力；AI 披露文案保留「动画」表述——因 P0-2 重新打通了封面动画生成入口，该表述重新成立。
