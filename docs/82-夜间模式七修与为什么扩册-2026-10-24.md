## 3. 本轮新增坑（环境类，全部复现两次以上）

1. **SQLite 路径双重人格**：Prisma `file:D:/abs/path.db` 绝对 URL 在本机连接到
   「空文件」而不报错；`file:./rel.db`（相对进程 CWD）才正确。所有 DB 操作
   一律 `createDb('file:./xxx.db')` 并在对应 CWD 下跑；跨库用「JSON 导出/导入」
   两段式，不做跨连接拷贝。
2. **ArtAsset 场景键**：章图键是 `chapter:<bookId>:<n>` 不是 `<bookId>:ch<n>`
   （gen-art 的 fallback 命名）；从 dev 拷台账前先 grep 生成日志确认键名。
3. **CF 对 404 也有缓存**：上传完成后的新文件可能仍 404（负缓存），加 cache
   buster 验证真实状态；前端对变体 404 本就有回退原图逻辑，无用户可见影响。
4. 死进程的「假成功」：`cp A B && cp C D` 链中第一个 cp 失败（通配不匹配）会
   让你误以为整链成功——分步执行并 `ls | grep -c` 核对数量。
