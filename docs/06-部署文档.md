# 桃阅读（TaoRead）部署文档

> 面向：把桃阅读部署到家庭自有环境（单机/家用服务器/轻量云）的运维者。
> 形态：单实例服务端（Fastify + SQLite）+ 静态前端（PWA）。

---

## 1. 前置条件

| 项 | 要求 |
|----|------|
| Node.js | ≥ 20（推荐 22 LTS） |
| 网络 | 服务端需能访问 `https://i.weread.qq.com`（微信读书 Agent 网关） |
| 时区 | **必须设置容器/系统 TZ**（如 `Asia/Shanghai`）——「一晚」的夜界分桶与周报窗口按服务器本地时间计算（登记册 N4-004/N3-005） |
| 域名（公网） | 需 ICP 备案（中国大陆）；全站 HTTPS |
| 反向代理（可选） | Nginx/Caddy 时必须配置 `TAO_TRUST_PROXY=1`（见 §4），否则 IP 限流退化为全站共享桶 |

## 2. 环境变量（apps/server/.env）

```ini
PORT=8787
NODE_ENV=prod
TAO_MASTER_KEY=<32+ 位随机串，用于加密各家庭 API Key；丢失=全员重新绑定>
TAO_ALLOWED_ORIGIN=https://你的前端域名     # 生产禁止 *（config 强制校验）
TAO_DATABASE_URL="file:./prod.db"          # 相对 apps/server/prisma/
TAO_BEDTIME=1290                            # 就寝时刻（本地分钟数，21:30）；off 关闭
WEREAD_API_KEY=                             # 留空（真实 key 由各家庭在应用内绑定）
```

生成主密钥：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

**迁移 drift 注意（N9-206）**：`prisma/migrations/` 含手工维护的 SQL（部分唯一索引）。
升级时只允许 `prisma migrate deploy`，**禁止 `migrate dev`**（会检出 drift 并尝试重写）。

## 3. 构建与启动

```bash
npm install
npm run build -w @taoread/web       # 前端产物 → apps/web/dist（PWA：manifest + SW precache）
npm run start -w @taoread/server    # 服务端（含 /api 与静态托管策略见下）
```

推荐生产形态：服务端只跑 API，前端产物交给 Nginx/Caddy 静态托管并把 `/api` 反代到 :8787。
SPA 路由需 fallback 到 `index.html`（vite-plugin-pwa 的 navigateFallback 已覆盖 SW 层）。

家庭首次接入：家长端「设置 → 绑定微信读书」输入家庭成员自己的 API Key（BYOK，
key 经 AES-256-GCM 加密落库，服务端日志与接口只回显尾 4 位）。

## 4. 反向代理示例（Caddy）

```caddy
taoread.example.com {
  encode zstd gzip
  handle /api/* {
    reverse_proxy 127.0.0.1:8787
  }
  handle {
    root * /var/www/taoread
    try_files {path} /index.html
    file_server
  }
}
```

并在服务端 `.env` 设置 `TAO_TRUST_PROXY=1` 后重启（未配置时 X-Forwarded-For 不被信任，
所有用户共享一个限流桶——登记册 N3-005）。

## 5. 合规与数据

- 儿童信息最小化：不收集儿童身份信息；注销家庭即物理删除全部家庭域数据（9 表级联）。
- 防沉迷内生：就寝窗口（TAO_BEDTIME 或家庭级设置）+ 单次软封顶；均可在应用内按家庭调整。
- 年度自查：对照《未成年人网络保护条例》第 37 条（见 docs/02 §7 清单）。
- 日志：不得记录 API Key 明文与儿童可识别信息（代码已保证，部署侧日志轮转自便）。

## 6. 演示模式（本地体验，勿用于生产）

```bash
npm install && npm run demo
# → http://localhost:5173 ，家庭码 123456
```

演示模式使用 mock 网关（零真实出网）+ 预置两周共读账本；就寝窗关闭；独立 sqlite（demo.db）。

## 7. 质量门（部署前自检）

```bash
npm run verify    # typecheck + eslint + 230 单测
npm run e2e       # Playwright 对演示模式全闭环（孩子完整仪式流 + 家长端）
```

两者全绿方可发布。当前版本：见 `git tag`（v1.0.0）。
