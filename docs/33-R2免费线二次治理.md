## TTS 死键 872MB 的根因与治理（第二波，commit 6adc2f5）

TTS 缓存键 = sha256(文本, 音色, 语速, 格式, lang, 命名空间, 模型)——**参数入键，参数一变旧键即死**。
09-26 英文书默认音色 mom-warm→en-storyteller 重预生成时，旧音色段不会被覆盖：深度分析实锤死键
**3958 个 / 872.0MB**，其中 **3932 个精确归因「en 书旧音色 mom-warm」**，26 个为旧文本残留。
对账闭环：期望键集（DB 正文×当前参数重算）5942 − 实际存活 5931 = 缺失 11 = 已知 stepaudio 451
内容拦截段；字节级重复 0 组（键含文本，天然去重）；跨语言同文本 0 段。

治理工具：`clean-media-r2.mjs --tts-dead`——以 DB 正文按当前参数重算期望键集（与 pregen-tts.mjs
同口径，期望集 <1000 视为连错库拒删），实际键不在期望集即死键；`--delete` 时 R2 批删 + 本地死文件
unlink + `.tts-public-state.json` 瘦身三处同步。已执行：3958/3958 删除，清单余 5931 键。
线上验证：活键 200 / 死键 404 / 图片 200，服务无感知。

## backup 桶用途裁定（09-28 复核）

fam-import 是家庭导入正本离机副本、art 是公共桶之外第二副本。整桶删除=放弃灾备，不建议；

**恢复演练仍未做过（待办），灾备未演练不算闭环。**

Vercel 存储评估结论（用户问题 1）：**用不上**。Vercel Blob Hobby 免费仅 ~1GB（超线直接暂停
store），Pro 下 ~$0.03/GB·月比 R2 超额单价贵一倍；且桃阅读生产是 Windows 自托管 + Cloudflare
Tunnel，与 Vercel 无关。Vercel 对本项目的价值只有免费带宽（taostudio 站已在用该模式）。

## backup 桶第一波：1.7GB 是什么

`reconcileRemoteMedia`（backup-to-r2.mjs 新增）以本地 `media/` 为唯一真值对账，孤儿 3341 个
与分项 Inventory 精确吻合，零误伤：

- `media/tts/` **3068 个 / 1036.8MB** —— 家庭 TTS 缓存。纯缓存（未命中自动重新合成），
  正文数据在 DB 快照里；09-26 治理只排除了 tts-public 漏了它；
- `media/videos/` **271 个 / 692.7MB** —— gen-video.ts 可再生 mp4；
- `media/.r2-sync-state`、`media/.tts-public-state.json` —— 运行状态文件误入镜像。

治理后备份桶保留：`art/` 原图 1044.9MB（公共桶之外的第二副本）+ `fam-import/` 94.4MB（家庭
导入正本）+ `db/` 3 份快照 29.4MB。

## 脚本变更（47769b4 + 6adc2f5，均已部署 prod）

- **backup-to-r2.mjs**
  - `isDerivedMedia` 排除列表扩充：`tts/`、`videos/`（此前已有 tts-public、缩图变体、状态文件）；
  - 新增 `reconcileRemoteMedia(dryRun)`：每次例行备份自动执行（幂等），远端孤儿批量删除
    （每批 1000 DeleteObjects）并同步瘦身 `.backup-state` 清单——根除「只增不删」；
  - 护栏：media/ 目录不存在或本地真值 < 1000 个时拒绝对账删除（防目录挂错清空全桶）；
  - DB 快照保留 7→3 份（`DB_KEEP`）；`--dry-run` 只出对账报告不上传不删除。
- **r2-inventory.mjs（新）**：只读全桶清点，按一级/二级前缀聚合对象数与字节数，作月度体检基线。
- **clean-media-r2.mjs（新）**：公共桶 taoread-media 孤儿清理，DRY-RUN 默认 + `--delete` +
  `--force`（孤儿占比 >50% 拒删，防本地目录挂错）；私有键（fam-/DB fam: 口径）命中即按孤儿删；
  `--tts-dead` 死键治理（见上）。**必须从部署 checkout（apps/server）运行**——prisma 与 src TS
  按相对路径解析，从 dev 仓库跑会连错库。

## 运维手册

```bash
# 月度体检（只读）
cd D:\taoread-prod\apps\server
node scripts/r2-inventory.mjs

# 备份桶对账报告（只读）
node --import tsx scripts/backup-to-r2.mjs --dry-run

# 公共桶孤儿/死键对账（只读）/ 删除
node --import tsx scripts/clean-media-r2.mjs [--tts-dead]
node --import tsx scripts/clean-media-r2.mjs --tts-dead --delete
```

计划任务 `taoread-backup`（03:30 每日）→ `D:\taoread-prod\bin\backup.cmd` → 新脚本，例行含对账。

## 遗留风险与后续

1. **余量恢复健康**：账号 ~8.67GB、余量 ~1.34GB；tts-public 后续若因再换音色/语速产生新死键，
   跑一次 `--tts-dead` 即清（键判定是确定性的）。
2. **9 月账期或擦线**：R2 按月均计量（账期 9/20–10/20），前 8 天的 11.74GB 高位拉高月均，
   估算 ~10.1GB——如被计量，超额 0.1GB 计费约 $0.002，10 月起干净。
3. **R2 预算警报**（手动一次）：R2 控制台「使用情况 → 添加预算警报」，阈值设 **8GB**，
   触发即跑 `r2-inventory.mjs` 体检。
4. taostudio 两桶（4.38GB）未动；cases-assets（3.35GB，本地 site-v2/images 有全量副本）是
   下一个治理候选，若增长破线再做「对照 manifest 删孤儿 + 浏览层 bake 进 Vercel 部署」。
5. 铁律沿用 docs/30 教训：**一切删除走 DRY-RUN → 报告 → 执行三段式，绝不在控制台手工清理**。
