## 上传容量门禁

实现：`apps/server/scripts/lib/r2-capacity.mjs`。标准 R2 S3 盘点列出账户所有桶、所有对象、未完成 multipart 的全部 part 字节；分页缺失、权限不足、异常数据都拒绝上传。预计总量达到 8,000,000,000 字节记录告警，达到 9,000,000,000 字节拒绝写入。覆盖图片后台推送、普通图片同步、经典内容发布同步、历史显式 R2 音频迁移分支及公共音频 S3 辅助入口。

新账户采用专用网关；Cloudflare API 已确认该账户仅有音频桶，因此当前桶盘点等于账户对象总量。网关所有本机上传调用集中受门禁约束，保留更严格的 **5,400,000,000 字节停止线**。如果以后新增其他桶，必须先补全新账户库存权限和总量汇总，再允许使用额外容量。

生产 API 与 CLI 的 `.env`、`.env.r2`、`.env.audio` 都指向 `D:/taoread-prod/.r2-capacity`。按账户共享原子目录锁，盘点缓存 60 秒，写前落盘保守预留本次全部字节；覆盖写也完整预留，失败结果不确定时不会释放额度。锁涵盖整个上传，两个本机独立进程不能同时使用最后一段容量。已有不可变音频只核验，不再预留上传量。读取清单的暂时性错误可有限重试；网关 PUT 不自动重试，避免把不确定成功当作未写入。S3 SDK 的传输重试始终包含在同一预留及锁内。

边界必须明确：这不是 Cloudflare 全局硬配额。其他主机、后台界面、其他项目和绕开共享上传模块的直接凭据写入不受本机锁控制；旧账户其他项目的桶计入盘点，但其上传器尚未接入同一门禁。60 秒库存窗口也可能遇到其他项目并行增长，9 GB 停止线保留 1 GB 余量。不能声称所有外部写入者已被强制停止。

盘点失败或孤立锁会停止上传，本地生成文件保留。遇到锁超时，先检查 API/同步任务进程是否仍存活；确认没有进行中写入、重新核对库存后再由维护者处理锁，不能自动删除活跃锁来继续上传。账本和锁目录均不含凭据。

## 每日一诗

上线 `GET /api/content/daily-poem?childId=...` 与孩子首页卡片。服务端要求登录和本家庭 childId，按真实档案年龄选择已挑选的 **29 首现有诗词**（学龄前池 9 首）。上海日期决定顺序轮换；相同有效池、同一日期和年龄结果稳定，相邻日期不重复。前端在换档案、恢复页面可见及上海午夜时刷新。

只使用数据库中 `published`、中文 poetry、未被家庭屏蔽的书。每章标题、正文、拼音和译文必须与挑选时的完整签名一致，否则从池移除；没有合格结果则隐藏卡片。首页展示作者和诗句，64 px 按钮进入准确书/章，复用现有正文、拼音、译文、朗读，不依赖第三方在线 API，不自动新增媒体。

生产审计发现现有 15 本中文诗词书都已 published，但人工 `reviewStatus` 都为 pending。每日池沿用已有发布版本，**未把结构核验或机器筛选写成“人工已审核”**，没有修改这些审核字段。现有全库人工校订仍是后续内容工作。

公网 390×844 手机与 820×1180 平板真实验收通过：学龄前当天《登鹳雀楼》，6–8 岁当天《江雪》；标题/预览一致，无横向溢出，进入正确章节，朗读命中现有缓存并实际播放新 R2 的 206 音频，无播放器或页面运行错误。验证使用独立临时家庭，结束后删除并确认，未借用真实家庭。
