# 105 — 性能第二轮：web 静态资产迁 CDN 通道（方案C-lite，2026-11-06）

前序：docs/102（音频/图片 100% CDN 化，方案 C 立项）、docs/103/104（真安卓路线B）。
第一性诊断：源站快（2.7ms），慢全在「绕不开边缘」的传输路径；音频/图片已离源，
**JS/CSS/字体是最后一块走家庭上行的重载荷**——每次部署新哈希=边缘全冷，首位访客裸奔上行
（docs/102 实证 MISS 回源 339s）。

## 0. 方案定案（第一性结论）

**复用既有 dl/dist 通道**（跨账号 taoread-dist 桶 + taoread-dist-origin Worker），
零新域名/零证书/零 DNS/零容量闸耦合（音频账号 7.83/9GB 红线不碰）：

| 层 | 改动 |
|---|---|
| Worker | ALLOWED_EXT +js/mjs/css/woff2/svg/ico；`web/` 前缀 → immutable 1y；其余维持 300s |
| 构建 | vite base=VITE_ASSET_BASE（cdn 模式）；index.html+CSS（含 /fonts/ 绝对路径）全前缀化；postbuild codemod 为纯保险 |
| 上传 | publish-web-assets.mjs（wrangler spawn 并发 4，幂等覆盖；上传集=除 index/sw/offline*/download.html/art 外全部） |
| 服务端 | CSP 五域放行 dl（script/style/font/img/connect，webAssetCspOrigin() 读 TAO_WEB_ASSET_BASE） |
| 部署序 | **先传资产→验样→装 dist→重启**（对抗性顺序：HTML 引用的哈希必须先于引用存在） |

## 1. 明确不做（记录理由）

- **PERF-08 早 304 否决**：304 路径仍付全量 DB 查询+序列化，廉价指纹方案有 docs/35 P0-1
  的「永久陈旧 304」前科；源站 2.7ms 下收益<风险
- **字体重子集（300KB 预算）判定被传输修复取代**：预算诞生于家庭上行时代；资产走边缘后
  冷 Today 字体从边缘 HIT 服务（<300ms 级），预算的存在理由消失——诚实记录 superseded-by-design
- HTML 仍源站 no-cache（2.7KB+RTT 是 SPA 壳的固有地板；s-maxage 短 TTL 需主账号 zone purge 权限，
  收益<陈旧窗口风险）

## 2. 部署实录与结果

- 上传 252 文件/12.4MB → taoread-dist/web/（REST 直传 252/252 零失败）
- dl 通道抽验 9/9 全 200（immutable+正确 content-type）
- 生产：cdn dist 安装+`TAO_WEB_ASSET_BASE` env+服务重启；index 7 处 dl 引用生效
- **生产真浏览器（Playwright）验证：0 console 错误/0 失败请求**（修复 art 漏传后）

| 项 | 迁移前（源站） | 迁移后（dl/R2） |
|---|---|---|
| 部署后边缘冷启动 | 全量走家庭上行（MISS 回源 339s 实证） | **结构性不可能**（资产不在源站） |
| 浏览器缓存 | immutable 1y | immutable 1y（不变） |
| 首访资产路径 | 隧道→上行 | 边缘 Worker→R2（免出站流量费） |
| 源站负载 | 静态+API+媒体兜底 | **仅 API+HTML+媒体兜底** |

## 3. 部署协议固化（每次 web 发版）

1. `npm run build:webcdn`（构建+postbuild 保险）
2. `node scripts/publish-web-assets.mjs`（**必须 exit 0 才可继续**——部分失败即中止，HTML 不可先装）
3. 装 dist 到 D:/taoread-prod/apps/web/dist → 重启（CSP 引导哈希重建）
4. 验证：dl 抽样 200 + 生产浏览器 0 错误 + index 含 dl 引用
回滚：`mv dist dist.bak-cdn-20261106` 反向 + 重启（旧 dist 自含资产，自洽可回）

## 4. 对抗审查记录（过程中已修）

1. **白名单缺 `.webmanifest`/`.wav`**：对象在桶、Worker 404——探测时「上传完≠能服务」
2. **传播延迟误判**：Worker 重部署后 3s 内探测全 404（隔离实例未换血）——复验须等 ≥15s
3. **art/ 引用漏判**：JS 用 BASE_URL 引运行时 art——上传集 exclusion 清单必须以构建产物引用实测为准，不能按直觉猜
4. **wrangler spawn 挂死 30min**：4 并发全程 0 文件进展——转 REST API 直传秒级全过（docs/102 已知坑再现，固化 REST 为唯一正道）
5. **postbuild 相对路径**：npm 链 cwd 漂移——脚本必须以自身位置锚定或显式 cd
6. **CSP 未生效假象**：先装 HTML 后推代码——生产跑旧 CSP；顺序=提交推送→prod 对齐→重启
