## 0. 结论：五个投诉的根因是同一个，且已被定位并修复

用户的投诉全部成立，但**不是产品本身差，是演示入口的接线缺陷让产品以最差状态呈现**。

`apps/server/src/demo/main.ts`（演示模式入口）此前只接了 mock 网关，四个 AI 能力参数一个都没传：

| 参数 | 缺失后果（用户看到的） |
|---|---|
| `ttsDeps` | TTS 路由 503 → 前端降级**浏览器 Web Speech**（机器人声） |
| `imageDeps` | 生图路由 503 |
| `videoDeps` | 「让画面动起来」按钮**不渲染** |
| `mediaDir` + 媒体台账 | demo.db 的 `artAsset`/`videoAsset` 表 **0 行** → 封面/题图 API 返回 `coverArtUrl: null` → 前端回退**自绘 SVG 矢量图** |

磁盘上 279 张 AI 插画和 203 条视频好好的，演示库里一行都没有。**用户看到的是骨架，不是成品。**

## 1. 修复清单（全部已落地并验证）

### N13-001 演示家庭码横幅错误（P1）
`scripts/demo.mjs` 印的是 `DEMO8888`，实际种子码是 `PEACH888`。更糟的是家庭码正则 `/^[A-HJ-NP-Z2-9]{8}$/` **排除了字母 O**（防与 0 混淆），`DEMO8888` 连格式校验都过不了，直接报「家庭码格式不正确」。
**修复**：两处改 `PEACH888`；curl 验证 `/api/family/join` 返回 200。bug-register 里 N11-105/N11-006 早登记为「已修复」但只改了 seed.ts，启动脚本漏了。

### N13-002 演示模式媒体接线（P0，本轮核心）
- `demo/main.ts` 按配置可用性接线 `ttsDeps` / `imageDeps` / `videoDeps` / `mediaDir`
- 新增 `src/demo/seed-media.ts`：从 dev.db 读媒体台账行，校验磁盘文件存在后幂等 upsert 进 demo.db
- 启动时自动播种：**+279 插画 / +200 视频**

**验证结果**（Playwright 实测 + curl）：
- 书架 39 张封面全部是真实 AI 插画（`/api/media/art/covers/*.webp`），零 SVG 回退
- 阅读器内 `<video>` 真实渲染（`/api/media/videos/*.mp4`，2MB 级文件）
- TTS 直连 StepAudio 3：`POST /api/tts/preview` 返回 200，mp3 落盘，**字级时间轴精确到毫秒**（`chars: [{char, start, end}]`）
- 无 503 降级文案

### N13-003 生图提示词重构（P0）
审查发现旧 STYLE 有四个明确的反模式，直接导致出图「丑」：

| 反模式 | 害处 | 修复 |
|---|---|---|
| `peach and indigo night palette` 强制夜景 | 学堂、花果山黄昏等白天场景被压暗发闷 | 按描述关键词（夜/月/星/萤火…）分流，夜景才补冷色调，白天保持明亮 |
| `watercolor and colored pencil` 混合媒材 | 两种纹理指令互相打架，质感发糊 | 锁定单一水彩 + `clean crisp linework over soft color washes` |
| `no text, no letters` 写在正向描述里 | 反向词走正向通道反而诱导出文字 | 改为正向表述 `wordless illustration, pure image` |
| `main subject centered with generous margins` | 大片留白，构图空洞 | 改为 `rich layered composition filling the whole frame` |

同时清晰度档位 1K → **2K**（封面 864×1152 → 1728×2304，题图 2624×1472）。
`gen-art.ts` 新增 `--regenerate` 参数强制重生成已存在场景。**279 张全量重生成在后台进行中。**

图像统计客观验证（同描述新旧对比）：亮度 133→165 / 149→167（解决发闷），细节能量回升。

### N13-004 UI 品牌氛围升级
- **书架顶栏**：纯文字栏 → 带星光装饰层、毛玻璃按钮的品牌头图区
- **登录页**：加固定星光背景层；标题「桃阅读」改蜜桃渐变文字；月亮徽章加 reduced-motion 门控（之前裸循环）
- 修复 `verify-demo-media.mjs` 的 `expect` 未导入（lint 3 error）

### N13-005 触达红线修复（P1）
DOM 实测发现**收藏按钮高度只有 40px**，违反设计系统明文规定的 ≥64px 儿童触达红线——52 个书卡全部违规。
**修复**：`h-10 w-10` → `min-h-touch w-16`，实测 64px 达标。
