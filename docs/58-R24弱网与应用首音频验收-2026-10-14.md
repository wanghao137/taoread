# R24 弱网与应用首音频验收（2026-10-14）

本轮承接 57 号报告中没有通过的 R24。首次验收时，用户授权是“处理完通过之后，提交推送部署”。验收基线为 `d3e92d4d3d7b98b447a3b30c19a80a6acb0fa039`，候选是基于该提交的工作区。第 1～5 节保留该验收快照；用户随后明确授权先发布一版修复，发布范围与记录位置见第 6 节。

**性能验收结论：R24 仍未通过。** 功能回归通过不能代替弱网、真机和实际首音频验收。单独发布已验证的改善不改变这项结论。以下分别记录已解决的路径问题、测量结果和剩余阻塞；57 号报告保留原时点的结论。

## 1. 已实现的变更

### 1.1 单本深链不再等待全书目录

阅读器和单书详情直接读取单书元数据，不再先下载 277 本全量目录。保留按孩子的收藏、进度、完成状态、续读章节、内容版本，以及服务端家庭归属、屏蔽和发布状态校验。回到“找故事”仍加载全量目录；列表页以外不再为首屏请求周报、成就或在回前台时刷新全量目录。

单书读取有独立错误重试，身份变更后旧请求不能覆盖新孩子的数据。专项浏览器用例验证深链没有全目录、周报或成就请求，验证返回书库、收藏和单书请求失败后的重试。

### 1.2 缓存播放与供应商可用性解耦

章节端点完成鉴权与可读性检查后，先查公共缓存和家庭缓存。只有实际新合成才需要供应商和每日配额。没有供应商配置或家庭额度耗尽时，已有可用缓存仍可播放。

前端章节播放直接请求 SSE，不再串行等待音色探测；阅读器也不以探测失败阻止缓存朗读。在点击手势内激活音频，保留自动播放策略拦截后的手势恢复、队列和取消语义。SSE 断开判断改为响应流关闭；本轮没有实现正在执行的供应商合成请求的 AbortSignal 透传，不能据此声称供应商在停止按钮点击时立即停止计费。

### 1.3 CDN 启播失败时使用确认存在的源站副本

真实 CDN 旧实验出现 5.3～8.6 秒 TLS 握手，预连接实验没有证明稳定复用连接，已撤回。候选改为：公共音频仍先用 CDN；服务端仅在清单命中且本地文件存在时发送源站备用地址；首次播放超过 2.5 秒未开始，或出现网络播放失败，改用源站副本。

已经开始播放的 CDN 音频保持播放。自动播放被拦截时保留队列等待手势。停止、切换播放会话或章节会使旧超时结果失效。该机制不复制 R2 对象，也不生成新的音频。只在 CDN 和本地副本同时存在时生效；本地副本被删除、源站公网链路也很慢或浏览器后台暂停时，没有统一首播上限保证。

相关源码：`apps/web/src/lib/audioPlayer.ts`、`apps/web/src/pages/child/ReaderPage.tsx`、`apps/web/src/pages/child/V8App.tsx`、`apps/server/src/content/service.ts`、`apps/server/src/modules/tts/publicCache.ts`、`apps/server/src/modules/tts/routes.ts`。

## 2. 验证条件与证据位置

证据根目录：`output/playwright/r24-20261014/`。该目录没有加入 Git；其中其他任务的备份也不得一起提交。`candidate-source.json`记录 14 个相关源码、用例与测量脚本的 SHA-256，以及最终前端 `index.html` 的 SHA-256。`checks-final.json`记录本轮完成的检查。

所有应用测量都用合成家庭和独立 SQLite；没有登录或修改真实家庭，没有使用生产数据库。UI 测试强制 `TAO_E2E_ISOLATION=1`，供应商禁用。音频测试另用本机回环服务、独立媒体与数据库，只按需读取生产配置中的 TTS 和公共 CDN 设置，不继承其数据库或身份密钥。新生成使用原创合成文本，每次服务运行最多 3 次供应商请求；配置和签名查询参数没有写入报告。

浏览器为 Windows 桌面 Chrome 154.0.8037.98，390×844、移动与触控模拟。弱网用 CDP 施加 4 倍 CPU 降速、100ms 延迟、200000B/s 下载、100000B/s 上传。冷缓存禁用 HTTP 缓存；暖缓存先访问同一路由。Service Worker 均阻止。此设置不等于真实 Android/iOS，也没有复现生产 HTML/API 的 DNS、TLS、Tunnel 和蜂窝网络。

LCP、INP、CLS 由 `web-vitals` 6.2.3 采集。内容可用时间以有意义 DOM 出现后连续两帧计时，不等于图片全部下载完成。翻页和续读的自定义计时不包含事件派发前的排队，不能代替 INP。保留缺测、失败、慢样本和首轮轨迹；不得把缺测填零。

本轮每组 3 次，只报告中位数与最大值，不报告真实用户 p75/p95。候选门槛仍参考 LCP≤2500ms、INP≤200ms、CLS≤0.1；实验室超过门槛表示没有放行依据，实验室低于门槛也不表示已经取得真实用户 p75 证明。
