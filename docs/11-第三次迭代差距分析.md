## 0. 第一性原理：第三轮要回答什么

前两轮解决了「有没有」（内容、阅读器、TTS、周报）。第三轮的问题不是「缺功能」，而是**「每一个已存在的界面，有没有达到儿童产品的体验基线」**：

1. **自主性**：不识字的孩子能不能独立完成「找一本书 → 听 → 退出」全程，不靠家长？（证据：Epic 绿话筒图标导航；Khan Kids 低幼段系统推送免导航）
2. **容错**：孩子的误操作会不会造成不可挽回的后果？出错时的语气是指责还是包容？（证据：Amazon 家长批准；MC-7 错误态不出现「失败」字样）
3. **一致性**：设计系统定下的规矩（空态不用 emoji、触达 ≥48px、吉祥物贯穿）是不是只在部分页面兑现？（本轮自查发现：**只兑现了一半**）

这三问把 75 条竞品差距 + 自查发现压缩成下面 8 张 P0 卡。**绝大多数竞品差距（G01 悬浮播放器、IA-4 听读分账、AU-3 音量上限、PC-8 远程暂停、AU-6 家人录音）不是不对，而是第二轮做不动**——它们要改信息架构或加服务端能力，排在 P1/P2，本轮不碰。

## 4. 补齐计划

### 4.1 优先级原则

- **P0 = 本轮必须做完**：全是可以 1-3 天内完成、且能在本环境验证（单测/e2e/DOM 断言）的项。
- **P1 = 验收日后**：书架「继续读」大卡片（IA-3）、阅读障碍友好排版开关（MC-5）、睡前渐弱（AU-2，需 Web Audio，Web Speech 做不了平滑包络）。
- **P2 = v4**：服务端 TTS 全套（字级高亮 + 锁屏 + 拟人音色）、家人录音、家校入口。

### 4.2 P0 任务卡

**P0-1 内容域搜索（S-1）**
- 服务端：`GET /api/content/books?q=` 支持 title/author 模糊匹配；中文匹配含**拼音首字母**（如 `sy` 命中「静夜思」需走全拼索引——务实做法：只做 title/author 子串 + 大小写归一，拼音留给 P1）
- 前端：桃书架筛选条上方加搜索框（复用旧 SearchBox 视觉），无结果时空态正向引导
- 验收：单测 `q=静夜` 命中且不命中时不泄露其他家庭；e2e 搜索「小王子」→书架定位

**P0-2 TTS 语速档位 + iOS 防御（S-5、S-6）**
- 语速：声音面板加档位 0.8 / 0.92（默认）/ 1.1 / 1.25，持久化到 tts store；朗读中改对下一句生效
- 防御：`tts.ts` 所有进入 `utterance.text` 的内容消毒 `<`/`>`（转全角），单测覆盖含尖括号的书名
- 验收：`apps/web/test/tts.test.ts` 新增 ≥3 项

**P0-3 空状态全量去 emoji（S-2）**
- 6 处空态换 SceneArt 场景 + TaoMascot：ChildHome（无孩子档案）、AchievementWall、BookPicker、ContentLibrary、StarSea、ShelfManager
- EmptyState 组件本身保留 emoji 入参（兼容），但生产页面零 emoji
- 验收：脚本扫 `apps/web/src/pages` 里 EmptyState 的 emoji= 用法为 0（KitchenSink 除外）

**P0-4 触达红线修复 + 巡检脚本（S-3）**
- 36px 弹层关闭按钮 → 48px（`h-12 w-12`）
- `scripts/audit-touch.mjs` 接入 `npm run verify` 前置，CI 级防回归
- 验收：巡检脚本输出 0 违规

**P0-5 吉祥物小桃贯穿关键情绪屏（S-4）**
- RitualGate：🌙 emoji → SceneArt 夜空场景 + TaoMascot（mood 随是否有未读会话切换）
- BedtimeScreen、CelebrationScreen、Loading 组件：emoji → TaoMascot/SVG
- 验收：e2e DOM 断言关键屏存在 `data-art="tao-mascot"`；无裸 emoji 的关键屏

**P0-6 阅读器专注模式（RD-8）**
- 阅读正文时点屏幕中央（非按钮区域）切换顶栏/底栏显隐；3 秒无操作自动收起
- 收起态只剩正文，把屏幕主动权交给共读家长（Reich 2016：共读对话应围绕书而非平台）
- 验收：e2e 点击正文区 → 工具栏 hidden；再点 → 恢复

**P0-7 路由级代码分割（S-7）**
- `React.lazy` 分割 ChildHome / ParentHome / LoginPage；预加载策略（idle 回调拉另一端）
- 验收：构建产物首屏 chunk < 300KB；verify 绿

**P0-8 孩子端误触防护（S-8、MC-4）**
- 「换家庭」改为二次确认（TaSheet 确认层，正向文案「确定要回到登录页吗」）
- 验收：e2e 点「换家庭」→ 出确认层 → 取消后仍在孩子端

## 6. TTS 升级路径决策（docs/09 §6 延续）

- **本轮不做服务端 TTS**。理由：Azure F0 免费层虽好（50 万字/月 + 儿童音色 Xiaoshuang/Xiaoyou + 字级时间轴），但需注册国际账号、出网、数据出境告知，且**本环境无法验证出声**（无浏览器、无音频）。做一个无法自测的语音链路，不符合「严格认真」。
- **本轮把纯前端能拿到的体验拿满**：语速档位、iOS 崩溃防御、分句稳定性回归测试。
- **v4 路线已定**：服务端 `/api/tts/synthesize`（Azure F0，SSML 限儿童内容）→ 前端 `<audio>` + MediaSession 锁屏 + WakeLock + Web Audio 渐弱。届时 G-01/G-04/G-05/G-06 一次性解决。
