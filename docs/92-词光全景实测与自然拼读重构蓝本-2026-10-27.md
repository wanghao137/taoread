## 1. 词光全景记录（实测）

### 引导向导（首访）
全屏向导：学习起点 A1–C2 卡片（各带一句话定位）→ 什么时候考试（选填+暂不设置）→ 每天学几个新词 5/10/20/30/自定（"建议从 10 个开始，复习另计"）→ CTA「开始学习」。底注："无需注册。进度保存在当前浏览器，学习设置可在我的中修改。"

### 今日（#/）
自上而下：日期+时段问候（"10月27日·星期二 / 早上好"）→ 考试日期计算器入口 → **今日学习卡**（新词 10 · 预计 9 分钟 · "先复习，再学新词" · 5 张词图预览 · 大 CTA「开始学习」· 范围调整「从 A1 开始·调整」「按难度学习·调整」· 文案"学会一个词，天上就多一颗星"）→ **今日一词**（vulgar：英音/美音/循环按钮+IPA+释义+生成词汇卡+整句例句逐词点读+播放例句）→ **今日阅读**（分级短文卡：题材/等级/时长/含 N 个未学重点词/开始阅读）→ **这一周**（连续天数+一周七日答题柱状+已学/较熟悉计数）→ **学习路线**（A1 0/785 → C2 0/274 进度梯）→ **词汇星图**（已点亮 0 颗星+进入星图）→ **按话题查词**（19 个话题 chip 带词数）。

### 学习队列（#/learn）
顶栏：X 退出（"暂停学习，返回今日"）+ 进度条 + **1/20**（10 复习+10 新词）+ 环境声开关。
阶段循环（实测枚举）：
- **认识新词**（新词导入卡）：大插画（tooltip"不喜欢这张图？点这里换成经典插画"+「换个画风」）→ A1/教育 标签+词条编号 → 超大单词 → 英音（**自动播放**）/美音/循环 三 pill → 双释义（中文+英文 gloss，带词性）→ **日常例句+雅思例句**（每个词可点查词、目标词高亮、播放例句、中文翻译）→ 常用搭配 → 相关词形 → 记忆提示（"library 是图书馆，bookshop 是书店"）→ 吸底「继续」。
- **看图，补全这句话**：插画+挖空句+四选一（带序号）。
- **选择词义**：词选义四选一。
- **答对反馈**：选项锁定+正确项打勾变绿+底部弹层（小图+“答对了”+词+IPA+发音自动播放+释义+整句点读+中文+「继续」）。
- **错词再练**：答错的词立刻以「错词再练 · <原题型>」重新出现（同题型重教重测）。
- 新词卡与测验**穿插**出现（不是先学完再测）。

### 图鉴（#/atlas）
"图鉴 · 7,298 词 / 看图学词，在语境中理解 / 14,596 条原创例句"。搜索框（单词或中文释义，⌘K 全局搜索）→ 难度筛选 A1–C2 → 19 话题筛选 → **学习状态筛选（全部/未学/学习中/较熟悉/收藏）** → 结果计数 → **图片/列表/星图三视图**。词卡=图+词+等级+一句话释义。点开=**底部抽屉词卡**：大图（可换画风）+ 状态 chip + 收藏 + 分享 + 词条编号 + 超大词 + 英美音循环 + 释义 + 例句。

### 星图（#/atlas?view=galaxy）
"8 / 7,298 颗星已点亮 · 已点亮星座 0/19"。**每个词=一颗星**，颜色=学习状态（未学/学习中/较熟悉），可拖动旋转/缩放，点星星开词卡；按话题分 **19 座星座**（教育座 Education 1/378"再学 302 个词即可点亮"），本话题学过 80% 点亮星座，"点亮不代表已经掌握"。+ / − / 复位 / 分享 侧边控件。

### 书房（#/read）
双分类：**短文**（词光短文第 1 篇 The Blue Book Box：生活 A1 约 1 分钟 · **重点词已学 8/10** 的词 chip 列表 · 中英对照开关 · 字−/100%/字+）· 正文逐词可点查词。**原版书**：小王子（可读，带"章节星图"）+ 即将上架书架（老人与海/傲慢与偏见/福尔摩斯/爱丽丝/时间机器，每本一句推荐语+主题+等级）。

### 练习（#/practice）
"让手，也记住它们。**练习成绩单独记录，不计入单词复习进度。**"
- 雅思专项：同义替换（#/paraphrase）、易混词辨析（#/confuse）。
- 打字三模式：**单词打字**（看图写单词）、**例句打字**、**听写**（只听写整句）。
- 选词范围：最近学过 / **错词本** / 收藏 / 学习路线。"可练 8 个词，每轮最多 10 个"。
- 打字游戏：图+释义提示+播放发音+输入框（**全对自动下一项**），顶栏实时 词/分钟+正确率，"速度按每 5 个正确字符折算 1 词"。

### 我的（#/me）
- 我的学习：连续学习 / 已学 / 较熟悉 / **首次正确率** / 学习时长。
- **过去 20 周热力图**（GitHub 风格，"每格代表一天，颜色越深作答越多"）。
- **未来 7 天待复习**（今天 8 / 明天 0 / …）。
- 学习设置：每日新词（1–200，复习另计）/ 考试日期 / 目标分数 / 自动安排每日新词 / 学习起点 / 学习路线（按难度/按话题）/ **复习目标（85%/90%/95%，"希望下次复习时仍记得的比例"）** / 默认发音（英音/美音）/ 外观（跟随系统/浅色/深色/极光/星光）/ 插画风格 / 英文字体（衬线/无衬线/复古）/ 自动播放发音 / **复习时先回想**（先隐藏图义例，答完再展开）/ 界面音效 / 每日开屏动画 / 复习时加入拼写题 / 功能导览重放 / 提示重显。
- 学习数据：**导出备份 / 导入备份 / 清空学习记录**（"进度保存在当前浏览器"）。

### 设计语言
深色星夜（近黑蓝底+星光点缀）、超大圆润标题、pill 按钮、卡片圆角大+低对比描边、橙色/绿色强调、水彩插画大幅出镜、微动效（星闪/弹层滑入）、一键换画风（新版/经典两套插画）。

## 2. 桃阅读现状 vs 词光差距

| 维度 | 词光 | 桃阅读拼读现状 | 判定 |
|---|---|---|---|
| 信息架构 | 五 Tab 平级（今日/图鉴/书房/练习/我的），每 Tab 都是完整页面 | 单页课程流（一节课内任务线性走），无 Tab 无主页 | **缺失，重构核心** |
| 今日主页 | 问候+今日学习卡（数量/时长/预览/CTA）+今日一词+阅读+周历+路线+星图 | 无；入口是 V8 首页一张卡 | **缺失** |
| 学习队列 | X/20 进度+暂停+题型穿插+答对弹层反馈+错词立即重练 | 有课内任务流，但无 X/20 总进度、无"错词再练"穿插、反馈朴素 | 部分，需改造 |
| 词的仪式感 | 一词一画+大字+英美音+IPA+双例句逐词点读+搭配+词形+换画风 | 词卡有图+三读+中文释义（已对齐词光核心），但只在课后收集，无大卡仪式感 | 部分 |
| 图鉴 | 7298 词全库+筛选+状态+搜索+三视图 | 只有"已收集词卡"网格 | **缺失** |
| 书房 | 短文+原版书+重点词进度+对照+字号 | 41 课 40 本小书散在课内 | **缺失** |
| 练习 | 打字三模式+专项+错词本+速度统计 | 无独立练习（复习走推荐链） | **缺失** |
| 我的 | 统计五件套+热力图+复习预告+全设置+备份 | 无 | **缺失** |
| 游戏化 | 星+星座+连续天数+周历 | 贴纸风 UI，无贯穿隐喻 | **缺失（星图隐喻可整体移植，孩子适配）** |
| 引导 | 首访向导（起点/每日量/无注册底注） | 家长选起点（已有，家长侧） | 家长侧已有，孩子侧无需 |

**教学内核不推翻**：桃阅读的 GPC 课体系（音素/拼读/小书/走查）是拼读教学本体，词光是"词义学习"产品，两者题型不同。重构对象是**产品形态**（IA/主页/队列/图鉴/游戏化/反馈），不是教学内容。

## 3. 重构方案（本轮落地）

**形态**：`/child/phonics` 变成沉浸式子应用——词光式五 Tab 底部导航（今日/图鉴/书房/练习/我的），深色星空主题（品牌桃色做强调色，与主站区隔=「英语声音课堂」是一个"世界"）。已有课内播放器改造为全屏学习队列。

映射表（词光 → 桃阅读实现）：
| 词光 | 桃阅读实现 | 数据源 |
|---|---|---|
| 今日学习卡 | 今日拼读卡：推荐链下一课/复习+预计步数+开始按钮 | `GET /next` + catalog |
| 学习队列 1/20 | 全屏播放器加总进度条+退出暂停 | attempt plan 步数 |
| 认识新词卡 | 音素/词导入卡（大图+自动播放+拼式+例词） | 现有 listen/meaning 任务强化 |
| 答对弹层反馈 | 底部弹层：小图+答对了+发音重播+继续 | 现有判分事件 |
| 错词再练 | 答错同题重试（客户端即刻重入队） | makePlan 已有 round 机制 |
| 图鉴 | 全部 89 词网格（未解锁灰显+锁），点开大卡 | catalog words + `GET /words` |
| 星图 | 每词一颗星：已收集词点亮；每课一座星座 | words+catalog |
| 书房 | 小书架：40 本 reader 按课解锁，封面+重点词数，点开走现有 reader 页 | catalog readers |
| 练习 | 看图拼词（letter build）/听音选词 quick round | review/consolidate planKind |
| 我的 | 已收集词数/连续天数/首次正确率+设置（发音口音偏好展示）+家长门入口 | progress+words |
| 连续/周历 | streak 按完成 attempt 的本地日期 | attempts 历史 |

**范围裁剪（孩子适配）**：不做打字/WPW（6-8 岁不识字量不够）、不做考试日期/目标分/复习目标百分比（家长不感知 FSRS 参数）、备份导出不做（进度在服务端账号上）。
