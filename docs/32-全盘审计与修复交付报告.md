## 一、架构勘误（重要）

此前多份文档按「Cloudflare Workers + D1 + KV」描述后端，实际架构为：

- **Fastify 4 + Prisma + SQLite**（Windows + NSSM 服务 + Cloudflare Tunnel 入口）
- R2 仅作公共媒体 CDN 与备份（脚本同步/备份），限流为进程内 Map
- 鉴权为 Bearer JWT（无 cookie）；全部 DB 访问走 Prisma 参数化查询

本报告及修复均以实际架构为准。
