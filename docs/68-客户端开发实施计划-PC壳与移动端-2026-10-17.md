# 桃阅读客户端开发实施计划（PC 壳 + 移动端）

> **执行方式**：按任务逐个执行，每个任务自带测试与提交。可用 superpowers:subagent-driven-development（推荐，每任务独立子代理+审查）或 superpowers:executing-plans（本会话顺序执行）。

**目标**：按 docs/67 的推荐方案交付三件可安装产物——Windows 桌面壳（Tauri 2 远程轻壳）、强化的双端 PWA、Android 侧载 APK——全部零货币成本，安装包经新 Cloudflare 账号的 R2 分发。

**架构**：PC 壳加载 `https://read.taostudioai.com`（远程窗口默认零 IPC 授权，导航拦截/快捷键垫片/自动更新全在 Rust 侧）；移动端先纯网页层强化（M0），再以 Capacitor 8 打包现有 React 应用（M1）；分发统一走 `dl.taostudioai.com`（旧账号域名反代新账号 R2）。

**技术栈**：Tauri 2（Rust stable MSVC）、Capacitor 8、Cloudflare Workers + R2、GitHub Actions、vitest/playwright（沿用仓库现有门禁）。

## Global Constraints（每个任务都隐含遵守）

1. **零预算**：不引入任何付费服务。本机已有 JDK 17 / Node ≥20；缺的工具链（Rust、Android SDK）全部用免费官方渠道。
2. **生产红线**：所有 `apps/web` / `apps/server` 改动必须保持 `npm run verify`（audit:touch + typecheck + lint + 单测）与 `npm run e2e` 全绿；生产变更走既定部署链（prod fetch/reset → build → `bin/nssm.exe restart taoread-api`），CORS 等服务端变更选低峰窗口。
3. **不随包携带书库**：安装包 ≤30MB（APK）/≤15MB（exe）；2.3GiB 音频绝不打包。
4. **不做热更新**：APK/壳升级一律「提示 → 用户下载覆盖安装」（壳走 updater 签名通道，是受控更新不是热更）。
5. **密钥保管**：minisign 私钥、Android keystore、R2 API token、CF 密码一律不入 git/不入文档/不入聊天。`*.keystore`、`key.properties`、`.env.dist` 进 `.gitignore`。
6. **凭据卫生**：本次聊天中已出现新 CF 账号明文密码——**Task I0-1 第一步就是改密码 + 开 2FA**；日常操作只用最小范围 API token。
7. **新增儿童数据为零**：客户端不采集任何新的个人信息，APK 不加统计 SDK。
8. 文件一律 UTF-8 + LF；`.cmd` 脚本例外（ASCII+CRLF，本计划不新增 .cmd）。
9. UI 文案延续产品中文口吻（如「接着听请再点一下播放按钮」的语气），儿童端不出现技术错误码。

// taoread-dist origin：按路径读 R2 对象，全部公开（安装包与版本清单无敏感数据）。
// 禁止目录列举；key 校验只放行安装产物与清单，防止误绑整个桶语义。
const ALLOWED_EXT = /\.(exe|apk|json|sig|txt|webp|png)$/i

export default {
  async fetch(request, env) {
    const url = new URL(request.url)
    if (request.method !== 'GET' && request.method !== 'HEAD') {
      return new Response('method not allowed', { status: 405 })
    }
    const key = decodeURIComponent(url.pathname.replace(/^\/+/, ''))
    if (!key || key.includes('..') || !ALLOWED_EXT.test(key)) {
      return new Response('not found', { status: 404 })
    }
    const obj = await env.DIST.get(key)
    if (!obj) return new Response('not found', { status: 404 })
    const headers = new Headers()
    obj.writeHttpMetadata(headers)
    headers.set('etag', obj.httpEtag)
    headers.set('cache-control', key.endsWith('.json') ? 'no-cache' : 'public, max-age=300')
    headers.set('access-control-allow-origin', '*')
    if (request.method === 'HEAD') return new Response(null, { headers })
    return new Response(obj.body, { headers })
  },
}
```

fn spawn_update_check(app: tauri::AppHandle) {

            .dialog()

                .dialog()
                .message(format!("更新失败，请稍后到下载页重试：{err}"))
                .title("桃阅读 · 更新")
                .blocking_show();

/**
 * PWA 安装引导（docs/67 §4.3 M0）。
 * Android/桌面 Chrome：捕获 beforeinstallprompt，提供程序化安装；
 * iOS：无该事件，由 InstallHint 组件展示「添加到主屏幕」图文步骤。
 * 已安装（standalone）时全部引导隐藏。
 */
export interface BeforeInstallPromptEvent extends Event {
  prompt: () => Promise<void>
  userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }>
}

let deferred: BeforeInstallPromptEvent | null = null
const listeners = new Set<() => void>()

function notify(): void {
  listeners.forEach((fn) => fn())
}

if (typeof window !== 'undefined') {
  window.addEventListener('beforeinstallprompt', (event) => {
    event.preventDefault()
    deferred = event as BeforeInstallPromptEvent
    notify()
  })
  window.addEventListener('appinstalled', () => {
    deferred = null
    notify()
  })
}

export function _acceptPromptEvent(event: BeforeInstallPromptEvent): void {
  event.preventDefault?.()
  deferred = event
  notify()
}

export function canInstall(): boolean {
  return deferred !== null
}

export async function promptInstall(): Promise<'accepted' | 'dismissed' | 'unavailable'> {
  if (!deferred) return 'unavailable'
  const event = deferred
  await event.prompt()
  const { outcome } = await event.userChoice
  deferred = null
  notify()
  return outcome
}

export function onInstallAvailability(fn: () => void): () => void {
  listeners.add(fn)
  return () => {
    listeners.delete(fn)
  }
}

export function isStandalone(): boolean {
  return (
    window.matchMedia('(display-mode: standalone)').matches ||
    (navigator as { standalone?: boolean }).standalone === true
  )
}

export function isIOS(): boolean {
  return (
    /iPad|iPhone|iPod/.test(navigator.userAgent) ||
    (navigator.platform === 'MacIntel' && navigator.maxTouchPoints > 1)
  )
}
```

  const parts = raw.split(',').map((s) => s.trim()).filter(Boolean)
  if (parts.length === 0 || parts.includes('*')) return true
  return parts
}

- [ ] **Step 1**：`appUpdate.ts`：

```ts
import { Capacitor } from '@capacitor/core'

export interface MobileRelease {
  version: string
  url: string
  sha256: string
  notes: string
}

const DIST_BASE = 'https://dl.taostudioai.com'

/** 语义化版本比较：1.10.0 > 1.9.1 */
export function isNewerVersion(candidate: string, current: string): boolean {
  const parse = (v: string) => v.replace(/^v/, '').split('.').map((n) => Number.parseInt(n, 10) || 0)
  const [c, cur] = [parse(candidate), parse(current)]
  for (let i = 0; i < 3; i += 1) {
    if ((c[i] ?? 0) !== (cur[i] ?? 0)) return (c[i] ?? 0) > (cur[i] ?? 0)
  }
  return false
}

export function currentAppVersion(): string {
  return import.meta.env.VITE_APP_VERSION ?? '0.0.0'
}

/** 仅原生壳内检查；web/PWA 返回 null（网页更新随部署自动生效）。
 * VITE_APP_VERSION 由 .env.mobile 注入，publish 脚本（Task M1-5 Step 3）负责校验其与
 * apps/mobile/package.json 及发布的 version.json 三者一致 */
export async function checkMobileUpdate(): Promise<MobileRelease | null> {
  if (!Capacitor.isNativePlatform()) return null
  try {
    const res = await fetch(`${DIST_BASE}/app/version.json`, { cache: 'no-store' })
    if (!res.ok) return null
    const release = (await res.json()) as MobileRelease
    return isNewerVersion(release.version, currentAppVersion()) ? release : null
  } catch {
    return null
  }
}
```

run(`npx wrangler@latest r2 object put "taoread-dist/app/version.json" --file apps/mobile/.version.json.tmp --remote`)
