设计说明（任务书要求的方案提交）：
- 采用「独立家长码」而非客户端 PIN 弹窗：家长码是服务端校验的第二凭据，创建家庭时生成、仅家长会话可见/可轮换；家庭码仅授予孩子身份。家长恢复=凭家长码重新加入；家长码遗失由任一家长会话查看/轮换。旧家庭迁移不自动提升任何已知儿童设备：`parentCode` 为 NULL 的存量家庭，由首个合法家长会话（迁移前 30 天旧令牌在本次变更中已全部失效，见下）无法再懒生成——即旧家庭需重新创建或由运维在库内回填；当前无生产部署，唯一存量是演示家庭（已回填 13572468）。

复现前结果：probe AUTH-01（家庭码 200 拿家长令牌）、AUTH-04（注销后旧令牌读正文 200）。

最终行为与实现边界：
- 儿童码/家庭码申请 parent → 403 `FORBIDDEN`（中文提示家长码入口）；家长码正确 → 200；孩子加入响应不含 parentCode。
- 注销家庭 → 全家 DeviceSession 级联删除 + 缓存逐出 → 一切旧令牌 401；单设备撤销 → 该设备 401，其他设备不受影响；伪造签名/过期/无 sid 令牌 → 401。
- 速率限制沿用 join/create 的 IP 桶（不泄漏有效家庭码语义不变：不存在 404、家长码错误 403）。

迁移与旧数据处理：迁移只加列加表；旧令牌（无 sid）全部失效属预期安全行为（重新加入）；演示库幂等回填。
