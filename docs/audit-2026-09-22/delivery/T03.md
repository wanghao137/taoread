## 执行中的重要发现（交接必读）

1. **e2e 曾误打用户实例**：vite 的 `/api` 代理目标默认 8787——隔离端口 e2e 若不给 web 端透传
   `TAO_API_PORT`，浏览器请求会打到用户正在运行的旧 demo（5173/8787），读写用户的演示库。
   这曾导致：同一 familyId 跨运行出现（用户持久库）、parent-code 404（旧代码）、
   「注销家庭」用例在用户 demo 库上真实删除过 123456 家庭（后已由演示种子幂等重建）。
   已修复：playwright webServer 给 vite 透传 `TAO_API_PORT`；教训——**隔离端口必须同时覆盖
   代理链，否则"隔离"只是表象**。
2. **F35 的 env 卫生不可靠**：`DOTENV_CONFIG_PATH` 指向缺失文件在 dotenv 16.6 预加载下虽
   生效，但 A/B 复现中出现过横幅仍显示「已接线」的实例（env 传递链不可证）。已改为
   **代码级强制**：`TAO_E2E_ISOLATION=1` 时 demo/main.ts 跳过 dotenv 并把三类供应商
   硬置 null——隔离性由代码保证，横幅可肉眼验证（⚠️ 三行 = 零出网）。
3. **A→B 切书用例与 F10 的冲突**：套件断言「结束旧书改读这本」后到第 1 章，与 F10
   「续读到原进度、显式重读才回首章」矛盾（上一用例把唐诗进度留在第 5 章）。已按 F10
   语义修正断言（章号正则 + API 侧确认会话是 cbf:tangshi-300）。
4. **演示种子留活跃会话**：seedDemoFamily 的最后一晚会话 endedAt=null（今晚正在读唐诗）——
   新库上小桃开任何别的书都会先撞 409 三选一。这是「今晚共读中」的演示语义，保留；
   需要无冲突流程的用例须先收尾该会话（audit.spec 的 finishAllActiveSessions 即此用途）。
