## 3. 可重跑接口探针

源代码：[probe.mjs](evidence/probe.mjs)，结果：[probe-results.json](evidence/probe-results.json)。从仓库根目录执行：

```powershell
node --import tsx docs/audit-2026-09-22/evidence/probe.mjs
```

脚本创建 `node_modules/.taoread-audit-*` 的独立数据库，先 migrate，再建合成家庭/两章书，执行接口检查；删除自己创建的合成家庭，随后导入真实内容包和演示家庭并监听 127.0.0.1:8799 供浏览器审查。测试媒体目录只读复用现有素材，生成供应商为 fake。端口必须空闲；Ctrl+C 停止自己启动的进程。它不是 production seed 命令。

注意：当前探针保存“观测值”，不是期望修复后的自动回归断言；修复 agent 应把场景转为正式测试。合成 `audit-book` 留在隔离库，因此隔离浏览器书库可能有 223 本，JSON 的 222 本来自 ALL_PACKS，不含合成书。不得把截图中的 Audit book 当正式内容缺陷。
