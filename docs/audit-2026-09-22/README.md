## 结论先读

桃阅读已有可保留的模块化后端、内容格式、亲子档案、阅读器和品牌视觉基础，但**当前版本不宜直接叠加自然拼读后作为稳定产品发布**。先修复身份权限、屏蔽绕过、阅读数据与流程阻断，再建设英语教学能力；无需先重写技术栈。

最先处理的发布阻断项：

1. 同一家庭码可直接申请家长身份，儿童掌握家庭码即可能取得家长权限。
2. 屏蔽仅作用于书单，直接访问正文仍成功；注销家庭后的旧令牌仍可读内容。
3. 儿童令牌能进入图片生成参数校验；图片、视频全局资源与付费生成缺少合适权限及配额边界。
4. `sharp` 被静态引用却未声明到依赖/锁文件，本机额外安装掩盖了干净部署缺陷。
5. 详情刷新误报不存在、“好奇”心情提交失败、继续阅读回到首章、重读清除完成状态。
