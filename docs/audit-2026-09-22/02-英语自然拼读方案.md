# 英语自然拼读：实施 PRD 与技术/内容规范

状态：建议方案，尚未实施或通过教学试点。适用于当前 TaoRead 架构；先完成审计 F01–F05、F09–F17、F30–F36 的相关上线门槛。产品负责人确认口音、首批内容和试点对象后才能发布课程。

## 1. 要解决什么问题

孩子在家长帮助下建立字素—音素对应关系（GPC），能把已学音连续合成为词，并把口语词拆成音；随后阅读与已学知识匹配的短句/短文。听故事、理解词义与自主解码分别培养，不能把“跟着听完/点对图片”记录为“已掌握拼读”。

定位为桃阅读里的可选“英语小练习”，与自由阅读并行。建议每次 5–8 分钟可中途退出，这是试点产品参数，不是科学规定时长。3–5 岁优先声音游戏与家长共玩；是否进入文字拼读按准备度与家长观察，不按生日自动升级。不给孩子贴落后、错误多、不聪明等标签。

## 2. 方法依据与适用边界

参考英国教育部的公开原始材料：

- [The reading framework](https://www.gov.uk/government/publications/the-reading-framework-teaching-the-foundations-of-literacy)
- [阅读框架 PDF](https://assets.publishing.service.gov.uk/media/664f600c05e5fe28788fc437/The_reading_framework_.pdf)
- [系统合成拼读项目核心标准与申请说明](https://www.gov.uk/government/publications/phonics-teaching-materials-core-criteria-and-self-assessment/submitting-phonics-programmes-for-validation-application-form-guidance)

采用的原则：系统且连贯的教学顺序；明确教授 GPC、合成与分音；练习读物匹配已经教过的对应关系和明确教过的例外词；复习与评估支持教学决策；词汇/理解仍需丰富口语及阅读经验。上述资料是方法参考，不代表桃阅读获得认证，也不是针对中国家庭第二语言场景的疗效证明。首批课程必须由懂英语教学与语音的编辑复核，agent 不能凭搜索摘要宣称教育有效性已验证。

## 3. 范围与非目标

| 首版必须有 | 首版不做 |
|---|---|
| 一套口音、一套有版本号的教学顺序 | 英美混用或让模型临时编排教学顺序 |
| 8 个试点课次，含复习课与匹配短读物 | 一次生成几百节“完整课程” |
| 准确示范音、慢速合成、正常词音 | 用通用 TTS 读字母冒充纯音素 |
| 看字听音、合成、分音、短文迁移 | 只认图、只听选项就算掌握 |
| 儿童退出/继续，家长观察与练习记录 | 强制睡前训练、排行榜、断签惩罚 |
| 可访问点击操作与音频替代说明 | 仅拖拽、仅颜色区分、自动录麦 |
| 稳定进度、幂等作答、可解释推荐 | ASR 自动打分、口音诊断、学习障碍诊断 |

以后可扩展常见辅音二合字母 sh/ch/th/ng、元音二合字母、长元音、替代拼写、多音节；每一阶段都先审课程与音频。字母名称单独提供，不和音素按钮混淆；th 等可有多个音，不能建成字母串→唯一发音的硬编码映射。

## 4. 信息架构与核心流程

儿童端保留“今天 / 找故事 / 我的”。今天出现可选英语练习卡；我的显示“英语练习记录”。家长设置可开启、暂停并选择口音；未开启家庭不增加强制步骤。练习与故事使用一致品牌、独立专注布局，不再套双层 Shell。

```mermaid
flowchart LR
  A[家长了解并开启] --> B[非诊断性准备度观察]
  B --> C[今天的可选练习]
  C --> D[复习已学音]
  D --> E[示范一个新对应]
  E --> F[合成与分音]
  F --> G[匹配短句/短文]
  G --> H[温和结束与记录]
  H --> I[家长观察 + 下次复习]
  F --> J[暂停/退出 保存待继续]
  J --> C
```

准备度观察问家长：是否能听懂练习词含义、愿不愿意模仿声音、是否认识部分字母音。孩子任务可用已知词的口头合成/分音小游戏；结果描述“建议先一起玩声音”，不输出考试分级。已有英语基础可由家长选择复习起点，保留变更记录。

一课页面：顶部退出与步骤进度；中间只呈现当前字素/词；主要按钮“听一听/再听/我来试”；底部下一步。示范阶段可展示图片解释词义，独立解码阶段不让图片直接泄露正确词。慢速拼音素与正常词音分开，英文标 lang，中文说明保持简短。

## 5. 首批 8 课建议草案

这只是可审校的开发样例，不是已定稿教材。选择 GB 或 US 后由教学编辑校正所有音频/词表；口音未定前只允许使用标注为开发占位的测试资产，不得发布。

| 课次 | 新授/复习 | 可用词或任务草案 | 说明 |
|---|---|---|---|
| L01 | s /s/、a /æ/ | 辨音、看字听音 | 不强凑句子，不把字母名当音 |
| L02 | t /t/ | at、sat；/s/→/æ/→/t/ 合成 | 爆破音短促，不额外加“uh” |
| L03 | p /p/ | pat、tap、sap | 先由成人确认词义适合试点 |
| L04 | 复习 s a t p | 独立新组合与听词分音 | 不仅重复背过的顺序 |
| L05 | i /ɪ/ | sit、sip、tip、pit | 与已学短元音对比 |
| L06 | n /n/ | pin、tin、in、nap、pan | 继续合成与分音 |
| L07 | m /m/ | mat、map、man、Sam | 专名及大写必须另作显式教学 |
| L08 | 累积复习与迁移 | “Sam sat.” “Sam sat in …”须重审完整句 | 仅经审定且所有词可解码的最终短文可发布 |

首批不强制引入例外词；若需 a、the、is 等自然句法，必须明确记录实际读音及尚未常规可解码部分，不能用拼写已出现就判定可解码。例如 a 在句子中常为弱读 /ə/，不能因为教过 /æ/ 就自动放行。只学 s/a/t/p/i/n 时不能出现 cat；c 未教。大写、标点、人名读法也要在课内解释。

后续路线分阶段审定：基本短元音与常见辅音→辅音组合与常见二合字母→常见元音对应→替代拼写与更多词形。不要把固定“26 个字母”当课程结束。课程更新不可改变已完成课的证据含义。

## 6. 音频资产规范：本项目最关键的内容门槛

每个 GPC 至少有纯音素示范、字素展示对应关系、必要的发音提示；每个练习词有音素序列、连续合成示范和自然词音。语音由合格录音或经过语音编辑逐条验收的合成素材提供。TTS 可作为编辑制作工具，不能未审自动发布。

manifest 字段：assetId、locale、accent、speakerId、kind（phoneme/blend/word/passage）、text、phonemeIds、courseVersion、audioRevision、mime、durationMs、sha256、license、reviewer、reviewedAt、status。教学音不得借用故事角色声线/情绪音效。音量一致，无削波、首尾截断、背景音干扰；/p t k b d g/ 不附加元音；/s m n/ 等持续音按教师规范呈现。

对齐使用人工审定的 phoneme/grapheme/word 时间戳，不复用目前按字符长度分配的 timeline 当精确音素对齐。错误示例音只在专业审定后引入，首版优先清晰正确示范。

验收包括：正常及慢速播放、连续点击、暂停恢复、音频解码失败、耳机/扬声器、iOS 首次手势限制、后台恢复；实际听审所有发布素材。音频缺失则该课显示暂不可用，不静默降级为不准确的字母朗读。听力无障碍支持文字/可视分音及家长协助，不承诺音频依赖任务对所有用户等效。

## 7. 数据模型建议

复用 Family/ChildProfile、统一鉴权、媒体元数据、UI 基础组件；新增 phonics 领域。不要在 ReadingProgress.finished 里塞课程掌握度。

| 模型 | 必需字段与约束 |
|---|---|
| PhonicsCourseVersion | id、locale、accent、status、contentHash、publishedAt；发布版本不可变 |
| PhonicsLesson | versionId、stableKey、order、prerequisites、taughtGpcIds、reviewGpcIds、exceptionIds |
| GraphemePhonemeMapping | stableId、grapheme、phoneme/IPA、locale、position/condition；允许一对多 |
| PhonicsWord | versionId、text、lemma、audioIds、meaningHint、reviewStatus |
| WordMapping | wordId、grapheme spans、phonemeIds、mappingIds、exception spans；完整覆盖且不重叠 |
| DecodablePassage | versionId、text、wordMappings、requiredGpcs、explicitExceptions、audioId、rights |
| PhonicsEnrollment | familyId、childId、courseVersionId、enabled、startedAt；服务器校验 child 归属 |
| PhonicsAttempt | id、childId、lessonVersion、clientAttemptId、startedAt、finishedAt、status；唯一 child+clientAttemptId |
| PhonicsResponse | attemptId、itemVersion、sequence、answer、hintUsed、replayCount、result、serverReceivedAt；幂等键 |
| PhonicsSkillEvidence | childId、mappingId、sourceAttemptId、independent/assisted、observedAt；可追溯事实 |
| PhonicsReviewPlan | childId、ruleVersion、dueItems、reason；可重算的推荐，不覆盖原始证据 |

Prisma 迁移先增表和索引，不修改已有阅读数据语义。家庭注销 cascade 覆盖新表；公共课内容不随家庭删除。题目答案在服务端验证，客户端只发 itemId/optionId，不能信任客户端 score。身份从 token 获取，不接受请求自报 familyId 作为授权依据。

孩子自称“我会了”记录为自评，家长观察记录为观察；选择题无提示正确为单次证据，不能直接叫已掌握。首版建议显示“练过 / 正在巩固 / 可以再试”，若使用熟练度阈值必须由教学负责人定义样本数量、跨日保持、迁移词验证及不确定性，不由 agent 编造科学分数。

## 8. API 契约草案（新增，不是当前接口）

| 接口 | 权限/行为 |
|---|---|
| GET /api/phonics/catalog | 已登录；仅已发布且地区/语言可用课程 |
| PUT /api/children/:childId/phonics/enrollment | 家长；开启/暂停/口音/版本；归属校验 |
| GET /api/children/:childId/phonics/next | 本家庭授权身份；返回推荐及简短理由 |
| GET /api/phonics/lessons/:versionedId | 可见性策略；返回学习内容，不批量暴露测验答案 |
| POST /api/children/:childId/phonics/attempts | 幂等创建；绑定已发布题目版本 |
| POST /api/phonics/attempts/:id/responses | 归属、题目版本、sequence、严格 schema；服务端评分 |
| POST /api/phonics/attempts/:id/finish | 幂等；区分 completed/paused，不把退出当失败 |
| GET /api/children/:childId/phonics/summary | 家长/允许的儿童摘要；区分练习和独立证据 |

错误统一包含 code、面向用户的 message、requestId；401 失效、403 不可用、409 版本/序号冲突、422 作答不合法、429 配额。实际状态码与现有错误规范统一后定稿。请求重试返回相同结果，不再添加一次练习；旧客户端与课程撤回有明确只读/结束当前课策略。

断网首版可先提供“已下载当前课继续练习，结果待同步”，若不做离线必须明确提示。离线结果存最小数据、版本和幂等键；不缓存凭据到课包；家庭退出清私人队列；课程撤回或授权变化重连时不默默接受失效作答。

## 9. 内容发布管线

1. 教学编辑编写 GPC 顺序、目标、例外词及词义范围。
2. 工具检查图谱无循环、前置课存在、每个字素 span 覆盖、词表不越级、音频存在且版本一致。
3. 教师逐课审合成/分音逻辑，英语编辑校词句与口音，内容负责人审图像/权利/儿童适宜性。
4. 录音或生成后人工听审，记录音频 checksum 与批准人。内容生成服务不能自己批准自己。
5. 形成不可变 release manifest，试点环境全走一遍；发布指针原子切换。
6. 灰度按家庭开启；发现错误可下架单课并回退课程指针，保留历史作答版本和解释。

AI 可以协助草拟/查重/结构转换，不能负责最终发音验收、版权裁定或凭空判定孩子能力。发布前缺任何 approved 状态必须阻断，不得用 warning 淹没。

## 10. 验收矩阵

| 维度 | 必测情景 |
|---|---|
| 教学 | 纯音与字母名区分；连续合成；分音；陌生但可解码词；例外词显式标记 |
| 内容 | 每课词/句不越级；大写/弱读处理；同一词多发音按语境；课程版本冻结 |
| 音频 | 正确口音、无附加元音、切换无串音、延迟不误结束、取消停上游/播放器 |
| 权限 | A 家庭看不到 B 孩子；儿童不能改家长 enrollment；注销后 token 无效 |
| 状态 | 快速重复点击/重试幂等；换孩子独立；离开再入；离线同步/版本冲突 |
| UE | 360/390 手机、768 平板、1440 桌面；200% 缩放；键盘；reduce-motion |
| 隐私 | 默认无麦克风权限；没有原始童声上传；日志不含凭据或敏感自由文本 |
| 评估 | 提示后正确不等于独立正确；完成不等于掌握；家长看得懂推荐理由 |

试点输出观察而非“提分效果”：新词合成是否能迁移、需要几次成人提示、哪里退出、音频是否听清。先验证完整一课，再做 8 课，再扩课程。上线默认关闭，已完成基础审计阻断项、8 课全内容/音频审校、权限/回归测试以及亲子试点后开放。

## 11. 需要产品负责人定稿的决策

这些不会阻止工程先修现有缺陷或搭建 mock：目标市场/授权范围；首套 GB 还是 US；教学审校负责人；第一批家庭英语基础；内容制作与人工听审预算；是否首版要求离线；课程和自由阅读的统计分离方案。没有决定前采用明确的 draft 状态，不能把开发默认值自动视为用户批准。
