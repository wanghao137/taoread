## 一、内容补全（任务 6）

### 1.1 范围与口径

- 「全本」= 书名承诺的完整语料：《唐诗三百首》收全本、《千家诗》收全本、《诗经》收全本 305 篇、蒙学（三字经/弟子规/千字文/百家姓/朱子家训/增广贤文/幼学琼林卷一）收全篇、《声律启蒙》上下卷各 15 韵部全本。
- 「选集」= 书名即为选本（李白/杜甫/王维诗选、童趣诗选等）：扩充到代表性规模（12-30 篇），且名篇逐字来自语料数据集，不臆造。
- 英文公版小说为「绘本化改编」：补齐到 8 章以上的章节化改编规模；CC-BY 单篇故事本身即完整。
- 版权红线不变：诗文均公版（作者卒年逾保护期），拼音为 pinyin-pro 生成（关闭一/不变调，与课本注音口径一致），白话译文为平台自撰（rights.translator = 桃阅读）。

### 1.2 数据管线

- 语料源：chinese-poetry 开放数据集（公版古籍文本）+ 平台自撰译文 + 名家诗选按题检索全唐诗。
- 生成器：`apps/server/scripts/gen-corpus.mjs`（繁→简 OpenCC、逐字注音、场景键映射、译文合并、缺口任务分发）。
- 译文管线：按全局 key（题|作者|首行）跨书去重后分发子代理批次撰写，合并回生成器。
- 元数据安全：`corpus-data/original-meta.json` 从 git 历史恢复各书原始 id/分类/适龄/封面配置，生成器不再读自身产物，避免元数据丢失。
- seed 性能：章节/块改批量 `createMany`（单书 3 次往返），全库重播种从分钟级降到秒级。

### 1.4 完整度审计口径修订

`scripts/audit-completeness.mjs`：CC-BY 单篇绘本按 3 章计（故事本身完整）；声律启蒙上下卷按 15 章计（韵部即全本）。`validate-packs` 的「场景键跨书重复」从失败降级为提示：全库 2400+ 章共用 ~40 个 SVG 场景模板属新架构预期，视觉唯一性由 AI 题图管线（按 bookId+chapterId 定址）保证。

补章后剩余缺口（82 本 / 缺 320 章过线）均为两类、已明确不做或缓做：
- 英文诗歌童谣选集（Now We Are Six / Sing-Song 等 9 本）：公版原文必须逐字保真，拒绝机改，排入后续按「原文一首一章」扩充。
- 名贤集：无可靠全本底本，按「不臆造」红线维持「儿童选」定位。

## 二、PC 宽屏布局（任务 1）

- 全局容器：`max-w-md / lg:max-w-6xl` → `md:max-w-2xl / lg:max-w-7xl`，桌面内容不再挤成窄列。
- 门屏（首页）：桌面左右分区（品牌区 + 行动区）间距拉开（gap-40），装饰贴纸全部撤出容器轮廓。
- 书籍详情：桌面双栏——左栏 sticky（封面/元信息/主 CTA），右栏简介 + 章节双列网格；移动端 CTA 吸底并为 dock 让位。
- 登录页：桌面双栏（左品牌 hero、右操作卡），消除此前 71% 宽度的两侧空置。
- 孩子端 xl 宽屏：两侧加品牌氛围层（蜜桃色光晕 + 贴纸点缀，纯装饰、不挡交互）。
- 阅读器：正文保持约 42em 的舒适阅读行宽（阅读类产品的刻意约束），底部 padding 加大为音频条让位。

## 三、书架页按钮重设计（任务 3）

- 头部：移除与底部 dock 重复的「← 首页」；标题横排不折行；「生词本」与「N 本」计数统一为胶囊家族并留间距。
- 「继续读」大卡：香蕉黄大底改为奶白墨线卡；封面/信息/CTA 三段式；进度条限宽 320px 不再横贯整卡；新增「继续读」胶囊 CTA。
- 筛选 chips：未选中态改为奶白底 + 1.5px 墨线（米色底上清晰可辨）；行尾加渐隐遮罩提示可横滑。
- 试听圆钮：从绝对定位（压作者名、跨卡漂移）改为信息行 flex 内联，文字区 min-w-0 截断，永不重叠。
- 「AI」角标：仅在插画真实加载后显示、降噪为小轻胶囊；全站返回/次级按钮统一为「奶白底 + 2px 墨线 + 硬偏移阴影」一族。
- 章节目录（详情页）：行改卡片式双列网格，当前进度章高亮并挂「接着读」角标。
