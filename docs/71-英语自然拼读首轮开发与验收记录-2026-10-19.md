# 英语自然拼读首轮开发与验收记录

日期：2026-10-19。依据 docs/69、docs/70。用户已批准本版开发建议与 GB 英式发音方向；不再需要重复确认这些产品选择。本记录区分代码实现、测试素材、正式素材、真机和家庭观察。

## 本轮实现

- 独立 v2 课堂：中文指令、字母音示范、点选、点击拼摆/撤回、重听、提示、重试、口头自述、逐页阅读、温和结束与可选重读。素材未准备好不开放作答；教学播放器只有一个音源，不调用 Web Speech 补音。
- 保存和恢复：冻结计划、服务端状态机、题目实例号、revision、幂等请求、单活动约束。已接受但回包丢失的请求可以用同编号重放；暂停/刷新保留步骤、页码、错误和帮助。回到今天、切孩子、离开页面或隐藏页面停止课堂声音。
- 题目切换：课堂按 attempt 与 taskInstanceId 重新初始化，避免新题短暂沿用旧题 ready/heard 状态、快速点击播放后被素材清理取消。修复前的浏览器失败报告保留为 browser-before-task-reset.json。
- 家长设置与记录：声音游戏/字母音起点、版本绑定、暂停开启、调整起点前明确处理原活动；今天一条推荐；全量分组次数、分页、不同课程与重读分开。补记显示实际词句、时间与阅读页，不只显示内部编号。已经用过帮助的口头尝试不能补记成独立读出。
- 学习证据：口头自述 correct=null；应用点选、孩子自述、帮助、家长观察分别保留。观察更正追加记录，不能覆盖原记录；儿童不能调用家长补记。没有自动发音评分、掌握率或英语等级。
- 内容工程：课程 schema、复杂映射表达、逐词前置与大小写/标点校验、未教干扰项校验、保留尝试检查、音频用途/口音/时间轴及真实文件哈希检查。公开任务不含答案或未来提示。
- 隔离与兼容：两次增量迁移，不删除旧记录。旧草稿使用原 enabled，新版独立使用 v2Enabled（默认 false），旧草稿开关不能开启新版。旧接口只读取/修改 protocolVersion=1；家庭删除清理学习事件与观察更正，公共课程发布索引保留。
- 媒体与开放控制：off/pilot/all（默认 off）、受控家庭范围、家长开启、已审定课程和数据库发布哈希共同生效。课程媒体有会话、白名单、真实路径和哈希检查，支持 Range206、no-store；关闭/撤回后保留历史和安全暂停/关闭入口。
- 工具：validate-phonics.mts、export-phonics-review.mts、phonics-release.mts。发布工具支持只读 inspect、受门槛约束的发布/默认版本操作与撤回；没有执行实际发布操作。

## 可复现命令

在仓库根执行：

```powershell
npm run typecheck -w @taoread/server
npm run build -w @taoread/web
node scripts/audit-touch.mjs
node --import tsx apps/server/scripts/validate-phonics.mts --mode development --out output/phonics-v1/20261019/content-development.json
node --import tsx apps/server/scripts/validate-phonics.mts --mode release --out output/phonics-v1/20261019/content-release.json
node --import tsx apps/server/scripts/phonics-release.mts inspect --version taoread-phonics-gb-v1
node node_modules/@playwright/test/cli.js test -c e2e/phonics.config.ts
```

release 校验此时预期非零退出。浏览器专项需要先构建 apps/web/dist；它在 127.0.0.1:8798 启动独立临时数据库/媒体与合成测试内容，拒绝复用已有服务，不读取产品 .env 来调用供应商。不使用正常 8787/5173 服务，不代表公网或真机通过。

正式生产工具仅在实际发布指令后使用。inspect 不传 --database 时只检查已安装包；需要数据库状态时显式提供 SQLite URL。写操作要求 --database 和 --expect-hash；publish 还要求哈希绑定的验收收据及技术、真机、教学语音、家庭试点、备份恢复证据文件。withdraw 使用数据库已有发布哈希，不因当前素材缺失而阻止紧急撤回。配置 off 和家长暂停同样是停止新学习/媒体授权的独立手段。

## 收尾与剩余门槛

本轮本地工程验收结果汇总在 output/phonics-v1/20261019/verification.json；verificationRunComplete=true仅指本轮验证执行结束，productComplete=false、releaseReady=false明确表示整体产品和正式开放尚未完成。

目前不能宣布 M1/M2 或正式可用课程完成。需要先由教学编辑确认逐屏稿；制作 L07 与前置的真实中文指令、GB 纯音、分音、连续合成、自然词音和适义图片；逐条听审并绑定文件哈希。此后完成全八课素材、正式音块对齐、其余显示边界、iOS/Android 真机中断/手势与家庭可用性观察，再推进扩课。用户对开发方向的批准不替代上述实际制作、听审和观察记录；不需要再次确认已批准的产品选择。

本轮不提交、不推送、不部署。回退时优先使用总开关 off/课程 withdraw；已有 v2 数据时，直接运行基线 0c4f650 的旧 phonics/routes.ts 会混读新记录，因此兼容回退必须保留本轮 protocolVersion=1 过滤、增量结构和新版媒体拒绝策略。没有把“切回旧提交”当成已验证的生产恢复方案。
