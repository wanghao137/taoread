## 三、信息架构

**孩子端**：今天（继续阅读 + 推荐三本 + 心情入口 + 最近一条家庭记忆）/ 找故事（搜索 + mood + 语言 + 全部内容）/ 我的（正在读、喜欢、读完、生词、阅读记忆+足迹图）。真路由：`/child/today|discover|my|book/:bookId|book/:bookId/chapter/:order`，支持后退/刷新/deep link。「换人」开选人浮层；换家庭在选人页退出登录。

**家长端**：今天（15s 静默轮询 + visibilitychange；当前阅读/共读卡）/ 内容（桃书库+微信读书+纸质书说明+已屏蔽，搜索/排序/分类筛选/屏蔽开关）/ 足迹（周报+分享卡，读过/读完双口径）/ 设置（孩子资料/微信读书/休息时间/安静模式/AI 说明/注销）。BindWizard 状态机：说明→输入并绑定→正在验证→成功(尾四位/重绑)/失败(重试)。

## 四、API 兼容说明

- `POST /api/content/books/:id/progress` 新增可选 `completed:boolean`（默认 false）；老客户端不传行为变化：末章不再自动 finished（这正是本次修复语义）。
- `GET /api/reports/weekly` 返回新增 `booksCompleted:number`；`books` 字段与既有客户端兼容。
- `POST /api/cosession` 异书时返回 409 `ACTIVE_SESSION_OTHER_BOOK`（原为 201 复用）——旧客户端需处理该码。
- 无数据库 schema 变更，无 migration。
