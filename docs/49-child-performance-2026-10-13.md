# 孩子端性能优化与验证（2026-10-13）

本次重点处理首次打开孩子端、找故事、直接打开章节、听读入口和滚动阅读。使用生产构建、独立演示数据库与禁用真实供应商的隔离实例；没有使用生产小桃的登录或写入真实阅读记录。

## 已实现

1. 公共阅读器、家庭阅读器与听读按路由加载。直接进入这些页面时，代码加载与家庭校验同时开始，避免拆包后再增加串行等待。孩子首页不再预取家长端；家长/运营的共用标题组件也不再引入孩子端整包。
2. 已选孩子的书库读取与家庭校验并行。家庭校验通过后才使用结果；凭据与孩子 ID 必须匹配，预取失败正常重试。结果只供本次启动使用，不持久化、不设置跨家庭缓存。生产构建刷新首页仍只有一次书库请求。
3. 家庭书、自然拼读与听读入口不预取整份公共书库。
4. 首章正文与进度并行读取；读取进度版本、恢复块位置后才展示正文和写入位置。原有冲突保护、版本缓存与下一章预取保留。
5. 找故事首批由 60 张改为 24 张，继续加载每次增加 24 张。搜索/分类仍处理完整目录；书卡通过 memo 避免周报、成就等无关更新造成重绘。
6. 动画执行功能通过 LazyMotion 异步加载；按钮、弹层和加载提示保留动画及安静模式。试读与在线离线书架也按需加载，真正断网时仍使用原有独立静态离线阅读器。
7. 拼音扩展字体不再全站预加载，仍由 CSS unicode-range 按需提供，不删除字体。
8. 公共阅读器滚动位置计算合并到每个动画帧，进度条按整数百分比更新；翻页模式不挂滚动计算。后台/pagehide 时提交最新待存位置，沿用原保存队列。
9. 家庭校验重试清除旧错误，避免成功重试后仍停留在错误页面。

## 性能实测

旧构建来自优化前 HEAD `880569a1b95f5fdbb9ec99d71b11674d7f33c8d7`。同机两个独立实例，Chromium 390×844，4 倍 CPU 节流、100 ms 网络延迟、200,000 bytes/s 下载、禁用 HTTP 缓存与 Service Worker。每个场景新建上下文，前后交替各 3 次。

“可用”分别指首页/找故事首张书卡可见、章节标题可见、听读开始按钮启用。时间为三次中位数；不是线上真实用户 p75，也不是 Safari 真机结论。

| 场景 | 优化前可用时间 | 优化后可用时间 | 观察 |
| --- | ---: | ---: | --- |
| 孩子首页 | 6.409 s | 6.225 s | 中位数约减少 3%，启动资源下降更明确 |
| 找故事 | 5.305 s | 4.280 s | 中位数约减少 19% |
| 直接打开公共章节 | 6.627 s | 5.720 s | 中位数约减少 14% |
| 直接进入听读 | 6.464 s | 6.496 s | 时间基本持平，不宣称听读启动已提速 |

首页/找故事本轮加载的压缩 JS：211,812 → 169,861 bytes，减少约 19.8%。公共章节：211,812 → 190,194 bytes，减少约 10.2%。听读：211,812 → 172,888 bytes，减少约 18.4%。扩展字体另减少首页不必要的 27,384 bytes 预加载。

单次计时有明显主机负载波动，所有样本保留；没有剔除慢样本再计算。本轮未同时运行构建、单测或 E2E 的最终对比为 `comparison.json`，第一次测量与中间版本结果也保留。模拟 100 次滚动事件，最终构建同步元素位置读取为 0，帧内读取为 1；这是合并行为验证，不代表真实用户每秒滚动事件数。

## 验证结果和证据

- 服务端 480 项单测通过；前端 120 项通过。首次 `npm run verify` 的前端线程池在所有断言通过后发生 Node 24 原生退出崩溃，退出码 134；保留日志。前端用 `--pool=forks --maxWorkers=1 --minWorkers=1` 重跑，120 项通过且退出码 0。
- 全工作区 typecheck、触达审计、最终 lint 通过；最终 Web 生产构建通过，现代与 legacy 产物均生成。
- 完整隔离 E2E：22 项通过，包括新增的请求并行/家庭校验门、失效孩子隔离、书卡展开/全库搜索、进度读取前不写位置，以及收藏、结算、换人、离线和家长流程。
- 生产构建浏览器检查：390/820/1440 公共阅读布局、实际触摸翻页、字号调整、家庭阅读器手机触摸与平板布局、校验错误重试、听读供应商不可用后的停止恢复均通过，无页面异常。
- 首页未请求公共/家庭阅读器、听读、家长、试读或离线页面代码；直接听读未请求全量公共书库。

证据目录：`output/playwright/child-performance-20261013/`。包括最终 `build-release.log`、`lint-release.log`、`e2e-final.log`、`web-tests-retry.log`、`regression.json`、`comparison.json` 和截图。原失败/中间版本记录保留。
