# 条件能力决策与验收卡

对应执行台账 M10、M11、M14。基线 524b5d8。这里记录本轮能完成的调研与落地边界，不代表课程、独立身份或原生应用已经交付。保留用户 docs/47 方案原稿。

## M10 正式自然拼读

现状证据：`apps/server/src/modules/phonics/routes.ts` 目录返回 `status: draft`、`audioAvailable: false`；报名默认关闭，家长可以显式开启内测。现有 8 课、题目记录、暂停续做和家庭权限检查不能证明教学内容正确或训练有效。英文经典原作不属于经过拼读分级审校的教材。

执行卡：

1. 教学审校人逐课核查目标音素、字母音区别、口音、例词与干扰项，写出年龄和先修要求；每个结论附实际依据、日期和版本。
2. 为每个音素准备可独立试听的音频，区分音素与字母名称。普通整词 TTS 不自动视为合格音素音频。先在隔离环境复核，不批量付费生成。
3. 绑定内容版本和音频哈希；变更后批准失效，修订留痕。当前审校台仅覆盖公共书，课程审校字段和音素播放器仍需独立实现，不能把书籍审校冒充课程审批。
4. 让适龄儿童在监护下完成开始、听音、选择、暂停、恢复任务，记录误解与操作失败。样本量与观察规则须先制定；练习次数和答对题目不宣称识字或理解能力提升。
5. 只有专业审校、音频复核、儿童观察、跨家庭权限与中断恢复均通过，才讨论正式发布。上线应显式报名、允许关闭，保留草稿和旧进度的版本回退。

验收产物：逐课审校表、逐音素文件/哈希/试听记录、儿童任务记录、自动化权限与续做结果。缺少专业审校人、音频或观察记录时状态保持草稿。**本轮正式课程未验收通过。**

## M11 公开多家庭服务的家长身份

现状证据：`modules/family/routes.ts` 与 `service.ts` 采用家庭码加角色选择。成人算术提示用于防误入，持码者仍可选择家长；设备撤销、家庭隔离和运营独立凭据不改变这个事实。现有共享家庭码是已确认产品决定，本轮继续保留。

只有决定对公众提供独立、多家庭服务时，实施以下迁移；当前不静默改变家庭登录方式：

| 工作 | 要解决的问题 | 必需验收 |
| --- | --- | --- |
| 独立监护人凭据 | 孩子码不得授予家长权限 | 服务端强制区分角色；有孩子码仍无法删除/导出/授权设备 |
| 家庭认领 | 旧家庭码不足以证明谁是监护人 | 使用受控认领或已有可信恢复渠道，不先到先得抢占家庭 |
| 孩子邀请 | 孩子入口维持简短 | 邀请限定家庭与孩子角色，可撤销、可轮换，不升级为家长 |
| 找回 | 丢码/丢设备不丢数据 | 有验证恢复渠道与限流，无枚举家庭或泄露儿童资料 |
| 设备授权 | 撤销和账号变化立即生效 | 已撤销令牌无法敏感操作；重试与并发不能恢复权限 |
| 数据迁移 | 保留家庭、孩子、书籍与记录关联 | 隔离副本比对前后行数、关联、阅读位置及导出哈希 |
| 回退 | 新身份服务不可用仍可恢复 | 保留迁移映射与数据库备份；回退不能重新开放被撤销的家长权限 |

尚待确定：运营模型、身份供应商、恢复渠道及相应成本。不得先收集儿童真实身份信息来弥补家长认证。**本轮未交付公开服务独立身份，现共享码模式不满足该条件项的身份隔离验收。**

## M14 PWA、封装与原生路线

现状证据：Web/PWA 已有安装清单、离线公共书和听读页面；本轮 Chromium 合成媒体检查不能证明 iOS 后台、蓝牙、锁屏、通知或商店发布可用。家庭书没有本轮公共离线书架的同等离线实现，听读位置保存在本机。

| 需求 | PWA 当前证据 | iOS Safari/独立安装 | Android 浏览器/独立安装 | 选择路线前的关口 |
| --- | --- | --- | --- | --- |
| 公共图文和已有音频离线 | 隔离 Chromium 可测试保存、断网、重载 | 待真机容量、驱逐、过期测试 | 待真机测试 | 检查过期/缺媒体/取消与空间不足，不把缓存当永久保留 |
| 家庭书离线 | 未交付同等能力 | 待需求确认 | 待需求确认 | 权限撤销、共享设备隐私、原始文件范围 |
| 锁屏/蓝牙/来电恢复 | MediaSession 代码与页面说明 | 待真机 | 待真机 | 正在播、暂停、跨章、切耳机、来电、解锁恢复逐项实测 |
| 通知/提醒 | 本轮未交付推送 | 待真机能力/用户需求 | 待真机能力/用户需求 | 用户主动选择，关闭后停止，不以通知作为核心阅读前提 |
| 文件导入 | 分块/预览 API 与近 32MiB 测试 | 待系统文件选择/后台挂起 | 待系统文件选择 | 取消、刷新、续传、重复和扫描 PDF 的实际任务 |
| 跨端身份与进度 | 阅读记录服务端能力；听读仅本机 | 待跨设备矩阵 | 待跨设备矩阵 | M11 条件身份、版本冲突、离线同步和注销范围 |
| 发布更新 | Web 构建；生产未发布本轮 | 未交付商店流程 | 未交付商店流程 | 签名、审核、增量更新、缓存升级与旧数据库兼容 |

成本比较：PWA 复用当前 Web；封装增加容器/插件、双平台打包与商店维护；原生增加阅读排版、导入、播放和离线的双端实现与一致性维护。没有需求和真机缺口证据前，不给虚构工期或费用承诺。

执行顺序：真实家庭确认需求 → 同一套 iOS/Android PWA 场景测试 → 记录 PWA 无法满足的具体能力 → 小范围封装技术验证 → 比较生命周期成本 → 决定是否需要原生。若只是界面样式差异，不足以支持重写。**本轮独立原生应用未交付。**
