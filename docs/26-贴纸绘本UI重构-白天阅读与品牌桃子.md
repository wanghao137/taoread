# docs/26 · 「贴纸绘本」UI 重构：白天阅读 + 品牌桃子 logo

> 2026-09-20。用户三点要求：① 严格按 [codex-resets.com/zh-CN](https://codex-resets.com/zh-CN) 的风格重构 UI（从第一性原理出发）；② 品牌 logo 使用 taostudioai.com 的通用品牌桃子 logo；③ **去掉月亮/夜灯隐喻**——用户没有要求过「睡前仪式」定位，阅读不该只有夜里才能做。

## 1. 为什么改：第一性原理复盘

「月亮/夜灯/睡前共读仪式」是项目早期（docs/08-11）自行引入的**产品假设**：把整个孩子端叙事锚定在「睡前」——门屏是月亮仪式门、成就体系叫夜灯墙、底部导航第一项叫「月亮」、家长端叫「今晚」面板。它带来的问题：

1. **与使用场景错位**：孩子大部分阅读发生在白天（放学后、周末午后），入口却永远是「月亮升起来啦」；
2. **隐喻挤压功能认知**：「夜灯墙」实际是成就纪念册，「点亮月亮」实际是开始选书——孩子要先学会一套夜间暗语才能用产品；
3. **不是用户需求**：用户从未要求睡前定位。

重构原则：**功能骨架全部保留（成就收集、休息时间管控、共读收尾），换掉隐喻层与视觉层**。夜间护眼模式作为「工具」保留，不再作为产品人格。

## 2. 设计语言：「贴纸绘本」（codex-resets 风 neobrutalism）

从 codex-resets 提取的设计 token（其 CSS 自定义属性）：

| token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#FFF4DD` | 应用底：暖纸黄 |
| `--card` | `#FFFDF7` | 卡片奶白 |
| `--ink` | `#26201A` | 墨色：文字 + 2px 描边 + 实心阴影 |
| `--accent` | `#FF5C2B` | 橘红主行动色（hover `#EE4518`） |
| `--sun` | `#FFD84D` | 芒果黄（白天主场景） |
| `--rose / --sky / --mint / --peach` | `#FFB9CC / #A5DCFF / #B9E6A6 / #FFB07A` | 贴纸色：分类、徽章、装饰 |
| `--border` | `2px solid var(--ink)` | 粗墨线描边 |
| `--shadow` | `4px 4px 0 var(--ink)` | **实心偏移阴影（非模糊投影）** |

| display 字体 | Baloo 2 / Arial Rounded MT Bold / 圆体 | 玩具感标题，中文回退幼圆 |

落地（`tailwind.config.js` + 全局组件）：

- 色板整表替换，新增 `sun/rose/sky/mint/peach` 五个贴纸色组（文字一律 `text-ink-900` 保证对比度）；
- `TaButton`：高饱和实底 + 2px 墨线 + `3px 3px 0` 阴影，**按下时 translate 到位、阴影归零**（neobrutalism 经典按压手感）；
- `TaCard`：奶白底 + 墨线 + `4px 4px 0` 硬阴影；
- `font-display` 从衬线（编辑风）换成圆胖体（玩具感）；楷体正文保留（语文课本标准字体，利于识字）。

验收修复战记（值得留档的坑）：
- **书架封面「大面积空白」**：三轮排查——①懒加载未触发（sweep 加预滚动）②仍白（等 img complete 不够）③定位为**截图与 2K 插画异步解码的竞态**（瞬移滚动+短等捕到未解码帧；probe 脚本实测真实滚动 0 白块 0 坏图，服务端文件/HTTP/台账全正常）。终解：分段渐进滚动+2.5s 等待。教训：30045px 的 fullPage 长图超出 Chromium 渲染上限输出纯白块，超长页要用分段视口截图。
- **书架分页方案被否**：先按「首屏 24 本+再看 24 本」实现，e2e 暴露它破坏「书架全量可达」契约（7 个用例找不到书）——撤销分页恢复全量渲染，封面懒加载本身没问题。
- **emoji 红线三处漏网**：登录页角色卡（👨‍👩‍👧/🧒）、KitchenSink 心情示例、FinishScreen 进度/心情贴纸（🌱🌟🏆/😄🤩 在 lib/finish.ts 常量表）——全部换线性图标（TaSticker 的 emoji prop 改为 icon 节点）。
- **阅读器裸视频控件**：gen-video 完成的章节在书架截图中显示为黑色原生播放器——SceneVideo 重做：去 controls，自动静音循环+点击暂停+插画 poster+墨线容器。
